# 04｜把设计组织成提示词，并形成定向返修闭环

[上一册：表演与连续性](03_表演时间声音与连续性.md) → 本册 → [返回总导航](00_阅读导航与方法总纲.md)

## 经验一：提示词是设计的表达层

前面三册已明确事实、观看任务和时间过程。此时再组织提示词，目的是让同一设计表达得准确且无冲突。若直到这一阶段才发现人物要去哪、对白怎么说仍不清楚，应回到对应设计步骤补齐。

截图中的四大板块体现了“全局设定与逐镜内容分开”的经验。学习这层结构即可，不必把截图标题逐字搬进项目。既有五列分镜与六模块提示词格式可承接这些信息；本套文档是经验教材，不是某一片段的完整生成提示词。

## 经验二：按信息职责组织，减少重复与互相覆盖

| 信息职责 | 应表达什么 | 与后续内容的关系 |
|---|---|---|
| 生成任务 | 总时长、画幅、需要生成的事件 | 确定范围，限制无关扩写 |
| 主要主体 | 身份、外形、稳定特征和初始状态 | 为逐段行动提供同一批主体 |
| 场景状态 | 地点、位置关系、入口、光源和环境 | 为每镜构图及运动提供空间依据 |
| 情绪目标 | 从什么状态走向什么状态 | 为表演强度和节奏提供方向 |
| 视觉风格 | 摄影质感、色彩、材料及适用限制 | 与具体机位、照明保持一致 |
| 分段脚本 | 按时间写动作、摄影、对白、声音和结尾 | 把全局设计落实成可见过程 |

全局写一次，局部写变化。例如全片角色身份稳定，而某段开始肩部受伤，局部就要写明伤势如何改变动作。不要在各段反复堆叠长串“电影级、高级、超真实”，挤占关键过程信息。

若同一提示词既写“全程固定机位”，又在局部要求绕到背后，必须解决冲突后再提交。若风格要求“任何反光都没有”，而场景又有湿润皮肤、金属和车灯，应改写材质要求，而不是继续增加形容词。

## 经验三：正向描述先说明成立的画面，负向约束防止具体偏差

只写“不浮夸、不僵硬、不塑料”，无法确定具体想要什么。先写人物在做什么、身体如何反应、材料如何呈现，再补最相关的禁止项。

参考图排除白底和展示站姿，是针对明确污染来源的有效限制。禁止伤势复原、人数增减，是针对剧情连续性的明确限制。与本片无关的长串禁用内容只会增加阅读负担。

“丰富内容”的委托也要限定职责：补可见过程、表演和环境反馈，保持已有事实与结果。这样既留出创作空间，也能判断扩写是否越界。

## 经验四：分镜头与生成片段是不同层级

镜头由观看方式与剪辑决定；生成片段由实际工作方式和工具条件决定。一个片段可以包含多镜，也可能为了控制复杂动作而拆开制作。不能把截图案例的18秒或15秒直接当成所有平台的能力上限。

具体工具的时长、参考图数量、声音支持及控制能力应在实际制作时核实。无论怎样拆分，前一段的结尾状态与后一段的开始状态都必须相接。拆分策略变化不应悄悄改变原始事件和总时长。

## 经验五：审片先看成立与否，再看好看与否

建议依次检查：事件和对白有没有变化；人物与空间是否连续；动作是否有可辨因果；表演与时间是否自然；声音是否支持事件；最后看材料、锐度、颗粒和局部亮部。

这一顺序降低无效精修。角色拿错道具时，先处理道具身份；动作完全看不懂时，先处理调度、机位或节奏。仅对已成立的镜头微调表面质感。

静音观看可以帮助检查空间和动作；只听声音可以发现对白遮盖或声桥断裂。但这两种辅助检查不能代替最终声画合看的判断。

## 经验六：失败后回到最早出错的层

| 看到的问题 | 先检查哪里 | 建议修订方向 |
|---|---|---|
| 背景混入人物定妆白底 | 素材用途 | 限定身份参考，明确场景来源 |
| 人物换位、空间镜像 | 世界位置与新机位 | 重算观察关系，核对行动路径 |
| 刀已接触但身体提前后退 | 动作时间链 | 明确接触、受力与反应顺序 |
| 情绪像统一表情包 | 人物目标与状态 | 选择少量有触发原因的反应 |
| 对白像赶读 | 同期动作与时长 | 调整可变节奏或镜长，重新读台词 |
| 画面很糊但仍不像电影 | 画质描述与观看任务 | 去除笼统损失指令，保留关键细节 |
| 皮肤像蜡或塑料 | 材料要求、光线与输出 | 分别检查高光、细节和通透感 |
| 相邻片段像两个场景 | 状态交接 | 统一人物、物件、环境、光和持续声 |

这里列的是排查顺序，不是已经证明的唯一原因。同一现象可能来自参考素材、表达冲突、工具能力或后期处理，需对照实际样片判断。

## 经验七：把一次修订变成可复用经验

建议记录“原目标—实际偏差—判断原因—修改内容—新结果”。尽量一次验证一个主要改动方向，避免同时换参考、机位、动作和风格后无法判断哪项起作用。

试验成功后，记录适用条件：什么景别、多少主体、怎样的运动、哪类材质、使用什么工具及配置。没有这些条件，“加一句就更电影”只能算个人印象，不能沉淀为可靠规则。

当前没有实际生成结果时，把建议标为“待样片验证”。截图文字自述已通过检查，只能说明作者作了这个声明，不能作为本项目视频完成的证据。

## 完成标准与复用方式

一套设计可以进入制作讨论，需要做到：事实来源清楚，参考用途明确，世界空间成立，摄影与人物行动互相支持，台词和动作放得进时间，前后状态衔接，提示词内部无矛盾。

正式样片验收还需检查实际画面与声音。将通过的局部经验回写到对应学习章节；剧情或世界状态变化时，从01开始检查依赖；只调整颗粒或锐度时，可聚焦02与本册。这样文档既连续，又支持按问题快速查找。
