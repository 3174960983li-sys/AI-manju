# 主体行动与角色表演系统优化说明

2026-10-26。导演photoreal-drama-director V0.2→V0.3；分镜shot-language-design V0.4→V0.5。两包完整升级前ZIP位于05_文件整理/03_停用归档/Skill历史版本。未改项目剧本、已采用作品、提示词六模块或全局默认；未安装。

| 方法缺口 | 实际修正 |
|---|---|
| 目的、策略有框架，但企图可能被写成成功 | 分任务/目的/方式/实际结果，沉默不自动认罪 |
| 容易每人独立执行表情清单 | 增加感知、判断、给予/接收与适应，按反馈改变行为 |
| 肢体动作与交流只作先后串联 | 增加从属与并行身体任务，以及中断/恢复条件 |
| 人物差异仍可能来自抽象标签 | 以具体对象、处境、习惯、熟练度和物件条件设计 |
| 观众想感动被误当人物必须哭 | 分开导演体验目标与角色当下行为，不提前演结局 |
| 微表情词库可能倒灌人物心理和造型 | 候选筛选，去掉残留标记，固定骨相与动作分开，眼神不证明真相 |
| 真人训练与AI编写层级不够明确 | 导演依据、分镜执行、提示词编译分层，模型不假装拥有演员经验 |
| 所有行动都可能被套主动目的 | 反射/意外及非人格主体分别处理，不强行补心理策略 |
