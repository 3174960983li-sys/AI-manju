| 发现的方法缺口 | 已做修改 |
|---|---|
| 路径明确但观察关系不够明确 | 加行动区域内外、观察距离及视点区别 |
| 同速/跟拍过于笼统 | 规定相对速度、距离、主体大小与朝向的联合检查 |
| 只优化摄影机路径 | 保持已锁人物行为，在未锁条件下协同双方路径 |
| 画面过门容易等同真穿门 | 分清真实路径、空间揭示、非实体穿越及拼接 |
| 阶段接口缺光学/中间画面检查 | 加关键节点、焦点/景深、遮挡、视差与信息可读性 |
| 默认缓慢流畅可能抹平节奏 | 起停/滞后/急变按职责，检查稳定性与整段运动规律 |
| 运镜与剪辑检查相对分离 | 增加动静组接、动作阶段、方向与新镜定位，不定死动接动 |
| 来源风格观点可能冒充规则 | 明确不采按性别年龄、商业片不停动、推轨客观等绝对要求 |
