# 观众情绪系统分析与三项Skill优化说明

2026-10-26。范围：阅读所给798行知识文档，分析方法及边界，更新项目剧本分析、导演思维、镜头语言设计，并检查视频提示词接口。没有修改原知识文档、作品、历史试跑或全局默认，没有生成媒体。

## 结论

应吸收的是“观看目标→必要条件→具体表达→兑现→证据反馈”的工作方法。五状态和五种方法可作提示，不能当作固定心理分类、固定场次结构或万能留存公式。三项Skill需要按职责接入，而不是每份复制整本手册。

## 1. 系统真正解决什么

文档把抽象效果拆成注意、理解、体验强度、人物关切、期待等不同问题，并将人物情绪与观众体验分开。它要求信息有来源、表演有刺激与反馈、等待有内容、揭示有兑现，最终用素材和观看反馈检查。这比“加音乐、加特写、加反转”更能指导返工。

完整工作链可概括为：

1. **确定体验。** 不是只填“紧张4分”，而是说明观众为谁、为什么、在等哪个结果；非叙事内容可以以理解、观察或新奇为目标。
2. **核必要条件。** 原文有没有提供前提？哪些是人物知道、观众知道、观众仅在猜测？不能把作者知识直接当成屏幕信息。
3. **设计观看过程。** 决定何时看/听什么、谁做什么、变化如何被感知，选择表演、调度、构图、运动、声音与时间。
4. **检查兑现。** 等待是否得到有效回应，结果是否真的改变理解、行动或关系；允许兑现后结束。
5. **分层验证、局部修订。** 设计自洽、素材实现、剪辑采用和观众体验各有证据；找到造成问题的条件，再修对应范围。

## 2. 需要保留的限制和调整

| 原文方法或潜在误读 | 本次判断与采用方式 |
|---|---|
| 五状态配五方法 | 原文已声明不是科学统一分类。保留为启发，先描述具体问题；状态可以重叠，平静和满足也可以是目标 |
| “放大表演” | 理解为提高反应/选择的可读性，不等于哭得更多、全用特写；歧义和掩饰也可能是既定表达 |
| 每镜标目标和信息 | 重要节点必须可回查，但不要求额外增加一套字段；段落共性写一次，关键条件落回七列 |
| 悬念模板包含人物代价 | 适合部分叙事，不推广成所有好奇都必须有风险；知道结局也可能关心过程 |
| 生成停顿时写微小行为 | 微动作是候选。倾听、静止、环境连续与观看时间本身可成立，不给每次停顿添加表演套餐 |
| 复杂互动拆素材 | 生成任务与成片镜头分开；不能擅自破坏已锁一镜到底或观看过程 |
| 去旁白、静音、去配乐检查 | 均作诊断；旁白与声音可能是作品正当的信息载体，不能由测试推导出禁用规则 |
| 优先修最早失效环节 | 按实际证据找因果，不机械重做最早阶段，也不把观看掉点直接解释成“不共情” |
| 加动作以建立关切 | 普通导演手段可提出；新增剧情、关键设定、对白或改变已锁意义仍需按现有边界讨论 |

## 3. 原文示例中发现的具体问题

- **首次试修时点不一致：**第12.1节写女孩离开前转发条、音乐盒不响；第12.4节S03放在女孩离开后。这会改变女孩是否见到该次失败，完整案例定稿时应统一。本轮不替用户裁定，也未覆盖原文。
- **“熟悉旋律”的对象应明确：**S10的熟悉可以属于女孩；观众若此前没听过，不能假定能认出同一旋律。若只需理解旋律恢复，原有请求与声画已可提供条件；若要观众辨认主题复现，需要另有前置声音，不自动补写。
- **“停顿中保留微小行为”易被机械执行：**原例可以这么选，但不应成为所有停顿的生成规范；已在导演和分镜方法中作了限制。
- **原文提及另附工作表：**本轮检索到当前正文，未据此核实独立工作表，不把它列成必须依赖的交付。

这些是使用前需要明确的点，不否定整套方法；文档本身对未经媒体验证、五分法证据和音轨限制已有较好的声明。
