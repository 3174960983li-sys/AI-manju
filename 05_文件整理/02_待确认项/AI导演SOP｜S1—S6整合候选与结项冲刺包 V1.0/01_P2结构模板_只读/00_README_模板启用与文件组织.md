# P2-02｜空白模板包使用说明 V1.1

本包覆盖S1—S6的A01—A22逻辑交付及G1—G6阶段工作门。只有**9类模板族**；某类内含的附页仍属于同一工作文件。项目负责人可以在实际项目中将多个附页并入同一Markdown/表格文件，保留同样字段与编号即可。T09属于横向管理，不是新增的A23。

## P2-04新增｜普通场最短路径与复杂场触发（F11）

**普通对话或简单情绪戏**：项目首次T01→T02+T03并行草拟、G2共同批准→每场T04 A09+A11简版→T05 A13七栏+A15需求→T06按GEN核实真实引用→T07 A18+A19→T08有视频才用；T09只在对应工作门记录结论。无高风险动作时A10、A11专项、A14、A20可标“不适用及原因”，不得无意义开四份空附表。

**复杂触发**：两人或多人接触、推拉抓握及重心变化→A11 S0→Sn和必要A10；多机位主反/俯→A11世界坐标/轴线+镜头机位关系；声音跨镜、OS/VO/SYNC混合→A14；长动作、多角色、指定高精度台词→A20；多SH同一GEN→T07时码映射及T08按SH源内可用段。触发是**工作条件**，不强制所有场次一视同仁。

该路径是**结构性预设**，实际填写耗时与模板便利性仍需P3用真实项目验证。

## 3. 使用顺序

T01 → T02/T03（同一生效剧本基础上协同）→ T04 → T05 → T06真实资产移交 → T07正式视频执行稿 → T08真实候选验看。T09在G1—G6节点使用且是**唯一签核权威**，其他卡仅引用gate_id。S6-01及文本规划可在G4后进行；**正式需参考的模型生成不能绕过G5**。

- `[填写]`：待输入，占位不构成满足必填；无材料写“待核实U、影响及下一次触发”。
- `F/I/H/U`：项目事实/依据推断/导演提案/未知状态；不是通过、失败评分。
- `不适用`：附加条件确实不满足时使用，需简要解释。不要填假内容凑完整。
- `未测试`：没有实际生成输出时使用；不能写“模型验证通过”。
- “项目层引用”与“原文台词”：正文可以有必要摘录，但权威始终是T01:A02标定的有效剧本。

## 4. 四条保护规则

1. **A13七栏的顺序不可改**：镜号与时码｜镜头任务｜摄影设计｜画面与表演｜场景与光影｜台词与声音｜衔接与备注。
2. **A19仅提交TXT**，按照一、生成任务；二、主要主体；三、场景状态；四、情绪目标；五、视觉风格；六、分段脚本。逐镜写时码/景别机位摄影、画面、台词、表达情绪、声音。TXT不写`#`、`*`和审核元数据。
3. **S5占位不是素材**：A17不能算G5证明；没有真实素材，不得虚构编号、绑定或“已核验”结论。
4. **候选与通过记录必须有真实输出**：T08在尚未生成时可以保持未启动，不填演练视频路径。

## 5. 来源与生效关系

P2-01 46项步骤规范为直接上游；T02视听八规则、T03视觉六锚点、T04表演六栏、T05分镜七栏和A19视频六模块分别取自对应已上传原始规范。T01—T09的编号和元数据、字段调用规则是本轮标准化设计（待项目负责人审定）。

- G2成对锁定T02:A06与T03:A07；G4允许S6草稿规划，不授权正式生成；G5按GEN核实真实必需引用；G6按真实候选逐SH判可用。
- R记录有值和事实U可并存，若U是本范围阻断信息则不能工作门通过。
- 上游更改后只能依据T09新一条签核/复核记录恢复新快照活动；旧记录保留审计痕迹。
