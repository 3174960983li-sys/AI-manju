# S5-05｜AI仿真人短剧道具资产设计流程与精简提示词规范 V2.2

> **文档定位**：P3-S5道具资产专项修订候选，供用户审核。替代本专项此前V2.0中关于“所有道具均按同样画幅起步”和“实际执行提示词必须填七个段落”的建议；不自动变更已存在的S5-05编号、T06、A16/A17或T09:G5审批规则。  
> **范围**：纯道具身份母版、按需结构补图、剧情状态变体和向视频制作交接。**不要求本次生成图片。**  
> **来源分层**：用户明确指定“中性、灰背景、45°摆拍、中性光、材质写实、8K”，并最终将道具主图比例锁定为16:9、1:1、9:16三种可选；上一版《道具资产45°摆拍、结构与交互状态设计规范V2.0》与《海外AI仿真人短剧道具资产提示词规范》提供背景与已有接口；本次分类、五步流程与三模块结构为改进建议。未经模型测试，不声称成功率。

## 01｜原有方案的问题及修订决策

| 原方案问题 | 实际表现/风险 | V2.2决定 |
|---|---|---|
| **七段必填、提示词太长** | 普通酒壶、玉佩也需反复填写结构、状态、功能、材料、参考职责，重复且易相互矛盾 | **实际生成提示词固定为三模块**；细节只在影响外形或使用时补充 |
| **九步工作法对每件道具都相同** | 背景摆件与复杂机械件采用同样工作量 | **五步主流程**，复杂/关键物件才增设结构、动作与状态核验 |
| **16:9被写在通用主图母稿开头** | 竖向酒壶、横向长刀或方形玉佩若统一采用16:9会产生大量无效留白、裁切或比例失真 | **每件道具只可从16:9、1:1、9:16中选择一种**；严禁使用其他比例 |
| **“45°”只写数字** | 易变成道具倾斜、相机正拍，或者关键识别面被挡住 | 统一解释为**相对主识别面的3/4斜向摄影观察**，摆放稳定、前侧结构可读 |
| **摄影指令与复杂设计要求混合** | 对母版同时要求手握、开盖、变化、叙事动作，出现多物体或画面污染 | **纯道具母版**与**状态/使用图**分开；主图无人物无手 |
| **材质描述趋向堆砌** | 无关镶嵌、密集微纹理、悬浮展示增加塑料感 | 只写**核心材质、主色、1—3个真实结构识别点** |
| **没有把8K列为统一照片要求** | 不同任务写法不一致；将超清口号误认作真实输出像素 | 固定`8K ultra-detailed`为**目标细节**，并在文件验收中查看实际像素尺寸 |
| **一概排除所有文字** | 对书信、题字酒壶、证物等剧情必要信息不合理 | 排除**附加标题/水印/无意义乱码**；本体确需文字时采用精确已审原文 |

**总原则：设计管理可以比执行提示词详细；把管理字段留在资产档案中，把图像模型必须理解的可见信息写进提示词。**

## 02｜仿真人短剧道具主图的六项硬性要求

| 固定项 | 操作解释 | 不合格表现 |
|---|---|---|
| **中性呈现** | 单件道具自然静置，目的是识别形制；不做广告海报、剧情氛围场景、动态冲击构图 | 戏剧性动作、悬浮魔法陈列、海报感 |
| **中性灰背景** | 干净无缝、均匀的中性灰摄影背景；道具仍保留自身真实固有色；地面与背景衔接柔和 | 白底、黑底、彩色背景、房间/复杂摆台 |
| **45°摆拍** | 相机相对**指定主识别面**大致斜向45°，同时看到正面与一侧/厚度；圆柱形以关键把手、壶嘴等结构为观察依据 | 仅正面平拍、纯侧面、识别面被遮挡，或道具被硬性倾倒 |
| **中性光** | 柔和、均匀、自然的影棚照明，光色中性、不过曝；保留材质真实高光与接触阴影 | 红蓝彩光、强舞台光、彻底无体积的平板光 |
| **材质写实** | 有真实厚度、工艺、重量、磨损逻辑；金属、陶瓷、木、织物分别呈现合理反射和形变 | 蜡像/塑料表面、重复噪点、低模连接、漂浮 |
| **8K超高细节目标** | 提示词固定写`8K ultra-detailed`；实际文件的**像素尺寸需单独检查**。如果目标输出真8K而模型入口不支持，则另做放大/导出验证 | 将“8K”文字写进图内，或把提示词包含8K当作实际8K证据 |

**补充约束**：默认纯道具单件、无人物、无人手、无额外物品、无图外标签或水印；**道具固有文字**若是必要剧情信息，不作为“附加字幕”删除。应根据时代与剧本禁止不合适的现代部件，而不是禁止所有现代题材道具。

**主图与45°的关系**：45°约束的是**拍摄观察方向**，不是所有道具都必须以45°斜立，更不要求柔软布料被固定成硬质三角形。平铺书本、垂挂饰品和长柄器物可采用符合重力的放置方式，由摄影机斜向拍摄。若单张45°图仍遮挡关键信息，补一张正视/俯视结构图，**不取消主图45°标准**。

## 03｜画幅选择：仅允许三种固定比例（强制）

**本项目正式道具资产仅允许 `16:9` 横向、`1:1` 方形、`9:16` 竖向。** 每张图片只能选择其中一种。`4:3`、`3:2`、`3:4`、`4:5`以及其他比例均**不得作为正式资产交付比例**，即使模型能生成也不例外。

先确认道具在真实重力下的展示姿态、长宽轮廓和必须展示的结构；再从三种比例中选择最能完整呈现的一种。**比例固定的是资产画布，不是道具实际形态**，不要为了适配画幅拉长、压扁、扭曲道具。

| 正式允许比例 | 推荐对象与展示方向 | 具体构图方案 | 典型道具 |
|---|---|---|---|
| **1:1（方形）** | 轮廓紧凑、宽高接近；或可以自然形成接近方形的摆放 | 单件居中，45°斜向观察，四周留白适度；高度略大于宽度的酒壶也可用1:1展示 | 玉佩、戒指、印章、圆盒、普通酒壶、折叠或自然搭放的红盖头 |
| **16:9（横向）** | 横向细长、扁宽；或竖长物件可以安全、合理地平放 | 物件沿画布长轴自然摆放，摄影机对其主识别面呈45°斜向；起点终点完整保留 | 长刀、剑、横向卷轴、长杖、长箱、茶盘 |
| **9:16（竖向）** | 竖向细长，并且能够安全、合理地直立、悬挂或垂落 | 物件竖向居中，45°斜向拍摄，顶部和底部完整入镜；不能为了上竖画幅强行把柔性布料撑成硬物 | 细颈酒瓶、高形烛台、瓶器、竖置的礼仪器物、自然垂挂的织物 |

**画幅选择优先级：**

1. 完整展示道具外轮廓、主识别面和重要部件，保证摄影观察角度是45°。
2. 选择能容纳真实摆放方式的比例：横向使用16:9，紧凑使用1:1，纵向使用9:16。
3. 一件道具如果多种比例都能完整展示，主图只锁定一种；需要第二种比例时，须作为**独立衍生版本**建档，不用“16:9或9:16任选”提示词。
4. 长而竖的物件若无法自然站立，可以平放并采用16:9；不要因为原实物很长就强制9:16。
5. 道具真实大小属于资产主档尺寸信息；画面比例只负责摄影展示，不能把画面像素当作真实测量尺。

**模型能力边界：** 若当前模型入口无法直接输出三种要求之一，可以更换支持的输出方式，或在不裁断物件的前提下以画布扩展/重新排版到指定比例；最终必须核对真实像素宽高与目标比例。**不允许以4:5、3:2等作为“近似比例”直接交付**。若需要重裁但会裁断识别点，则此生成结果不合格，应重做。

**推荐留白**：四周不截断把手、器口、杖首、挂饰或布角；无需强制所有物件在画面内占同样百分比。尤其16:9横幅与9:16竖幅都应避免长轴两端被边缘裁切。

## 04｜简化设计流程：五步即可开始制作

| 步骤 | 实际要做的事 | 最小交付与通过条件 | 不通过如何返工 |
|---|---|---|---|
| **01 需求确定** | 从剧本/分镜找出需要独立建档的道具；明确用途、时代与角色使用关系 | **一句话道具任务**；不能引入剧本未授权的新物件 | 道具不需要独立母版→纳入场景；剧情不一致→退上游核对 |
| **02 外形与画幅决策** | 锁定轮廓、主要部件、比例、主识别面，仅从16:9、1:1、9:16中选定一种画幅 | **可复原的极简设计卡+单一画幅**；结构、方向不自相矛盾 | 外形或大小不合理→改设计卡，而不是加形容词 |
| **03 精简提示词编译** | 只将必要的道具视觉信息写进三模块，统一附上六项固定摄影要求 | **一条短的可执行母版提示词**；画幅严格三选一，无互斥比例或多余动作 | 遮挡→换45°偏转侧别；复杂→删无关要求 |
| **04 生成、选图、验收** | 查看实际图像，检查背景、45°、完整轮廓、材质、时代、结构和8K目标/实际像素 | 保存**真实图片与审核记录**；只有文字提示词不记资产完成 | 图像偏差先判断是设计/提示词/模型执行问题，再局部重出 |
| **05 按需派生与交接** | 只有剧本需要才补开合、背面文字、破损、持物参考；登记版本、状态、适用镜头 | 真实AST文件、状态编号及REQ→AST→GEN对应关系；可申请但不可自签G5 | 交互不成立退结构或动作设计；绑定失败退S5-08 |

## 05｜提示词结构：三模块，且可写成一段短文

**固定项：实际提示词中画幅必须写明16:9、1:1或9:16的其中一项，不可写“任意比例”“根据情况调整比例”。**

| 模块 | 写什么 | 建议篇幅 |
|---|---|---|
| **A｜是什么** | 道具名称、时代/用途、基本形状、是否需要唯一识别点 | 1句 |
| **B｜长什么样** | 主要材料、颜色、最多几个关键结构/纹样、当前状态 | 1—2句 |
| **C｜怎么拍** | 已选定的画幅、真实45°摆拍、中性灰背景、中性光、写实材质与8K目标，主体完整 | 1—2句 |

**不必把模块标题一起投喂给图像模型；只要三部分信息完整，最终写成一个短段落即可。** 不使用“某比例或另一比例”“可能有”“随意增加”等模糊表达。若已有真正上传的参考母版，加一句“参考图1只锁定既有造型和材质，保持识别点”；若没有上传就不要虚构`Image 1`。

### 5.1 通用简洁模板（主图）

```text
一件〔时代/风格〕的〔道具名称〕，用于〔基本用途〕，整体呈〔主要轮廓〕，具有〔必要结构与识别点〕。主体采用〔主材质与真实工艺〕，颜色〔〕，当前处于〔完好/关闭等指定状态〕。

采用〔从16:9、1:1、9:16中选定的唯一画幅〕，同一件道具完整入画，以主识别面为基准，从约45°斜向机位摆拍，同时呈现主面与侧面，稳固自然放置。中性灰无缝背景，中性柔和摄影光，材质写实，真实厚度与自然接触阴影，8K ultra-detailed。无人物、无人手、无无关道具、无画外说明文字或水印，无塑料感、无低模感、无夸张透视。
```

> 模板只有**道具特征**与**摄影约束**两小段。复杂道具可以在第一段补一个关键机械信息句，但不升级为所有道具都强制七段。

### 5.2 现成固定摄影尾句（只需替换画幅）

```text
〔从16:9、1:1、9:16中选定的唯一画幅〕，单件道具完整入画，约45°斜向摆拍，正面与侧面结构清楚。中性灰无缝背景，中性柔和影棚光，材质写实、体积真实、自然接触阴影，8K ultra-detailed。无人物、无人手、无多余道具、无额外文字、水印、塑料感和低模感。
```

若道具表面存在经剧本确定的刻字，最后一句中的“无额外文字”不影响保留**道具本体的正确刻字**。不要把`8K ultra-detailed`当作像素尺寸自动升级指令。

## 07｜追加视图与状态：只在剧情需要时增加

**默认只有母版**。是否补图按镜头需要决定，而不是按“高级资产必须有多视图”决定：

- **含正面信息**：如信纸、地图、印章底字，保留45°母版，另做正视/俯视信息核对图。
- **开合动作**：如酒壶拔塞、箱子打开，保留母版，再按同一部件关系追加打开状态图。
- **手持交互**：真实互动必须核对角色掌宽与握点，可单独制作含手的交互参考图；这不是“纯道具母版”。
- **被损坏或沾污**：新建`STATE`图，明确发生时间、变化部位与后续镜头；保持原有轮廓和识别点。
- **结合特效**：纯道具母版不预先烙入火焰、电光或粒子；效果进入独立FX资料并注明同步条件。

**最小状态派生句**（需已有且实际上传的母版时使用）：


## 08｜审核标准：六项固定 + 三项功能检查

### A｜硬性审图项目（不满足则退回）

- [ ] 中性呈现：单件独立、姿态合理、没有强剧情化/广告包装。
- [ ] 背景为干净**中性灰**；不是白底、黑底或具体房间。
- [ ] **45°斜向摆拍**真实成立；看得到主识别面和厚度/侧面；如圆器则重要部件可见。
- [ ] **中性光**、曝光正常，物件轮廓与接触阴影清楚。
- [ ] **材质写实**：形制正确，木、陶、金属、布等有各自真实物性，没有塑料/蜡像/低模感。
- [ ] 提示词与审查均执行**8K ultra-detailed目标**；另行记录文件实际像素，不能据提示词声称实际8K。
- [ ] **真实输出画幅是16:9、1:1或9:16其中之一**，与本次提示词完全一致；物体全貌清楚、不裁关键部件，不过度空白或被拉伸。
- [ ] 固定识别点与结构相符；没有凭空附加现代零件、无关物件、标签水印；本体必要文字准确。
- [ ] 若存在实际交互需求，尺寸、把手、开合方向可执行；未测试动态行为则标注`未验证`。

### B｜失败原因与最小返工

| 失败现象 | 首先修订什么 | 不要做什么 |
|---|---|---|
| 酒壶竖身被16:9压缩或裁头 | 从**1:1或9:16**中选择，检查物件占画比例和上下留白 | 大幅重复“8K超清” |
| 45°变成平面正视图 | 指定主识别面、机位所处侧别、须看见的厚度 | 仅再写一次“45°” |
| 长物件被砍掉一端 | 横向画幅和摆放方向，补“首尾全见” | 随意缩小成小型短物件 |
| 道具像塑料 | 核对具体材料、釉面/铜/木/织物反射与接触阴影 | 叠加“极致细节”与密集随机微纹理 |
| 玉佩厚度异常或花纹跑位 | 补1处主识别面和边缘厚度参考 | 从另一张随机图再设计纹样 |
| 灰背景被摄影台与道具群替换 | 强化“单件、无场景、无摆台”并重出 | 默许其他道具增加构图丰富度 |
| 多次生成仍结构漂移 | 先锁设计卡/参考图，再小范围改提示词 | 每次重写所有颜色、纹样和外形 |
| 输出写“8K”，实际像素不达标 | 查图片尺寸、输出入口、必要时做单独放大核验 | 把提示词中的8K当作已达标事实 |

### C｜项目状态和审批

- `E0 文本审查`：检查道具需求、短提示词和画幅是否清楚。
- `E1 实际图片审核`：存在真实输出文件，可检查结构、角度、画幅、材质、文件像素和可用性。
- `E2 视频动态验证`：在真实GEN中核实持取、开合、转动、受力与跨镜头一致性。
- **G5是资产引用准入审批**：需要真实AST文件、版本、适用REQ/GEN和T09授权；设计一份V2.2文档不等于资产通过G5。
