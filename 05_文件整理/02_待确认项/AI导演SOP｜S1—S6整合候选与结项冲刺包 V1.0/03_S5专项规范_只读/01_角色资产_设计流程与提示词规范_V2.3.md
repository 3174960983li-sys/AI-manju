# S5-03｜AI仿真人短剧角色资产：设计流程与提示词规范 V2.3

> 文档属性：项目专项修订稿／待审，不是模型官方语法，也不代表真实出图通过。承接角色资产V2.0、三联定妆V1.1、《角色脸部正特写提示词结构与规范标准V1.0》及用户本轮明确的画幅要求。保留现有S5-03、A16/A17、T06/T09:G5接口，不另编正式工作步骤。  
> **本轮确认硬约束：三联定妆图唯一画幅为16:9横向；左正面全身，中背面全身，右约45°头肩大近景；三格同人同装同状态；中性中灰影棚背景。**

## 01｜原规范问题与修订决定

| 问题 | 旧版风险 | V2.3处理 | 是否改变质量标准 |
|---|---|---|---|
| 九步R01—R09对普通角色过细 | 从选脸到登记在多个环节反复录入同一身份、造型与状态 | 合并成**六步主流程**，复杂角色按需做专项工作卡 | 不降低 |
| 七段执行提示词与固定开头／结尾重述三联要求 | 信息过多，甚至可能出现“正面特写”与“右45°”冲突 | **四个执行模块**；三格摄影规则只集中写一次；必要时提示词可直接整理成完整自然段 | 不降低 |
| 母版、三联图和表演图在同一稿中处理 | 角色面部容易被情绪、戏剧光线、动作姿态污染 | 身份→造型→三联→剧情状态／特写增补，分清文件身份 | 不降低 |
| 背面来自未经设计的信息 | 会随机生出绑带、发髻、腰封或配饰 | 在三联前明确**背部结构是设计提案还是已审定事实** | 提高 |
| 用户“三视图”易被误认为正侧背 | 第三格变成全身侧照或正脸特写 | 三联明确定义为**正面全身／背面全身／45°头肩**，侧视若需要另生 | 提高 |
| 画幅随意调整 | 三格比例失衡、鞋子被裁、脸部占比不足 | **只允许16:9**；通过三格排版比例和人物相机距离解决空间不足，不改3:2或9:16 | 提高 |
| “8K超清”可能误判 | 写了超清但导出像素未知 | 提示词保留`8K ultra-detailed`视觉目标；文件像素独立登记，未验证不能称实际8K | 提高 |

**原则：制作管理可保留必要结构；输入图片模型的提示词应短、准确、无冲突。** 角色身份信息多不意味着堆砌描述，必须优先描述能被镜头识别的骨相、发型和衣装结构。

## 02｜固定交付与画幅

| 项目 | 必须满足 |
|---|---|
| 主输出 | **一张16:9横向三联定妆角色表**，不是三张不关联的角色图 |
| 左格 | 单人**正面全身**，平视、正对摄影机、自然直立、双臂垂放、手部和鞋子可见，头脚完整且留边距 |
| 中格 | 同一姿势、同一比例的**正后方全身**，不得回头；后脑、发尾／发髻、背幅、腰带／腰封、裤／裙／袍后摆、鞋跟真实可见 |
| 右格 | **约45°四分之三头肩近景**，脸大且清晰，同时看到正面五官结构与侧脸轮廓；不得变成正面脸、90°侧脸或全身 |
| 统一条件 | 三格是**同一人物、同一身份、同一LOOK、同一STATE**；摄影棚中性中灰色纯背景，柔和定向中性光，真人影视定妆观感 |
| 人物状态 | 自然中性表情，不拿物件，背部服装与发型按实际角色设计，不能给所有人统一套用“衣裤和松散发尾” |
| 禁止 | 头脚裁切、正背不等高、同脸不同人、服装变色、增减饰品、塑料皮肤、油亮磨皮、糊成片的头发、低模感、标题、注释、水印、演出布景 |

**全身两格比例接近，右侧近景按识别需要放大。** 若服装体积大，优先调整分格宽度、全身人物缩放与留白；不放弃16:9，不裁掉鞋履。建议正文将输出只描述为一张三联图，不要求摄影模型内生成分隔线、标题或排版文字。

**独立正脸身份母版**：主要角色在选脸时可以单独出一张正面脸部锁脸图。此图不同于“三联右格45°头肩”，不拿来替换右格。额外严格侧面全身、动作表情或受伤图按S4镜头需求派生，不改变三联固定结构。

## 03｜设计资料最小要求：ID、LOOK、STATE

| 层 | 最低设计信息 | 来源纪律 |
|---|---|---|
| 身份ID | 姓名、已确定的年龄段和世界时期、角色可辨认骨相（脸型／眉眼／鼻唇下颌）、肤色倾向、发际线、体态 | 来自剧本的标F；美术拟定的外貌标H；未确定标U |
| LOOK造型 | 一套服饰前后层次、主要颜色、真材质、前后领口、袖口、腰带/封、鞋、后发型和配饰数目 | 未被来源看到的背面须先审定，不宣称参考图已经证明 |
| STATE剧情状态 | 当前穿着是否完好、皱褶／破损／污渍、盖头/头饰在位、受伤妆、适用场次与SH | 一场一版；状态变化由剧本事件触发，不把剧情表演刻进长期母版 |

## 04｜六步主流程（R1—R6，仅为S5-03内部操作编号）

| 步骤 | 做什么 | 可交付结果／通过条件 | 返工入口 |
|---|---|---|---|
| **R1 需求判定** | 依据剧本、A11动作、A13七栏分镜、A15出镜需求，确认角色、服装版本和必要镜头面向 | 一张身份／LOOK／STATE最小卡，事实与美术提案分开 | 剧本冲突退S1/S3，镜头需求冲突退S4 |
| **R2 身份与造型设计** | 主角先锁脸；明确服装正背连接、发型后脑与体型；群演可在同一步完成选型 | 可复原的前／背设计；面部骨相清楚，无悬空背部结构 | 变脸退选脸；衣服背面矛盾退造型设计 |
| **R3 三联提示词编译** | 一次仅做一个角色、一个LOOK、一个STATE；固定16:9中灰三格；引用真实输入参考 | 一条四模块提示词，无多画幅、无三格歧义 | 文本冲突直接改本步 |
| **R4 出图与初选** | 保存实际使用的参考、模型入口、提示词版及候选文件；优先检查左／中／右三格任务 | 真实候选图片及引用记录；没文件不写已生成 | 不按三格／比例→重生，不能凭想象修补 |
| **R5 质量验收与局部修订** | 先查构图完整，再查三格同一身份、衣装与材质；明确最早错误来源 | QC通过／返工／缺证据判定，失败有位置和责任 | 骨相→R2；服饰→R2；排版→R3；模型偏差→R4 |
| **R6 版本锁定与交接** | 保存母版、实际分辨率、适用SH/GEN、资产局限、审稿人；关联T06 A16／A17 | 仅经审查的真实AST文件可申请T09 G5；没有权限者不自签 | 错绑定退S5-08；GEN表现问题转S6归因 |

**复杂角色可扩展步骤而不是拉长所有人的提示词**：化妆变化、战损、背面大型披风、双人同场近身或大量换装，另出状态卡、细节图和交互试镜计划。

## 05｜优化后的四模块图片提示词结构

1. **任务与版式**：单张16:9三联＋中灰背景＋真实定妆摄影；明确同一角色。  
2. **身份与造型**：骨相、前后发型、前后服装结构、材质与角色当前STATE；不堆砌性格标签。  
3. **三格摄影**：左正面全身、中背面全身、右45°头肩；两全身等尺度、自然站姿、头脚完整。  
4. **质量与禁止项**：柔和中性影棚光、皮肤／发丝／衣料真实性、8K细节目标、无多余人物文字或歧义构图。  

实际输入可直接合并为两段自然语言；四模块是审查结构，不属于图像模型官方语法。有真实图片时在模块二前加一句“参考图片1只承担身份参考”等，并说明优先级；**没有实际上传就删除该句**。

## 06｜完整可复制角色三联母稿（替换方括号）

```text
为AI仿真人短剧制作一张16:9横向三联角色定妆摄影表，三个面板展示同一位〔姓名／年龄阶段／身份／时代〕，采用统一的平整中性中灰影棚背景。真实影视人物定妆照片观感，柔和定向中性摄影光，三格肤色与服饰固有色一致。

角色身份固定为〔脸型、眉眼、鼻梁、唇下颌、发际线、体态〕；发型为〔正面及后脑结构〕；当前LOOK穿着〔服装内外层、主辅色、材质、前衣襟、后背闭合、腰带／腰封、下摆、鞋履与配饰数量〕；STATE为〔状态〕。面部自然平静，真实皮肤细节与发丝，服装重量、褶皱、缝合和反射自然。

左侧：〔姓名〕正面平视相机，身体正对镜头自然站立，双臂自然垂在身体两侧，头发顶部到双脚鞋底完整可见。中间：〔姓名〕保持完全相同的站姿和尺度，从真正背面观察，后脑勺及〔实际束发或发尾〕、后衣领、背幅、腰带／腰封、下摆及鞋跟清晰可辨，不能回头。右侧：〔姓名〕一幅放大的头肩近景，面部相对相机转向约45°的四分之三角度，正面五官与侧面骨相轮廓同时清楚可见。左中两格身高比例相近、边距充足，三个面板不交叠。

中性中灰背景、中性柔和真实摄影光，写实影视肤质、真实毛发与织物，8K ultra-detailed细节目标。禁止三格变成不同人物、换装、混入动作道具、正背姿态失配、裁头裁脚、右格变成正脸或全身、塑料蜡像感、油亮过曝、廉价CG低模、任何文字标签及水印。
```

## 07｜专业质量验收：先硬约束，再艺术质量

| 等级 | 具体可观察判据 | 不合格处理 |
|---|---|---|
| **L0画幅** | 实际图像宽高为16:9或经无损布局调整达到16:9；不允许其他比例充当正式三联 | R3/R4重做，不能直接提交4:3/9:16 |
| **L0视图** | 左正面完整全身、中背面完整全身、右45°头肩；不存在侧身回头、裁鞋、正脸替代 | R3/R4 |
| **L0身份一致** | 至少脸骨相、发际线、体态、发色、服装与头饰数目一致 | R2/R4 |
| **L0摄影状态** | 同一中灰摄影棚、三格同一中性光、自然站姿，角色不拿道具 | R3/R4 |
| **L1真实质感** | 皮肤不过亮不蜡化；发束体积与发丝方向自然；织物厚度/鞋/手清楚；无异常微纹 | R2材质定义或R4候选修订 |
| **L1可供后续使用** | 后背可在逻辑上还原前衣装，面部能与独立锁脸图核对；被分镜需要的特征可见 | R2补后背设计／调整分格 |
| **L2实测** | 用实际镜头首帧与视频检查不同角度身份稳定，存在真实截图/候选视频证据 | 未测试＝“未测试”，不可判动态一致性通过 |

## 08｜交付与变更边界

最小记录：`CHR-ID | LOOK | STATE | 三联16:9真实路径 | 输入参考真实路径 | 提示词版 | 实际像素 | QC | 适用SH/GEN | 负责人 | G5状态`。实际文件之前，只能登记候选提示词与待制作REQ，不得凭文本填AST已通过；正式G5必须在T09中审批。新增R1—R6和四模块只是**S5-03内部工作法**，不改变P2冻结候选的全流程编号及T06字段。

**来源与新增区分**：左正面／中背面／右45°及中灰摄影来自用户与上传角色三联规范；16:9唯一画幅来自本轮用户明确约束；身份、LOOK、STATE分层来自既有角色规范；六步合并、四模块提示词、质检优先级属于本次建议，尚待真实出图对照检验。
