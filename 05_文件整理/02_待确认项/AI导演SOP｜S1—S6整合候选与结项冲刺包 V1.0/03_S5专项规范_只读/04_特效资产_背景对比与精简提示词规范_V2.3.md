# S5扩展类目｜AI仿真人短剧特效资产：背景对比、设计流程与简洁提示词规范 V2.3

> 文档属性：特效资产候选专项修订／待审，非正式新增S5步骤。特效FX作为A16资产需求及S5-07/08验收移交的扩展类别，需与既有S5-05道具及T06/T09对应，不创建S5-09或A23。参考上一版《特效资产效果母版与阶段分解规范V2.0》及用户最新要求。  
> **本轮明确硬约束：特效背景不能与特效本身的颜色或亮度过于接近，必须清楚看出轮廓、边界与体积。特效画幅和机位按实际形态选，不固定比例，也不强制固定中灰底。**

## 01｜原有问题及修订

| 旧版问题 | 风险 | 修订结果 |
|---|---|---|
| 纯特效统一中灰背景 | 灰烟、灰白冲击波、浅色半透明效果可能与背景混成一团 | **以主体可读性为第一优先**，按主辅色和明度选择对比背景；中灰只在适用时使用 |
| 九步流程与七段提示词 | 普通火焰或一团烟雾也需要过度记录阶段、尺度与来源，制作繁琐 | **四步基础流程＋三模块提示词**；特殊效果再补运动、交互资料 |
| 每个效果预设多个阶段图 | 小型环境光、静态光雾可能不需要启动/爆发/消散系列 | 母版必选；有明确时间变化的才做阶段组 |
| 默认16:9 | 球形护盾、长条电流、竖向火柱不能得到合适构图 | 画幅和摄影观察角度根据实际效果轮廓和用途决定；每次任务写定一个比例即可 |
| “灰底PNG”被视作合成成品 | 灰色残边、半透明部分无法无损叠到视频 | 纯审阅背景与正式透明Alpha/遮罩分开建档、分别实测 |
| 用“炫酷、高能、8K”堆质量词 | 过曝、光片、随机粒子抢画面 | 用可见形态、光强分区、源头与方向控制质量 |

**不把特效资产复杂化**：普通视觉效果只需“是什么、长什么样、怎么呈现”三个问题。只有影响人物、场景、道具或具有关键持续动作的FX才增设交互时序卡。

## 02｜背景对比的固定规则

**背景选择顺序：先判断特效主体的主色、明度和透明程度，再确定背景。** 背景不必用同一套色板，但必须简洁、均匀、不抢主体，尤其不能让主体消失在相近色块中。仅改变背景预览颜色不会改变特效固有主色。

| 效果主体 | 建议审阅背景 | 必须避免 |
|---|---|---|
| 白色／浅金色／浅蓝高亮能量 | 深灰、深石板灰或其他低饱和深色 | 白底、浅灰高亮底、过曝白片 |
| 黑雾／深灰烟尘／暗影 | 浅中性灰、很浅的暖灰等浅色背景 | 黑底、炭黑底、与烟同深度的中灰 |
| 蓝色、紫色电弧／护盾 | 与蓝紫色明显区分、亮度适中的中性灰或低饱和暖灰 | 同色蓝紫、过度鲜艳互补色导致严重色污染 |
| 红色／橙色火焰 | 深中性灰或低饱和冷灰，保证黄色焰核与暗红外缘都可见 | 与火焰相近的暖红橙底、让暗边完全丢失的纯黑 |
| 半透明灰白气浪、薄膜护盾 | 用浅/深两种简洁中性背景分别检验；最终选择更易读的一种作为主图 | 只在一个接近同色的灰底上判断透明边缘 |
| 多色粒子或彩色效果 | 选择低饱和、亮度适中的非主色背景；避免与任何主要能量区域同色 | 斑驳彩底、多层光圈以及与主体混色的花纹底 |

### 最低可观察标准

1. 缩略图大小仍可辨认主体外轮廓，不与背景融成一片。  
2. 特效亮部与暗部都保留可见细节：不能只有高亮白核，也不能暗边完全变黑。  
3. 发光、烟雾或护盾的**半透明边界**在背景前仍可观察；必要时再用另一张深/浅背景进行技术预检。  
4. 背景为均匀单色或缓慢明度过渡，**不包含人物、完整场景、装饰图标、文字、水印**；只有单独的“场景交互验证图”允许出现剧情环境。  
5. 同一FX-ID的不同阶段应优先保持一致的审阅底色，便于比较；若因颜色/亮度变化必须更换背景，应在文件记录中说明，不能把背景颜色变化误判为特效本身变色。

**背景强度不是靠“颜色不同”四字自动保证**：黄色效果放浅蓝色背景仍可能亮度接近而看不清；应综合色相、明度与透明边界判定。不要为追求对比使用刺眼彩色底。中灰不是禁用色，只是**有条件的选择**。

## 03｜画幅、观察角度和资产类型

- **画幅**：不设统一硬性比例；根据整体轮廓与实际图像入口，选择一个本次真实可输出的比例。短宽冲击／横向电脉冲可横幅，球形护盾可方幅，竖直火柱可竖幅；不要拉伸效果去适应画布。
- **角度**：根据效果本体选择能看清立体结构的最佳方向，约45°仅在球形、半球形或体积复杂效果有帮助时采用，不机械沿用道具资产的45°要求。
- **纯母版 FX-A**：一个FX核心形态、一个阶段、一张清楚的对比背景；无人物、无场景、无实际武器本体。
- **状态组 FX-B（有剧情需求才做）**：启动、主峰/维持、消散中选实际需要的阶段；每张图只表现一个明确时点。
- **交互图 FX-C（需要与实体接触时才做）**：可见人物/武器/场景，目的是检验位置、遮挡、相对尺度、接触点，**不是纯特效母版**。
- **合成图层 FX-D（真有后期需求时）**：真实Alpha、蒙版或其他分层，需要实际像素与通道检验；**有背景的PNG不等于透明贴图**。

## 04｜四步最小流程（V1—V4，只在本专项内部使用）

| 步骤 | 关键判断和动作 | 最低交付／返工 |
|---|---|---|
| **V1 明确效果需求** | 从真实剧本和分镜提取是否必须出现FX、效果作用对象和时点；锁定基本形状、主辅色、来源 | FX最小设计卡；剧本没有的特效不强行新增 |
| **V2 选择背景和构图** | 按主色＋明度＋透明度挑对比背景；画幅和观察角度服务完整轮廓，提前排除同色灰底 | 一项确定画幅、一项确定背景及理由；看不清就先改背景或分布，不盲改FX主体 |
| **V3 编译短提示词并实际验收** | 三模块、单效果；生成候选后在正常及缩略尺寸核对轮廓、光强、层次、干净背景 | 真实FX-A图和审查记录；轮廓失效退V2，颜色/结构失效退V1 |
| **V4 按需派生并交接** | 若剧情需运动阶段／接触反馈／透明合成，则补FX-B/C/D；登记真实文件、来源、适用SH/GEN及限制 | 按A16引用真实资产；T09:G5仍需外部授权，不能以静态图宣称动态已验证 |

### FX最小设计卡

```text
FX-ID／名称：
出现原因与镜头：
主体形状／来源／运动方向：
主色、辅色和亮暗层次：
本次阶段：
本次画幅与视角：
本次背景颜色及选择理由（与FX轮廓对比）：
是否需要额外状态／交互／Alpha：
真实素材路径与审查状态：
```

## 05｜三模块精简提示词结构

| 模块 | 只写必要内容 | 一句话逻辑 |
|---|---|---|
| A **效果本体** | FX名称、源头、核心外形和主辅色 | “这是什么效果” |
| B **形态与阶段** | 体积、边缘、密度、扩展/消散方向，当前是哪一个时点 | “此时具体长什么样” |
| C **构图和背景** | 已选单一画幅、最佳机位、主色与背景有足够反差、真实光影、禁止项 | “如何展示清楚” |

**实际提示词只需1—2段，不用完整七段式。** 只有护盾碰撞、武器命中、复杂生物生长等涉及空间受力的效果，才补充位置、遮挡和接触原因等内容，不强迫普通烟雾也填物理公式。

## 06｜纯特效短提示词母稿（可直接复制填变量）

```text
制作AI仿真人短剧专用的〔特效名称〕纯特效母版，单个完整效果，当前处于〔启动/维持/主峰/消散的唯一阶段〕。主体为〔核心形状和层次〕，主色〔〕，辅色〔〕，来源位置〔〕，边缘呈〔半透明/火焰/烟雾/电弧的实际形态〕，朝〔方向〕自然延伸或扩散；真实影视特效视觉质感，体积清晰，高光不过曝，不增加无依据的烟尘和碎石。

采用〔已选择的唯一画幅〕、〔最有利于读出形态的观察角度〕；背景为〔确定的对比色和大致明度〕，与特效主要颜色和亮度形成清楚区分，使核心、轮廓、透明边缘同时可见。背景简洁均匀，无人物、完整场景、道具主体、文字、水印、低模游戏UI效果。画面仅呈现此时点的单一特效，不出现阶段拼贴。
```

## 07｜三种典型效果的完整执行示例（教学案例，不代表项目已有此FX）

### A. 深灰黑雾｜浅灰底，16:9

```text
一团从低处卷升并向右扩散的深灰黑色体积雾，外轮廓由稀薄灰雾和密度不同的暗色烟卷组成，中心灰黑、边缘半透明，只有一团烟雾，内部无角色或碎石，真实影视体积烟雾观感。

16:9横向构图，主体完整入画，均匀浅中性灰背景，背景明显浅于烟雾核心与边缘，让卷动层次和半透明薄雾可见。无人物、场景、标题、光圈、水印、塑料低模效果。
```

### B. 浅蓝白色半球护盾｜深灰底，1:1

```text
单个影视级薄层半球能量护盾的稳定状态，完整半球曲率可见，中心通透，浅蓝白色柔和能量沿边缘形成极细光带，表面仅保留少量有序微纹，轮廓体积自然，发光不过曝。

1:1方形构图，略高的45°观察方向，均匀深石板灰背景，使浅蓝白色护盾的半透明薄膜与边界清晰呈现。无人物、地面场景、说明字样、装饰套环、白色大片过曝及游戏UI图标感。
```

### C. 橘红火焰｜深冷灰底，9:16

```text
一束从明确底端火源向上延伸的橘红色真实火焰，底部亮黄色焰核、中部橘色焰舌、外缘暗红半透明，形态随自然上升气流伸展，火焰厚度、热量分布与发光层次写实，不出现无依据爆炸或黑烟云团。

9:16竖向构图，完整单束火焰置于低饱和深冷灰色均匀背景前，橘红外沿和黄色内核同时可读。无人物、道具本体、完整环境、文字、水印和卡通贴纸感。
```

## 08｜验收与最小返工

| 等级 | 具体证据 | 最早返工 |
|---|---|---|
| **L0背景对比** | 缩略图能辨轮廓；明暗主次和透明边缘不与背景同化；背景无彩色干扰 | V2优先换中性对比背景；不应先任意换特效主色 |
| **L0纯资产** | 单特效、单阶段、主体完整，无无关人物/物件/文字 | V3改任务与边界 |
| **L0身份颜色** | 主辅色、发光位置、几何中心、来源方向与FX设计卡一致 | V1/V3 |
| **L1电影质感** | 体积、渐变、颗粒与真实光效有层次，无过曝或廉价游戏UI低模 | V1改设计、V3调整表现 |
| **L1序列一致** | 如存在状态组，前后相位在形态、起点和颜色方面可解释 | V4／V1，不能用不相干图片冒充连贯 |
| **L2真正可制作** | 合成有真实Alpha／遮罩数据且边缘可用；视频动态有真实样片和动作反馈 | 未测就记未测；静态资产不等于真实动态通过 |

**失败归因**：黑雾贴黑底→先换浅中性灰；浅蓝护盾贴浅蓝底→先换深灰；主体虽然分色却同明度→增加明度差或简化背景；亮部糊团→控制核心亮度和面积；形态乱变→返回FX主档；后期灰边→检查真实Alpha而非继续堆提示词。

## 09｜与S5、S6的关系与审查状态

FX只是当前S5现有A16内的附加资产类型；道具实体形状由PROP主档负责，FX不能随意把武器、盒子、人物装备改形。与场景发生作用的特效，交互图要依赖同一SCN-GEO布局与主反机位。视频生成时由S6决定触发→变化→反馈→终止的时间顺序。当前文档与示例**未进行正式真实特效生产试验**，也不存在G5批准或S6动态验收记录；任何未来效果质量结论必须基于实际图片、图层与视频证据。

**来源与新增区分**：本轮“特效不强制比例与统一颜色背景、背景不得和主体同色”来自用户明确要求；FX分类与Alpha区别继承V2.0；四步生产、三模块短提示词和对比色审查表是本次项目方法修订建议。
