# S5-04／S5-06｜AI仿真人短剧场景资产：双画幅、正反打与提示词规范 V2.3

> 文档属性：专业场景设计与摄影参考专项修订，待审／待真实图片核验。基于《场景资产正反打与空间连续性V2.0》及上传的《海外AI仿真人短剧场景资产提示词结构与项目规范》修订。保留原S5-04（场景设计）及S5-06（机位派生），T06 A16/A17与T09 G5不变。  
> **本轮确认硬约束：场景主反打资产只允许16:9或21:9；每套主图A/反图B采用同一确定画幅；两张都是3/4对角线构图和轻微俯视角度；真实透视、同一空间、纯场景，无文字、人物、动物。**

## 01｜旧版问题分析与修订决定

| 原有问题 | 可能导致的生产错误 | V2.3修订 |
|---|---|---|
| 未锁定画幅 | “16:9或其他比例”容易让一个场景在不同镜头反复改变画幅 | **唯一可选16:9、21:9**；每个场景资产包先选一种，主反打保持同规格 |
| 没有说明何时选21:9 | 为追求“电影感”把所有房间盲目做成超宽 | 21:9仅在横向布局、全景空间或宽银幕视频方案有明确用途时使用；9:16短剧镜头优先考量裁切成本 |
| 七段模板过长且前置条款重复 | 多次叙述墙体/机位，出现背景和空间逻辑冲突 | 保留详细空间主档，**实际图片提示词压缩到五模块**，每张视图只有一个明确机位 |
| 主视图与反打图各自生成 | 两张“漂亮房间”却无法互相证明是一个建筑 | 先锁真实SCN-GEO世界布局，再由A/B共同派生；拒绝镜像反打 |
| “中性灰背景”表达容易歧义 | 把婚房内部、室外天空或原定服装陈设整体灰化 | 仅在场景被当作可见片场模型、布景资产陈列时设置中灰外部衬底；**完整真实室内外的画框以场景自身环境为背景**，不添加灰色墙幕或强制灰化世界 |
| “四层空间／空旷无垠”被机械套用 | 室内尺度被夸成无限大厅，甚至墙门缺失 | 四层指空间信息层次；“无垠”只用于真实开阔题材，封闭室内强调完整和合理留白 |
| 对21:9超宽输出和后期裁切缺检查 | 图像表面是宽银幕，但关键物件在9:16视频裁切时消失 | 额外执行**画幅—用途—裁切风险**检查；不将场景资产比例等同于视频最终比例 |
| 摄影机／胶片词当作真实设备 | 虚构8K文件、相机硬件或胶片冲洗证据 | `8K ultra-detailed／ARRI Alexa LF／Kodak Vision3 250D`仅为成像目标；真实像素另查文件 |

**核心原则：场景优先解决三维空间的真实性，提示词只是准确表达已经决定的空间与机位。** 摄影成像词不能修复错误的门窗方位、家具尺寸或人物动线。

## 02｜画幅选择标准：只允许16:9或21:9

| 比例 | 优先适用 | 避免采用的情形 | 正反打规则 |
|---|---|---|---|
| **16:9 横向** | 常规AI短剧场景、对话房间、角色移动路线、后续可能多端裁切；主次关系集中 | 如果场景长轴极长且主体两端必须同时呈现，可考虑21:9 | A/B均16:9；同一SCN-GEO、LOOK、STATE |
| **21:9 超宽横向** | 宽银幕空间参考、横向大跨度、壮阔外景、明确需要同时展示左右两端区域的复杂场面 | 最终主要是9:16人物近景、空间很窄、无横向叙事要求；超宽会导致有效像素浪费或竖裁重大损失 | A/B均21:9；不得仅把A图拉伸成宽画幅或镜像成B |

**作出单一选择**：同一场景主反打不能一张16:9、一张21:9并当作同版成对母图。如果确需两套比例，则登记为**独立的宽幅变体**，各自维持同一布局并分别生成、验收主反图；不能让模型在一条执行提示词里任选两个比例。

**9:16竖屏使用说明**：本规范的“场景资产图”仍固定16:9／21:9；视频镜头或首帧可能是9:16，需单独在S4/S6确定实际9:16取景区域，检查门、床、人物动线和轴线是否可在竖裁后成立。尤其21:9→9:16裁切会损失大量左右画面，不能仅靠缩放保证场景有效；需要时另做竖屏首帧，不将其登记为本类正式场景主反资产。

**技术核验**：若模型当前不直接输出21:9，应以可靠的画布扩展／重新构图方式制作真实21:9文件，再核对像素宽高及内容是否遭裁断/拉伸；未经核验不得标注正式21:9资产。

## 03｜主反打共同依据：SCN-GEO几何主档

在任何出图之前，需要一张可审阅的**空间描述卡**，至少记录：

```text
场景ID／名称／时代／日夜：
画幅选定：16:9 或 21:9（实际只留一个）
场景范围与边界：
世界方向：北/南/东/西，或者固定参考地标
门/窗/开口：数量、墙面位置、开合及对外可见性
床、桌、柜、通道：世界位置、朝向、相对尺度、连接关系
灯具及自然光源：固定世界位置与照射方向
角色行走路线、对手戏轴线和可使用空间：
STATE：场次时点，门开闭与陈设状态
A机位世界位置／朝向／俯角：
B机位世界位置／朝向／俯角：
两机位共享的可识别地标（至少2项）：
来源事实/推断/提案/未知及待确认：
```

**方位优先于画面左右**：A机位画面左侧的门，在B机位不一定出现在画面左侧；门只允许固定于它在真实场景中的墙面位置。B机位不是A图的水平翻转，也不是交换两侧的家具。先有空间布局才允许展开摄影视角。

**正反图与人物摄影轴线区分**：SCN-A/B是两张用于认识空间的相反观察图，它们不自动构成可直接剪辑的演员正反打。演员镜头的180°轴线、眼线、跨GEN首尾必须依据S3/A11和S4镜头设计再确认。跨GEN相邻视频最后／最初镜头采用确实不同机位，不能以重复同一位置但缩小画幅代替；同时保持人物世界位置和动作状态连续。

## 04｜四层纵深、主体留白与场景摄影要求

| 层次 | 室内示例 | 室外示例 | 质检重点 |
|---|---|---|---|
| L1 近前引导 | 门框边缘、床柱、前景地板 | 道路近端、前景植被 | 引导视觉，不能挡住主体结构 |
| L2 主要剧情／活动层 | 对话区、婚床或桌案 | 人物预定行动范围、核心建筑 | 最可读，站位与路径有效 |
| L3 空间关系层 | 后墙、另一组家具、窗与通路 | 中景建筑、院墙、坡地 | A/B交叉复核地标的主要层 |
| L4 远层／空间界面 | 最远墙、远处开口或真实纵深终点 | 地平线、山体、空气透视 | 合理解释空间尺度；室内不凭空无边界 |

**构图硬条件**：主要场景结构完整置于画布内，关键物件保留四周均衡视觉边距；透视线自然，家具与门窗尺度吻合，不出现墙面穿插、家具悬浮或地板奇异拉伸。为后期字幕和平台UI留出合适的安全区域，**图片本身不产生任何文字、标签或字幕**；真正安全区应基于目标成片画幅与平台实测，而不是在场景资产里机械挖空固定百分比。

**固定摄影角度**：SCN-A/B均为**四分之三对角线观察、轻微俯视**。相机在可物理放置的位置看向重要场景主体，略高于主体或人物预定眼平线，温和下俯；避免顶视、极端高机位、广角畸变、正对平板墙的无深度景片。机位角度约束的是**观察方向**，不能要求两张图都无条件看到同一墙面全部细节。

**摄影观感**：`8K ultra-detailed；ARRI Alexa LF电影摄影机成像观感；Kodak Vision3 250D胶片质感；轻微胶片颗粒；自然且可控的高光溢出`。这组是项目希望模仿的摄影审美，不证明真实使用摄影机或胶片，也不能令夜间室内被错误改为日光。材质应有自然反射、接触阴影和合理使用痕迹，避免低模/塑料/过度锐化/Q版/不适用的现代物件。真实像素以生成文件元数据核验。

**“中性灰背景”的使用边界**：如生成的是“单独布景模型／沙盘展示图”，可在场景边界外使用中灰无缝衬底；如生成的是完整房间或广阔外景图片，则背景就是**真实房间、墙面、天空与环境**，无需附加灰色幕布，固有色与时代不得被改写。为避免冲突，实际提示词需要明确本次是“实景全画幅”还是“场景布景展示”，只选一种。

## 05｜七步主流程（E1—E7，为S5-04/06内部流程）

| 步骤 | 操作任务 | 最小产出 | 不通过时回退 |
|---|---|---|---|
| **E1 读取剧情和镜头用途** | 确认时代/地点/时段、角色行动、场景必要开口；依据最终视频用途从16:9／21:9选择唯一比例 | 场景REQ与画幅决定 | 无法确认剧本事实退S1/S3；不明用途标U |
| **E2 锁定真实几何** | 确定世界方向、边界、门窗、固定家具和通道，不以画面坐标代替世界坐标 | SCN-GEO版 | 空间逻辑不可能→退S3动作构思或重做几何 |
| **E3 锁定材质、光线及状态** | 场景建筑形制、材质固有色、光源世界位置、日夜、道具开闭与布置 | SCN-LOOK／STATE版 | 时代错误或光源不合原场次退本步 |
| **E4 确定A/B真实机位与构图** | 主/反采用不同对角角落或其他可放置机位，均3/4轻俯；四层纵深、关键主体、字幕与裁切余量；核对演员轴线 | CAM-A、CAM-B与共通地标 | 视图不成立→调整机位；动线不成立→E2/S3 |
| **E5 编译两条提示词** | 保持同一SCN-GEO/LOOK/STATE与已选画幅；仅改变可见面和相机位置；写入五模块 | A提示词和B提示词各一份 | 模糊“从任意方向”或多画幅→重写 |
| **E6 生成、对照与修订** | 保存真实参考及候选；A/B与布局三方比对门窗/家具/光源/透视，先空间再美术；不合格按最早根因返工 | A/B真实图片候选、QC记录与修订差异 | A和B不是同一房间→E2/E4/E5而非增加“高质量”词 |
| **E7 锁版、验证和交接** | 按SCN-ID／GEO／CAM／STATE记录真实图、文件比例及实际尺寸、适用SH/GEN、限制；为竖屏首帧另安排裁切或派生验证 | 仅可审核通过的真实资产登记T06 A16并申请G5 | 未通过G5不作为已准入S6素材 |

**复杂空间不因流程缩短而省略E2和E4**：楼梯、仓库、狭长房间、多门、跨房间通道、床桌近身动作，都必须有可信拓扑图或文字坐标。在没有几何主档的情况下，生成更多华丽图像不等于推进制作。

## 06｜五模块简洁场景提示词结构

1. **场景身份**：名称、年代、日夜、主反图用途、唯一画幅。  
2. **固定空间及陈设**：核心建筑、门窗、床桌、通路和状态，按世界位置写。  
3. **机位与四层**：本张A或B的方位、朝向、3/4轻俯、实际可见面、纵深层与安全留白。  
4. **材质光照与电影成像**：真实固有色、光源位置、ARRI/Kodak外观、轻微颗粒、可控高光和8K细节目标。  
5. **连续性与禁项**：共享同一空间，A/B非镜像，无文字人物动物、无现代乱入、无塑料低模。  

**五模块用于审阅；实际提示词可以写成4—6段自然语言，不需要强制七个标题。** 对B图若有真实已上传A图和空间示意，可以加一句明确“哪张图锁定建筑，哪张图锁定布局”；没有实际上传则不能声称“基于图片1”。

## 07｜可直接复制：主视A／反打B提示词母版

### A｜主视图（将〔画幅〕替换为16:9或21:9中唯一值）

```text
为AI仿真人短剧制作〔SCN-ID〕〔地点、时代、日夜〕的纯场景主观察图A，输出一张〔已选定的16:9或21:9唯一画幅〕横向图，真实古装影视实景摄影观感，不出现人物或动物。

同一场景的真实世界布局为〔房间边界及世界方位〕；〔门/窗/通道〕位于〔固定位置〕；主要〔床/桌/柜/建筑〕位于〔位置〕，朝向〔方向〕，当前开合与陈设STATE为〔〕。建筑材质为〔〕，家具织物材质为〔〕，光源实体位于〔位置〕，阴影方向合理，透视准确。

A摄影机位于〔世界方位/可放置角落〕，朝向〔主体〕，四分之三3/4对角线构图，轻微俯视；实际画面主要看到〔墙面、家具表面、通道〕。层次为L1近前引导〔〕、L2主体动作区〔〕、L3背景关系〔〕、L4远处环境或封闭空间终点〔〕。关键主体完整入画，四周留白均衡，预留未来字幕安全区但本图绝不显示字幕。

8K ultra-detailed细节目标，ARRI Alexa LF电影摄影机成像观感，Kodak Vision3 250D胶片质感，轻微胶片颗粒，自然可控的高光过渡与少量溢出，真实木、石、织物或金属材质，不做塑料磨皮或网游CG。图片呈现〔完整真实实景画框／布景模型外部中灰衬底；只选一种〕，不改变场景内部材质固有色。

纯视觉图，无文字、人物、动物、叠加字幕、标签、水印、无依据现代物件；不夸大封闭空间成无边厅堂，不出现透视错乱、结构漂移、家具悬浮、Q版和低模感。
```

### B｜反打图（与A同画幅，仅改变摄影位置）

```text
为同一〔SCN-ID〕制作纯场景反观察图B，画幅与A图完全一致，为〔已锁定16:9或21:9的唯一值〕，建筑及陈设仍是同一空间。空间基线〔SCN-GEO版本〕不变：〔门/窗/床/桌/通道和各自世界位置、朝向〕。场景时段〔〕，光源世界位置〔〕，固有色、材料、开合状态与A图相同。

B摄影机位于〔与A不同的真实可放置对角方位〕，朝向〔观察对象〕，仍采用四分之三3/4对角线构图和轻微俯视，主要显示〔反方向可见墙面、家具背面及通道〕。至少能与A图共同核对的固定地标为〔地标1〕和〔地标2〕。不水平镜像A图，不将门、窗、床头、家具或光源换到其他世界位置。

组织L1〔〕、L2〔〕、L3〔〕、L4〔〕四层空间，核心场景完整置于画框内，边距均衡，给后续字幕/界面保留适当空间而不显示任何文字。场景仍为〔完整真实实景画框／布景模型外部中灰衬底，只选一种〕，真实环境内部颜色不强制变灰。

8K ultra-detailed细节目标，ARRI Alexa LF成像观感，Kodak Vision3 250D胶片质感，轻微颗粒、自然高光溢出，材质写实。无人物、动物、文字、字幕、现代乱入、CG低模、塑料感、Q版和透视错误；主反图的几何、光线和剧情状态必须连续。
```

**使用要求**：提示词中“已选定的16:9或21:9唯一画幅”是**待替换占位语**，最终投入模型的执行稿中必须写一个确定值，例如“16:9横向”。“完整真实实景画框／布景模型外部中灰衬底”同样必须择一；不得把括号和备选一起投喂模型。

### 两种画幅的可复制锁定句

```text
16:9选型：输出唯一16:9横向画幅，完整呈现同一场景主次结构与稳定空间纵深，主体在未来人物镜头裁切后仍可识别。
```

```text
21:9选型：输出唯一21:9超宽横向画幅，保留场景横向跨度、左右两端关键地标与完整纵深，不拉伸、不镜像、不无依据增加建筑开口。
```

## 08｜正反打检查卡与返工规则

| 项目 | 通过条件 | 缺陷优先回退 |
|---|---|---|
| **L0双画幅** | A/B同为16:9或同为21:9，实际文件比例可核对 | E1/E5/E6 |
| **L0机位** | 两张均3/4轻俯，真实不同观察方位，非水平镜像，不撞进墙或柜 | E4/E5 |
| **L0空间连续** | 门、窗、床桌家具数目、世界位置、方向、真实尺度及光源位置对得上 | E2/E3/E6 |
| **L0纯场景** | 全画框没有人物、动物、文字、字幕、标注、随机现代物件 | E5/E6 |
| **L0安全构图** | 主体完整、边距足、至少两项可互证地标，四层纵深有物理解释 | E4/E6 |
