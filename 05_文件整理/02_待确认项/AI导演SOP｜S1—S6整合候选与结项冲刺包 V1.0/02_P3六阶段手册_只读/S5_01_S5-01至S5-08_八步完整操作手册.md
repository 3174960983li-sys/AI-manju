# P3-S5｜八项正式工作步骤操作手册（集成版 V1.0）

> **编号不变**：S5-01至S5-08严格沿用P2-01及T06。此文件把新收到的四类美术规范V2.0作为生产工艺**候选实现**；不自动变更P2-V1.1-RC1的生效权限。不单独增加S5-09特效步骤，FX作为A16类别归入相关设计及核验。G1—G6只有T09有授权效力。

## 统一输入—输出—工作门

**权威输入**：A02有效文学版本与项目约束；A05风险复用；A06/A07视觉风格；A11世界空间、人物起尾、动作链；A12机位；A13含时码与原句的七栏分镜；A15可见资产及视角需求。A14只在声音强依赖时参与状态检查。可先做带U的需求研究，但正式冻结和G5须按T09查上游G1—G4授权。

**权威输出**：T06:A16-1(REQ需求)、A17(S5-03~06资产制作方法及尚缺实际文件的透明登记)、A16-2(真实AST)、A16-3(逐GEN绑定)；T09:G5（仅签核者可批准）。S6以A18区分GEN，A19编译文本不代替真实素材。不得把拟命名文件当已上传真实输入。

**证据等级**：E0来源与文本结构核验；E1真实候选图片视觉、几何、分辨率元数据与入口静态绑定试验；E2真实视频动态连续性及可用性。L0为硬性契约和拓扑，L1为专业美术质感及可读性，L2为实际镜头测试。角色头像优美不代表A16已闭合。

## S5-01｜建立资产需求

**目标**：把已确认的镜头需要转成明确、可追踪、最少可完成的REQ，而不是把剧本出现的所有物体都做成单体三视图。

**前置**：可辨认A13/A15、A05、A07与G4状态；A13尚未正式批时只允许`预检需求`。

**执行**：
1. 逐SH抄录可见主体及近景要求；把“谁出镜、是否背身、要不要表情”“房间正反需要看到哪面墙”“碰到哪里、物件何种状态”“需要独立特效吗”拆成不同需求。
2. 将共用同一身份、LOOK、STATE、SCN-GEO的镜头并需求；视角、剧情状态不一致则建附需求，不另造同一个角色ID。
3. 每条REQ写：复合SH ID、GEN候选、资产分类、镜头必需性、需看到的结构/动作部位、世界方向与状态、来源F/I/H/U、优先级、责任、验收条件、证据缺口。
4. 与S4负责人核对：每项镜头必需REF能否由已有角色三联、场景主反及道具45°图支撑？不支持时标附加视角/首帧，不能默默删除镜头。

**交付**：A16-1；A17待专项/方法接收标记。**L0**：所有必需SH均覆盖；无`REQ`不能冒用`AST`。**L1**：最小生产集兼顾复用与实际镜头角度。**L2**：无图未实测。**回退**：戏情事实错误→S1；机位/动作需求错误→S3/S4；分类错误→S5-01。

## S5-02｜识别复用与优先级

**目标**：优先投入对多个镜头有效或对接触/口型/空间安全关键的资产。

**前置**：A16-1初稿、A05风险清单。

**执行**：
1. 先标P0（阻断关键GEN）、P1（当前段必要但可排期）、P2（延后且不影响本次范围）；这些优先级是本手册工作标签，不增P2正式对象。
2. 建共享依赖图：一个CHR身份可能多个LOOK；一套婚房SCN-GEO映射多机位；同床柱近景可以复用同一PROP；FX只在明确剧本/镜头需要时出现。
3. 估计某REQ缺失对哪些SH/GEN构成阻断；一项REQ复用于多个GEN时，优先审查母版的身份/几何真实性。
4. 将能不用额外制作的资产标记“有实际文件待验”或“现有设计文稿可继承，但没有真实图片”，二者不能混写。

**交付**：A16-1优先/复用备注。**L0**：P0确有SH/GEN支持；**L1**：不因精细装饰挤占动作视角；**L2**：真实节省工时待收集。**回退**：需求错误回S5-01。

## S5-03｜角色资产与状态变体

**目标**：生成可复用的真实人物身份与服装母版；本次接入`01_角色资产...V2.0`，不代替原步骤。

**前置**：角色身份/年龄与改编边界已区分F/H/U；A06/A07视觉方向；A11动作侧别；A13露脸与背影/接触需求。

**执行**：
1. 给同一人物建`CHR-ID`，把脸/发际线/骨相/体态独立于婚服`LOOK`和已经发生的`STATE`；原文未定外貌仅记待审提案。
2. 对有正脸的主要人物先生成**正面脸部选型母版**候选；核对五官比例后锁定身份，不把没有审核的漂亮图当锁脸资产。
3. 明确服装正反面结构（领口、束带、腰封、衣摆、鞋、束发后脑），不可凭一句“豪华红婚服”要求前后必然一致。
4. 以固定七段正文及摄影开头/结尾生成16:9三联：左正面全身，中背面全身，右45°头肩；中性灰影棚；左右身高接近，不裁鞋，面部不过度磨皮。
5. 对SH确实要求的盖头已揭、衣襟皱褶、受伤、湿发等变化生成另一个STATE，并登记起止SH；不能把脸表情和剧情动作画进固定身份母版。
6. 真正需要近距离肩部接触、正侧身或推开时，只按已批A11/A13派生特定视角或非性化动作参考，不能让三联图取代动态可达性验证。

**交付**：候选图+参考职责+版本链，经真实审查后登记A16-2；未出图只保留A17待提交。**L0**：三格顺序/姿态/角度/身份/LOOK一致；**L1**：皮肤、发丝、服装、手脚真实；**L2**：真实视频身份漂移仍待测试。**回退**：同脸错误退选脸，背部服装错退LOOK，状态漂移退STATE，动作不合理退S3。

## S5-04｜场景母版与空间锚点

**目标**：先锁唯一可解释的SCN-GEO，之后才能制作主反图；本次接入`02_场景资产...V2.0`。

**前置**：A11世界空间、A07年代视觉锚与A16-1需求。

**执行**：
1. 固定世界坐标/至少两个稳定地标，明示门、床、窗、供桌、走道、烛台的数量、方位、朝向及可动/不可动性；剧本未给的尺寸与墙向标H待批。
2. 画可审查的平面拓扑（文本方位图或草图），标角色站位/通道/接触可达区域；检查床柱是不是可以被手碰到、主反相机有没有占据实体家具。
3. 锁`SCN-GEO`和`SCN-LOOK`两个版本：几何/固定陈设一套，材料色彩/光源位置另一套。
4. 审查四层：L1引导前景、L2动作区、L3家具与关系、L4真实空间终点；为平台字幕安全区留视觉余量，但成图绝不放文字。
5. 中灰只在**资产展示可见的布景轮廓之外**做中性背景；完整室内仍保持真实婚房红布、木材与烛火固有色。必要时拆分“展台式空间资产图”与“全画幅镜头场景参考”，不将互相冲突要求硬塞一图。
6. 写场景A主观察角候选，机位为3/4对角轻俯；场景主体完整入画、透视自然、前后层次可读，风格词不作8K/真实摄影设备承诺。

**交付**：SCN-GEO/LOOK文字主档及A候选，真实图存在后A16-2可填AST。**L0**：空间地标可解释、主光有来源；**L1**：材质/胶片感可读不过曝；**L2**：与真实角色站位可达性的实测待执行。**回退**：世界布局错退S3-A11或本步几何，光材错退LOOK。

## S5-05｜道具及状态变体（兼管按镜头需要的纯FX）

**目标**：保证角色能拿、推、打开或依靠的物件具有可识别结构与正确尺寸；本次接入`03_道具资产...V2.0`，FX依据`04_特效资产...V2.0`作为A16扩展类别。

**前置**：A11抓点/受力/结果、A13道具可见镜头与A16-1。

**执行**：
1. 区分“房间不可移动结构的一部分”（例如固定婚床床柱，优先归SCN/必要时建立关键结构细节PROP）与“可持取的独立道具”（例如红盖头），确定单一外观权威母版，避免双系统重设计。
2. 每个关键物件登记功能、材料、长宽厚级别、部件连接、正背识别面、可接触位置、使用顺序和剧情STATE。
3. 单件纯道具主图为45°摆拍、中性灰无缝背景、完整轮廓；随需要补正/背/内部、盖合状态或与手接触参考，不强行让普通装饰件拥有三视。
4. FX仅当A13需要独立可见效果时添加`REQ-FX`，先定触发事件、作用点、形态/色彩、阶段、衰减；中灰图不是Alpha透明素材。1-1昏迷并不需要凭空加雷电特效。
5. 对照A11接触点审查：尺寸是否允许指定人手抓握，柔性布如何自然褶皱，床架/盖头与人物位置是否矛盾。

**交付**：PROP/FX候选、STATE链及真实图到来后的A16-2记录。**L0**：45°/中灰/部件可复原，FX有故事依据；**L1**：材质、重量感、纹样可信；**L2**：实拍式接触/特效时序尚需S6验证。**回退**：构造错退道具主档，抓点错退S3-A11或S5-05，特效无源退S4需求。

## S5-06｜镜头所需视角参考

**目标**：补齐与S4机位/跨GEN尾首不同机位实际相关的视图，而非同一张图片翻转。

**前置**：S5-04世界几何与A12/A13/A15的摄影需求；对话摄影轴线或接触动作轴线由S3/S4先定。

**执行**：
1. 确定A机位在世界坐标的准确相对位置、观察对象、可见墙体；B机位从另一真实对角方向反看，两张图**都保持3/4轻俯**，主反结构不能镜像。
2. 在SCN-GEO文字与已选A真图基础上派生B（若尚未生成A，B只能写模板）；逐项确认门窗、床头/床柱、灯位、物件数量、相对尺寸一致。
3. 另列S4实际需要的镜头级首帧或特殊角度需求，不把场景主反图直接等同于电影正反打的最终可切机位——镜头轴线可能限制使用角度。
4. 对每个跨GEN边界写**末镜机位世界位置/方向**、**下GEN首镜机位世界位置/方向**、两个共同地标、动作尾态→首态、服装/道具/光向以及剪接风险；只是换焦距/画面左右镜像均不算不同机位。
5. 如实标注真正不存在的镜头角度/图片，增加REQ-ANGLE，不写假AST。

**交付**：CAM-A/B、特殊视角需求，A16-1和真实文件到来后的A16-2/3。**L0**：同一SCN-GEO+机位真不同+不越轴；**L1**：人物未来动作可读；**L2**：跨GEN真实视频尚需逐帧比对。**回退**：机位与几何冲突退S4或S5-04；衔接行为冲突退S3/S4。

## S5-07｜视觉一致性核验

**目标**：根据**真实图片像素和输入来源**逐项判定资产是否可用，而不是仅凭完备的提示词和命名。

**前置**：存在可读取的候选图及其来源；如无文件只能做条款预检并标未核验。

**执行**：
1. L0硬检：角色三格及45°、场景双图同空间/3⁄4轻俯/纯场景、道具45°、特效纯主体，角色/场景/道具/FX中灰规则是否符合各自定义。
2. 与A07核对时代及材质（架空明中后期，不混清制/现代物）；与A11核对床、盖头、接触点及状态链；与A13/A15核对镜头需要的侧别、视角、安全区。
3. L1专业审查：发丝、皮肤、织纹、木纹、反射、自然高光、胶片颗粒、四层和透视；检查场景主体是否因为追求“空旷无垠”变成不合逻辑巨大房间。
4. 建图像证据：图片路径、实际分辨率、参考图片与提示词版本、截图/抽检点、问题ID、复核者及复核日期；同一版本不得只复核A图而跳过B图。
5. 按错误根因决定**局部重生/退回几何/退回角色LOOK/修改S4**，不能把S6视频失败统统归给图像，也不能用负面词掩盖错误结构。

**交付**：A16资产与SHOT适配核验结果及明确不合格/未测原因。**L0/L1**：逐图真实审查才有通过意义；**L2**：S6生成观察结果回写但不能替代G5准入。**回退**：本步记录指向真实错误源。

## S5-08｜锁定可引用资产并移交S6

**目标**：让S6知道每个GEN实际使用什么媒体文件、哪个版本、支持哪些SH以及其输入能力是否存在。

**前置**：S5-07真实核验、指定GEN必需REQ闭合、适用的G4确认。

**执行**：
1. **只为真实存在**的候选图建立AST-ID并记录可访问文件位置、文件hash、画幅分辨率、ID/LOOK/GEO/STATE/PHASE、设计与QC状态；预测名字写在REQ备注，不能放实际文件栏。
2. 在A16-2中逐REQ列真实文件版本与适用镜头，核对未绑定的关键参考（含床侧真实3/4和关键手部图）。一个REQ可由多个AST支持，同一AST可按审查范围支持多个REQ。
3. 在A16-3中逐`GEN→SH→REQ→AST/版本→模型入口实际绑定方式`建闭合表；入口不支持多参考时，必须真实试验替代方案并记录，不得假设平台能同时传三联+主反+道具。
4. 查T09 G5授权**只对特定GEN及必需参考集合快照生效**。G5未知/待核查时只能继续准备和预编译，不能宣布正式生成已放行。
5. 将资产状态、镜头起尾态和跨GEN不同机位信息交给S6 A18/A19/A20；留版本追踪入口，收到E2视频后把真实问题反馈S5或S3/S4。

**交付**：可审A16-2/3与T09申请材料（不私自签G5）。**L0**：路径真实、版本匹配、必要集合无空缺；**L1**：输入组合与视觉目标相容；**L2**：模型能否稳定执行仍由S6试镜/验收证明。**回退**：文件不符S5-07，视频入口绑定不支持回S5-08/S6-02，世界/动作源错误回S3/S4。

## 三个必须显式声明的例外

1. **FX不自动必需**：若剧本没有独立效果，A16记录“本GEN无FX需求（待G4核）”，而不是建一个不存在的FX素材；仍不等于该GEN其他REQ已闭合。
2. **真实夜内场景的灰底**：灰底规则只适用于场景资产展示外衬区域，不得把真实房内红婚服/红帐/木床改灰。未来视频首帧应遵循镜头内真实空间而非摄影棚背景。
3. **G5与实测边界**：G5是**单GEN真实引用准入**；E2视频质量属于G6，不允许以本册的文档检查代替真实审核。
