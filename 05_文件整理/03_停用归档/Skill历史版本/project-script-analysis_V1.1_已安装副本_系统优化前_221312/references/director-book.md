# 单份导演本的编排结构

这是输出结构，不是要求用户先填写的问卷。最终交付可编辑Word文档，先在聊天中完成项目理解与关键问题交流，讨论方向后完善成册。对简单项目简写；长剧使用清楚的标题层级和目录，不把整部原文压缩成摘要冒充完整导演本。

## 文档头

作品名、导演本当前版本／状态、依据剧本版本、本次实际覆盖集场、尚未覆盖范围。写清本文件是制作解读，原剧本是否含未确认修订；默认不改原稿。

Word编排：使用实际标题样式组织项目／集／场，便于导航和目录；原剧本与导演处理用明确标签和段落样式区分，不仅靠颜色。按项目长度使用必要分页、页码、清楚的表头和可打印字号；避免表格超出页面、标题孤悬或把整场正文塞入狭窄表格。实际生成时按文档制作Skill完成渲染和视觉核对，不能把Skill结构校验当作文档排版验收。

内部中间稿不作为第二份当前导演本公开维护。接收Word批注后核对版本再修改，避免用旧中间稿覆盖用户批注。未实际生成.docx时，只称文字草稿，不声称已交付Word。

## 一、项目定位与要求

用途、作品类型、题材、受众、横竖屏、时长／集数、期限、已确认限制。用户偏好和工具／预算条件按已知记录，未知事项集中列出，不在每页重复“待定”。

## 二、故事大纲与理解

原故事概述、主线／重要支线、人物目标与冲突、转折和结束状态；连续剧给分集大纲及承接。主题、情绪体验和导演解读与事实区分。

## 三、时代背景与世界约束

时间地点、历史／现实／架空属性、影响制作的服化道和风俗、允许的艺术改动；给实际出处与待考项。正文写可用结论，详细来源可放文末。

## 四、人物小传与关系

主角和重要配角：身份与经历、目标与关系、性格通过何种行为体现、知识变化和弧线、必要外形／声音要求。其他角色按功能简写。推断和新增经历明确标识，未确定外貌不写成已锁定演员设定。

重要性格判断补关键选择的场次依据、知情范围与代价；区分观众逐渐认识人物和人物自身发生变化。没有足够前后材料就标待判断，不机械填写成长弧线。相关内容直接写入小传或逐场处理，不再要求独立长表。

## 五、导演、画面风格与制作路线候选

结合用户偏好提出少量组合，说明参考作品／导演借用维度、具体处理、制作影响与取舍，给推荐。选定后该段记录采用方向及仍待验证内容；未采用方案简短留存，不与采用版混用。

## 六、逐集逐场导演本正文

每集先用一小段写本集目标、剧情变化和承接。每场按下列结构：

```text
第X集／原场号／原场标题（无场号则注明整理场号）

场景：地点、内外、时间；缺失处明确，推断与原文分开。
出场角色：实际出现／参与声音的角色；有需要时注明画外、被提及不出场。
使用及关键道具：名称、用途、必要起止状态；无则明确说明。
必要连续性提醒：只写本场真正关键的造型、伤势、持物、空间等。

【原剧本】
保留当前有效版本的原文顺序与措辞，不把摘要当完整正文。

【本场导演处理要点·提案或已确认】
本场作用与开始→结束变化。
角色目的、策略变化及关键表演触发。
观众需理解／暂时不知道的信息。
空间、声音、节奏和视觉处理原则；不展开逐镜分镜。
本场制作重点，以及下游需要准备什么。

【问题／候选修改】
仅在存在问题时写：原文位置、问题与影响、候选改法、需谁决定。
原文不随之直接被替换。
```

场景头和原剧本重复的是检索入口，不另造第二套剧情。重要节拍可简述，但当前约定不扩成详细逐镜表、全套动作时间轴或参数清单。

## 七、制作需求汇总与推进安排

按人物身份及变体、场景与状态、道具／其他对象、声音与效果汇总。建议表列：对象／关联集场／叙事用途与状态／已有材料／需要准备的东西／依赖或验证。

正文逐场便于制作时阅读，文末汇总便于统筹复用；汇总更新必须核对正文，不各自新增设定。需求不等于资产已完成，已命名对象不等于已有实际文件。

安排按任务依赖与重要性，不在没有时间条件时承诺日程或预算。最后集中列少量影响下一步的用户决策与待查证事项。

## 八、来源与必要修改记录

给原剧本定位与实际使用的研究来源。仅在改动影响原判断或下游时记录变更，避免每次小改新增一份报告。不建立无实际用途的哈希、审批台账或编号体系。
