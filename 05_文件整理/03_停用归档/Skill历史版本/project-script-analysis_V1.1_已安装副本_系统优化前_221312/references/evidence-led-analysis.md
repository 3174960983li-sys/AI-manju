# 有依据的项目分析：从知识到执行

版本：V1.1新增方法。用于故事、人物、背景与逐场判断；按任务选择相关部分，不强制把所有字段都塞进导演本。

## 1. 分析顺序与完成物

先核项目要求与原稿范围，再读懂行动因果；随后检查人物选择和世界条件，最后转为导演表达及制作需求。不能先凭风格参考定义人物，再倒推原稿。

首次交流优先交付：准确故事理解、最重要的分析结论、影响下一步的关键问题及候选。普通未知不妨碍的原文整理继续推进。讨论后完善原有单份Word导演本，不额外堆四份独立分析报告。

## 2. 人物判断：从标签转到处境与选择

1. 将身份资料、本人宣称、他人评价和实际行为分开定位。台词评价不自动等于作者认证。
2. 对关键选择还原人物当时知道什么、想获得或保住什么、会失去什么。后续揭晓或观众信息不能倒灌人物。
3. 列原文明示或情境支持的可行选项。被迫、无知、能力受限与主动承担代价分开；选项不明时先描述行为，不强判品格。
4. 用“处境—选择—代价—支持的有限解读”写结论。一场戏不证明整个人生；没有证据的家庭背景或心理病因不补写。

输出：主角和重要配角的有依据小传，以及关键场次的选择说明。配角按实际作用简写，不给所有人安排隐藏创伤或高压考验。

## 3. 人物变化：先分辨揭示与转变

先对照前后选择中的知识、目标、可行性与代价。条件不同不能只凭行为不同判崩人设；观众新发现一个既有侧面，也不等于人物刚刚改变。

再查原文是否提供经历、反馈或关系变化，足以解释取舍变化。材料不足则写“人物揭示／变化待判断”，说明需要哪些场次。只有节选不补整季弧线。

重要选择获准修改后，检查小传、行动前提、结果、他人知识、后续场和结局的受影响范围；列局部修订候选，不静默全剧重写。只改无因果影响的措辞时不扩大为结构返工。

## 4. 背景研究：从设定清单转到事件条件

检查时代、故事跨度、关键地点与冲突层面。故事跨度、银幕片长和交付期限分开。

围绕关键行动写出：完成它需要什么、已有规则如何限制、是否存在有依据的例外。无规则说明时标未知；已建立规则却被无解释突破时定位冲突；不能把“现实里不可能”直接用来否定项目明确的幻想规则。

事实研究、作者设定和艺术候选分别保存。把研究任务限定为“确认什么事实，影响哪场／资产／行动，得到什么依据可以继续”，避免将背景研究变成无终点百科。新外部事实按实际可靠来源核验。

## 5. 心理叙述：先守信息义务，再选表达

1. 提取心理句承担的事实、情绪、判断或行动动机。
2. 分开人物知道、观众该知道、其他角色知道的范围，避免提前揭底。
3. 判断可由已有动作、对白、声音、获准旁白或资料保留承担；不用皱眉和特写统一替换。
4. 对新增动作、道具、证据或台词检查是否改变因果或人物知识，候选不能倒填原文。
5. 输出“必须被理解的内容＋候选表达及取舍”。分析阶段不自动锁焦段、镜数、秒数或生成模型。

若原稿要保留含蓄，不为了说明明确就强制显化；若信息必须明确，不能只用含混动作假称已表达。输入不足时说明依赖并讨论。

## 6. 关键问题如何写成可决策内容

采用简短结构：**原文位置 → 直接证据 → 问题或未知 → 影响 → 最小处理候选 → 谁需决定**。

例：剧本写手机无信号，但墙上有对讲机。不能直接判“主角为什么不报警”的逻辑错误；先查对讲机功能、供电、通信范围及原文有无尝试。缺资料就问相关问题，不新增设备故障冒充原设定。

涉及原文身份、数值、固定对白或人物知识的修订遵循既有确认边界。用户已确认的项目修改仍有效，不能因知识书采用某种理论便推翻。
