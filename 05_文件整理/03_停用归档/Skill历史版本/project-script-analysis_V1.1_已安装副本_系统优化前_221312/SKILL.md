# 项目剧本分析

版本：V1.1。按用户要求补强人物选择、人物揭示与变化、世界规则及视听表达判断。V1.0曾通过一次实际小说素材与Word讨论稿试用；V1.1新增方法做局部文字试跑，不继承为完整新版Word或媒体链路已验证。当前面向AI仿真人叙事项目，不替代制作总控、完整原著开发或逐镜分镜。

## 本次要完成什么

把有效剧本与项目要求整理成一份制作时可持续查阅的导演本。包括项目定位、故事理解与大纲、人物小传、时代背景、逐场原文与处理要点、风格候选、制作需求及下一步。使用[分析方法](references/analysis-method.md)作专业判断；分析人物、背景或心理叙述时读取[有依据的分析流程](references/evidence-led-analysis.md)，按[导演本结构](references/director-book.md)组织成果。不要把所有栏目强制扩写成长篇论文。

用户已确认的边界：
- 从原文提取；合理推断注明；新增设定作为候选讨论，不倒填成剧本事实。
- 原剧本保留。发现问题定位到集／场及原句，说明影响与改法；关键歧义与用户讨论，不静默改稿。
- 每场有场景／出场人物／使用道具、原剧本、本场导演处理要点；不自动展开逐镜分镜、参数表或视频提示词。
- 结合用户偏好研究画面风格、导演方法和优秀对标作品，提出少量有实质差异的组合并推荐。没有偏好先询问，不套固定导演或流行风格。
- 正式角色／场景设计、图片、分镜和媒体生成均是下游任务；本Skill只形成需求及适用的候选处理方案。
- 最终导演本交付可编辑的Word文档（.docx），便于阅读、批注和打印；讨论阶段可先在聊天中交付文字，不要求每轮生成Word。
- 先阅读约定范围内的剧本，提交项目理解与关键问题，讨论方向后再完善导演本。不能跳过讨论直接替用户锁定风格、补设定和完成整本。

## 工作顺序

1. **核材料及项目简报。** 先判定是小说、梗概还是分集分场剧本；小说章节不直接视为集数，内心描写不自动转为对白。确定有效文件、章节／集场范围和不可改内容，读取当前项目约定；检查文件是否完整可读，保留原场号。发现节选疑似删漏时可有针对性核对相关原著或版本，但只作为对照，不能静默替换当前依据。了解用途、作品形态、题材、受众、画幅、时长／集数、期限、参考及现有资产／工具限制。未指定不等于AI可以替用户锁定；只询问会改变当前判断的关键项。
2. **先理解再拆解。** 全读当前约定范围，梳理人物目的、行动因果、信息与关系变化，再分析场次功能、世界与视听需求。对关键人物还原知情范围、可行选项、代价与实际选择，再提出有限性格结论；区分外在变化、人物揭示与真正转变，不用抽象标签代替证据。长剧按完整集／场推进并记录真实覆盖范围，不以抽读或前几场代替全剧结论。
3. **研究必要背景与参考。** 只研究影响理解和制作选择的年代、地域、阶层、习俗和参考作品。事实性或易变判断核可靠来源；无法检索则标待核，不编造史实、影片情节、工具能力和预算。研究服务具体决定，不输出无关百科。
4. **首次交流：项目理解、关键问题与初步候选。** 先提交准确的故事理解、人物与关系变化、制作重点、要求冲突及少量需要用户决定的问题。风格偏好已知时可附初步候选与推荐；没有偏好先了解偏好。明确画面风格、导演处理、制作路线的差别及对表演、空间、资产和声音的影响。此时不把未选方案扩写成全本已确定设计。
5. **讨论后完善。** 根据用户选择记录采用方向、保持项与仍待验证项。按场次提取可复用身份、造型、空间、道具与状态，完善逐场处理、制作顺序及最小验证。不依赖当前选择的原文整理和事实提取可继续；依赖重要未决选择的设计留待回答，不以等待时间代替选择。后续不重复询问已经确认的方向。
6. **编排单份Word导演本并复核。** 已确认要求、原文事实、推断、考据与提案容易区分。逐场头信息和正文一致，需求能回到具体场次，未覆盖与待定部分明确。交付实际可打开的.docx，而不是仅把Markdown改扩展名。使用可用文档制作方法，读取相应文档Skill，检查渲染与排版；无法生成或检查时说明真实限制。

## 交互与输出

首次遇到重要缺口时提出少量高价值问题，先完成不依赖答案的部分。风格／剧情重要取舍提供具体候选、推荐与代价；用户选择后更新同一导演本，保留仍有效内容。不是每填一个栏目都确认一次。

最终格式已确定为Word；遵循作品保存约定，维护一个当前导演本交付入口。内部如需文本或结构化中间稿，用于生成Word，不能当作另一份独立维护的当前版本；用户批注以实际收到的Word版本为准，下次修改先核对批注和有效来源。单个项目成果放该作品，不存回本Skill。用户只要口头讨论时不强制落盘。

交付说明用简短文字写清覆盖的版本／集场、重要结论、尚待用户决定或研究的内容。一次任务不创建多套独立报告；来源与制作需求都可放同一导演本附录。既有原著、剧本、参考图与输出保持独立。

调用本Skill不表示已有真实生成验证、历史考据齐全或制作预算已获批。缺乏真实回执、测时和媒体观察时，不给确定成本、精确时长或效果保证。
