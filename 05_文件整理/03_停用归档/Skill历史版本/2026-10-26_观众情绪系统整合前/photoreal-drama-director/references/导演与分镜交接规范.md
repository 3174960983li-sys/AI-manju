# 导演与分镜交接规范

接口V1.0｜2026-10-26。适用photoreal-drama-director→shot-language-design及局部返工。本文件维护共同约定；各Skill自己的专业方法、作品已有格式和用户当前要求继续有效。

## 1. 分工和采用状态

导演决定观众体验、戏剧重点、信息边界、关键行动/反馈、场面及视听原则。分镜将其转成观看位置、构图、镜头组织、摄影运动、可见表演与声画连接。二者可以协商，不凭阶段名称夺走已确认选择，也不由分镜重新发明剧情。

先核原文范围与版本、导演稿版本及当前选用方案，区分已确认、供讨论、局部待改和未定。Skill软件版本不等于作品稿版本。文件较新不自动覆盖用户确认；新版原文与既定导演方案冲突时列明具体差异，按最新有效用户要求处理，不混拼。

用户已说“按这版做分镜”，即采用所指导演方案并要求文字分镜，不再重复询问同一许可。用户要求先试候选，可以做标明依据的分镜草案，不能把试跑当正式确认。只交导演方案不会自动启动分镜，文字分镜确认也不会自动启动媒体。

## 2. 最小交接内容

在导演方案现有的“分镜交接”段说明即可，不要求另建台账、JSON或重复导演本。普通场面可合并字段，关键内容不能省掉。

| 内容 | 交出什么 | 接收时怎样用 |
|---|---|---|
| 来源与范围 | 有效原文/路径或所给全文、场号和覆盖范围、导演稿版本、当前采用状态/方案 | 核输入一致，保留场号并映射到镜号；未读范围不宣称掌握 |
| 导演意图 | 观众立场、戏剧重点、期待/认识变化，关键处理理由 | 决定镜头任务及观看策略，不只复制阐述 |
| 必须保持 | 重要事实/原对白及归属、不可改结果、必须可见可听或保留未知、已锁视听/调度 | 在分镜找到承载方式；不以近景、音效或表演暗中坐实未知 |
| 行动与状态 | 起始位置/知识/持物、刺激—行动—反馈、环境与声场基准、场尾与相邻承接 | 细化当前可见过程和镜间状态；不省略必要接触，不重演动作 |
| 可变范围 | 可由分镜选择的手段，非关键摆位/细动作的候选，哪些已被锁定 | 在范围内自主设计，不逐项请示；既定机位/时长等不因阶段更换而失效 |
| 缺口与依赖 | 原文歧义、关键空间未知、道具未定初态、真实素材及验证缺口 | 区分可合理提出的布置候选与阻碍关键判断的问题，继续独立部分 |

建议用明确措辞区分“原文如此”“本稿选择”“可调整”“待定”。不强制每个动作编码；复杂场面可给重要保持项临时编号帮助回查。

## 3. 从逐场方案转成文字分镜

接收后先列本轮完整行动单元及承接点；导演的场次、分镜的叙事段落、剪辑镜头和生成任务不是同一单位。不得按场数固定镜数，也不能按平台时限拆散原意。

按分镜现有七列制作：镜号/时间、任务、起幅构图、主体与场景动态、摄影机与光学、声音对白、落幅切点承接。重要导演要求可落在多列/多镜，不是一项要求对应一镜。为重要保持项指出承载镜号或声音范围，检查遗漏、过早揭示、动作/对白重复和跨段状态。

抽象意图转可观察关系；表演解释不全复制为模型指令。分镜可以选择新的观看实现，只要保持已选体验和事实。导演没有锁定的非关键摆位可以细化为候选；若会改变可听性、角色知识、揭示或因果，须标影响，不能称普通摆位就自动采用。

## 4. 谁处理问题

| 问题性质 | 处理 |
|---|---|
| 在可变范围内调整取景、焦点、路径、普通布置即可解决 | 分镜自行修正，检查关联镜头；不重启导演开发 |
| 实现手段不同，但核心体验/信息/关键行动与保持项均不变 | 分镜可提出并选择合适实现；必要时说明取舍，不固定回上游审批 |
| 已确认导演调度或视听要求相互冲突，修改会影响选定体验或保持项 | 列冲突、受影响场/镜号、具体修订候选；需用户选择时只暂停该部分，其他部分继续 |
| 原文/方案/参考版本不一致或重要剧情、人物、台词、揭示需改变 | 指出来源差异及影响，回到原文/导演问题层讨论，不静默覆盖 |
| 关键原文或素材缺失 | 能继续的先做；影响定稿的标条件并补问，不虚构已确认信息 |

返工记录最少包括原因、建议改动、受影响范围和采用状态。导演改变一场时回查相关镜头及相邻状态，不自动推翻全段/全剧；分镜仅改技术措辞时不撤销导演采用状态。修订结果进入现有当前稿，不维护两套冲突动作。

## 5. 后续阶段与分发

默认链路：导演方案→按当前请求做文字分镜→采用该文字后，按需故事板或直接提示词。用户明确要求跳过阶段时按实际授权处理；若从导演方案直接要提示词，而没有足够镜头描述，需先补当前段必要镜头设计并标明其状态，再编译，不能称导演方案本身就是已确认分镜。已有充分镜头输入无需重跑。

接口不改写提示词完整规范、不自动执行生成。单独分发一个Skill而同级包不可用时，仍可按已有原文、导演意图、保持项、状态和可变范围完成当前任务；需要另一阶段时说明缺少能力或参考，不强制安装或整套重做。

入口：[导演](../SKILL.md)、[镜头语言设计](../../shot-language-design/SKILL.md)。本接口来自两包当前内容对照和本轮联合文字应用，不是新增书籍定律，也不是自动Agent调度程序。
