# 书籍方法与选择检查

V0.4维护：保留V0.2基本方法，文末新增本轮补读与采用边界。用于形成导演主张、选择表演与空间处理、核交接。该文件自含必要方法，不依赖外部文章才能执行。

## 1. 三层判断顺序

先核**叙事事实与表达义务**，再选**观众立场与戏剧重点**，最后落实**动作、空间、画面与声音**。

主题不能直接决定机位。写出观众当前理解、接下来通过什么事实或关系获得什么理解，或什么体验需要累积；据此选择手段。无须所有场景都反转，也不能替原作补出不存在的人物关系。

## 2. 最小必要表达检查

为主要设计明确：要完成的任务、承担它的可见/可听证据、成立条件与完成状态。问“换掉或删掉它，会损失什么”，必要时比较一个真正不同的实现。

- 没有影响：可能是装饰，可保留为审美候选，但别列为叙事强制项。
- 只影响某种风格：说明形式取舍，不把个人偏好当客观缺陷。
- 丢失关键信息或反馈：列为必须保住的表达，允许下游另选镜头实现。
- 只能靠导演解释、方案本身无证据：补设计或缩小解读，不宣布观众一定读懂。

精简针对无职责的重复与装饰，不要求台词越少越好、表演永远克制或一切靠切镜。

## 3. 双层表演指导

导演层掌握人物目的、知情范围与关系依据；执行层说明此刻要对谁做什么、触发、行为、反馈及结束。避免把整场主题强压进每个微动作。

从情绪词转到行为时，既不能只给“悲伤”，也不能把它换成未经解释的动作动词就结束。说明当下行为及对象，例如“听完再回应，让对方可以继续离开”。

原文需要激烈外显表演就保留依据，不强制克制。无需每个人物都加迟疑、抿嘴、吞咽、眼眶湿润的套餐。AI生成能否实现另行验证。

## 4. 视点不等于主观机位

先写观众随谁获得信息、注意谁的反应，何时改变认识。观察立场可移动或中立，不用第一人称/近景名称代替关系判断。

人物调度、画面组合和摄影机运动可互相配合，也可分别完成任务。对关键节点交代注意力应该转向哪里、什么行动或信息触发、什么必须读清；不在本Skill提前锁镜头分解。

## 5. 连续与分解呈现是可选策略

若场景依赖同场关系、行为反馈与空间保持，可向下游强调这些覆盖义务；若依赖不同事实的先后联系，说明排列关系。两种方式可以组合，不规定长镜头高级、跟拍无效、多切更电影化。

选择时比较：观众理解、人物反馈、节奏、空间可读性与实际制作条件。复杂连续生成存在未知时记录验证，不凭书中真人拍摄方法保证模型控制能力。
