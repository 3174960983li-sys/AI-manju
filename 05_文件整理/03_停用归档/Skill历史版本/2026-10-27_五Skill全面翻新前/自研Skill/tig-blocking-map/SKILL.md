# 角色站位图｜TIG Blocking Map

V2.1｜2026-10-26。基于Tigran/TIG原v2的本地适配版，保留彩色轮廓与几何/外观职责分离，新增四阶段接续、镜号/阶段范围、动态状态与真实绑定核对。原作者来源保存在[原始附件](原始附件/tig-blocking-map.skill)，不因存入自研Skill目录而宣称原方法为自主原创。文字试跑不代表图像或视频控制效果已验证。

## 定位与入口

这是按需调用的空间表达辅助能力，不是四阶段主链必经的第五审批环节。导演可借它检查调度候选，分镜可借它明确某镜观看关系，提示词阶段可接已核实图稿；简单镜头或用户直接要提示词时，不强迫绘图。

核心输出是具体摄影机视角下的人物位置、朝向、姿态、裁切、比例、前后遮挡与必要道具接触。世界位置与画面左右分开，单幅画面不能证明隐藏区域布局、精确距离、真实焦距或可行摄影机路线。不要把镜头站位图叫作精确俯视平面图。

按[站位图设计与交付](references/站位图设计与交付.md)形成绘图提示词、文字人物键和几何连接说明；接导演/分镜/提示词时再读[体系接口与回查](references/体系接口与回查.md)。只读当前任务需要的部分。

## 操作流程

1. 核模式与依据。区分绘图提示词、实际出图、审查现有图、接入视频说明。核作品、制作文本/导演/分镜版本、场/镜号、动作阶段、采用状态及保持项。源画面重绘与据文字新设计分开；新增布置明确为候选，不称从原图读出。缺上游文件可据足够材料独立完成。
2. 读空间与可见范围。有源画面先实际查看；无查看能力说明限制，不凭文件名判断。按主体列位置、朝向/视线、姿态、裁切、遮挡、持物/接触及地标。镜头高度/朝向沿有效依据，不机械改成正面。未见的身份、身体和空间保持未知；源画面和有效分镜冲突时列差异，不默改已锁方案。
3. 选择最少必要图稿。一图只约束对应镜头/阶段。换机位、明显走位或遮挡改变时核是否需要新视图、起末两态或文字节点；不要求每镜出图。人物路线和摄影机路线分别声明坐标、触发与终点，不用屏幕箭头代替世界路径。初态图不冻结后续脚本行动。
4. 交付并核身份键。默认中文、工具中立提示词；彩色细轮廓和简化锚点，不堆外观细节。保留TIG约定：图里不画字母/文字，A/B等只在图外文字中与角色名称/真实参考及颜色对应。A是逻辑别名，不是平台原生槽位；未知身份不猜名字，颜色不代表服装。未核真实绑定不编造@标签或image_1。
5. 按当前请求止步或接续。只要提示词就交提示词、人物键、适用范围及必要依赖，不自动出图；明确同时要连接说明就一起完成，不按原版两步法重复索要同一授权。实际制图时按可用图像Skill/工具执行并检查结果；仅保存提示词不称图已完成，图合格也不等于视频通过。
6. 回传下游。带图稿真实文件/逻辑标识、来源版本、镜号/阶段、人物对应、采用/检查状态与几何范围。关键图文位置/身份/朝向/遮挡冲突先处理，不声称文字必然覆盖图。视频仍用当前指定Skill格式，站位连接并入素材职责和相关镜头，不另建竞争模板。

## 核心约束

- 图主要约束几何；角色、环境、服装、材质和光线沿当前项目有效参考与文字，不强迫写实，不将轮廓颜色、白底或辅助线作为成片外观。
- 颜色清楚可辨、细轮廓不填大色块，是原作者的降干扰设计选择，不是防串色保证；不要无限减淡到看不清主体。
- 正向表达优先，必要短否定允许。上传顺序、标签语法、权重和能力按实际入口核实，不采用放最后必有效、英文必需或100%匹配等保证。
- 图稿版本不是分镜版本或采用状态。改机位/裁切/关键站位/阶段后回查图及相关提示词，不覆盖无关镜头。改变关键几何的图像误差须修正；不影响职责的差异可记录保留。
- 不因接入本Skill强迫补故事板、上传或新增费用，不覆盖其他项目默认方法，不自动安装。
