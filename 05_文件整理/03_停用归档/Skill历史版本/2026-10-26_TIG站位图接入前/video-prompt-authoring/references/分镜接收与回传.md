# 分镜接收、编译与回传

V0.2。完整提示词格式仍由[结构规范](structure-and-rules.md)维护，本页只定义接口。可接同级[镜头语言设计](../../shot-language-design/SKILL.md)；同级包不可用时，足够明确的用户镜头描述也可作为输入，不要求安装或先制作故事板。

## 1. 核有效输入

明确本次有效分镜版本/消息、镜号、采用或草案状态、对应场号/段落、当前制作文本、导演保持项及未决条件。导演本里的原著对照不能覆盖用户已采用的修补；不能把最新文件日期当采纳证据。缺关键输入时指出影响，不以其他版本偷偷补全。

接收必须可辨的信息、暂缓的答案、人物知识/反应触发、环境因果及持续后果、空间/光学关系、准确原句/声音、独立声画切点与首末态。共同条件在段落说明或导演保持项里也有效，不能只拷七列表格而丢掉它们。抽象体验留在说明中，正文落实可见可听条件。

## 2. 七列到六模块

| 分镜输入 | 提示词承接 | 编译检查 |
|---|---|---|
| 来源/镜号/时间及段落共性 | 块外依据、任务映射及设置；模块二拍摄形式、模块三共同初态 | 区分设计/估计/实测，原镜号可追溯，不能因任务重组擅改切点 |
| 镜头任务 | 模块二可见事件目标及模块四对应过程 | 把“关切/等待”落成具体观看条件，不重复情绪口号 |
| 起幅与构图 | 模块三首镜基准、模块四各镜起幅 | 后镜从前镜推导，机位变化不把世界镜像或重置人物 |
| 主体行动与场景动态 | 模块四刺激、行动、反馈及局部变化，模块六末态 | 道具/环境后果持续，角色反应有来源；不为动感加无关运动 |
| 摄影机与光学 | 模块四观察关系、清晰要求、连续路径 | 锁定固定/连续观看须保留，不以模板替换既定机位 |
| 声音与对白 | 模块四发生节点、模块五唯一完整原句或分配后的实际发声内容 | 原文逐字、说话者、画内外/谁听见、声源和跨镜范围准确 |
| 落幅、切点与承接 | 模块四出入点/独立声画边界，模块六任务末态 | 不能切掉必要反应/兑现；后一任务不重演上一动作 |
| 真实资产与用途，可能来自段落说明 | 模块一素材绑定及边界，必要设置在块外 | 文件路径不是槽位；声音参考不自动带入人物外貌；无参考可省略 |

模块位置是职责映射，不要求同一信息反复写。短任务可合并模块；复杂镜头的补充说明与七列表共同作为同一输入，若矛盾先核当前有效内容。

## 3. 镜头、任务、音轨分别组织

保留原镜号，在块外用简短说明列G任务对应哪些镜头/连续阶段；G号不是新镜号。一个任务多镜要写真实切点；一个长镜分任务须说明保持连续的实现条件，不能偷偷加剪切或宣称拼接必然无缝。无具体平台约束不为凑任务数拆分。

对白跨镜而处于同一任务：原句在统一声音模块完整出现一次，逐镜只标对应发声/延续窗口，不让每镜重新说整句。若选择逐镜维护原句，则声音总区不再重复全文。

对白跨生成任务：优先将完整话轮放在同一任务，或按已选制作路线以连续音轨后期承接。确需分别生成时，记录每任务实际发声范围，顺接后逐字对应原句、没有遗漏或重复；不能让两任务都说全文。上下文引用要明确“不在本任务发声”，否则易误生成。影响锁定说话节奏/切点的分法作为取舍，不擅改。

跨任务配乐、环境声、画外声和延续动作也要说明衔接或后期依赖，不要求每块音频从头启动；尚无真实声音/素材时只交条件与待验项。任务独立可读指必要初态完整，不意味着重复上个任务的表演。

## 4. 交付状态与返工

块外最少说清依据、覆盖/映射、采用或候选、必要设置/缺口，避免把工作说明塞进生成正文。无需模板化长表。

- 无参考、足够镜头描述：可交通用文生提示词，不强迫补图。
- 依赖参考但无实际槽位：交待绑定稿；不虚构标签，不宣称可直接提交。
- 平台入口或能力未知：可交通用稿，标未适配；不猜当前参数。
- 真实接口已核：说明适用入口及核对范围，仍不等于媒体效果通过。

提示词层能修的歧义/绑定/丢项直接修；需要改分镜构图、行动、切点时给具体镜号与理由；触及导演核心体验或制作文本事实时反馈相应层。只回查受影响镜头/任务及相邻状态，不自动重做全剧。源分镜变更时旧提示词相关部分标待回查，核对后更新，不能无视上游版本继续提交。
