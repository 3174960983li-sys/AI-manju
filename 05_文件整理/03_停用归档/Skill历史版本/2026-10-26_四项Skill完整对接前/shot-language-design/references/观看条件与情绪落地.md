# 观看条件与情绪落地

V0.8新增。用于把导演体验目标转成实际可见可听的分镜条件，保留现有七列。

## 从目标到镜头

先核本段的目标、信息释放顺序、必须读清/暂缓的内容、关键行动与结果、已有采用状态。缺导演文件时可补必要判断并标明来源，不强制重跑上游。

对关键节点问：**观众具体看/听到什么，凭什么形成理解，何时有机会读到变化？** 再决定取景、机位、调度、焦点、运动、声画关系和切点。不能将“令观众落泪”直接塞入生成指令；也不为每个节点强拆一镜。

| 原有位置 | 承接内容 |
|---|---|
| 段落设计说明 | 目标体验、观众起始知识、关键承诺/兑现、共同声画条件与待验问题，写一次 |
| 镜头任务 | 需要看清、理解、等待、观察或消化什么；不强求每镜新增信息 |
| 起幅与构图 | 焦点与必要背景的关系，关键信息是否进入画面；反射或边缘是否意外泄露答案 |
| 主体行动与场景动态 | 刺激—行动—反馈及持续状态；克制或静止的观看价值，不凭空补动作/设定 |
| 摄影机与光学 | 看清变化所需距离、角度、遮挡、清晰范围与路径；表现力服从已选意图，不默认推近 |
| 声音与对白 | 谁听见什么、关键信息是否可辨、配乐/环境/主观声各自职责及跨镜延续 |
| 落幅、切点与承接 | 什么被观众读到后才切、结果有无被过早切掉、答案在哪里兑现、下一镜继承什么 |

## 五项执行检查

1. **可读不等于出现。** 关键文字/物件需核正常播放下的尺寸、遮挡、清晰、运动与可用时间；屏幕裁切和声音遮蔽会影响理解。没有实际画幅或媒体时写待验，不伪造最小字号/固定秒数。读不清时先调整条件，不默认增加特写或延长全段。
2. **反应要有条件，心理可留歧义。** 角色感知来源、变化与下一行动可衔接；观众获得信息的顺序可以不同于角色。不能因反应位于某镜后，就断言唯一情绪。已锁歧义不靠近景或音效改成定论。
3. **停留和运动都要有用途。** 保持不动可以等待、倾听或消化，不强制加眨眼、摸道具、环境风动。必要环境反馈和声场仍连续。将时长标成事件条件或估计，只有试读/预演/媒体后才填写相应实测。
4. **兑现与信息边界贯穿素材。** 起幅、运动过程、反射、关键图都不能提前泄露应暂缓内容；结果发生后留出必要观察机会。已完整结束可以收束，不额外插谜团。一个长镜可承载多次变化，不因生成任务分块自动加切镜。
5. **检查对象分层。** 纸面查覆盖与自洽，图稿查空间/构图，实际素材查可读性/表演/连续性，剪辑查采用区间和声画，观众反馈查实际理解与体验。静音或去配乐仅是诊断；故意依赖声音的作品不因静音看不懂而失败。

## 下游编译和局部返工

交提示词时保留关键对象、动作反馈、信息显露时点、声音和切点条件；共同条件集中，镜内变化放回对应镜头，不复制整套理论或六问，也不反复堆“紧张、感人、震撼”。沿用当前提示词结构与真实素材绑定。

“线索没看清”不一定是剧本问题：若原素材清楚而被剪短，先调采用区间；若原素材不可读，查取景/执行/资产；若缺必要前提，再反馈上游。修改限于相关镜头、声音与相邻状态。改变已锁连续观看、重要揭示或事实时提出具体取舍；其他可变手段自主修正。
