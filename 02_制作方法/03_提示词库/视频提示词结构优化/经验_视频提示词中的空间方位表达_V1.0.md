# 经验：视频提示词中的空间方位表达

V1.0｜2026-10-25  
用途：区分空间规划坐标与视频生成描述，减少人物、摄影机、构图和光线的方位歧义。  
来源：用户审阅CINEDANCE优化模板时，对东南西北写法提出的质疑及本次讨论。  
状态：已形成文字分析与改写建议，未进行模型生成对照；不作为已实测的成功率结论。

## 一、问题与结论

[优化模板](CINEDANCE视频提示词优化模板_V1.0.md)中的办公室示例原写：

> 房门在房间南端，桌子位于北侧，窗户在西墙。女子从门内向北侧桌子走去。摄影机位于她东侧，朝西北观察，窗户自然留在她身后偏侧的位置。

用户提出：“使用东南西北来描述，AI能够听懂吗？”

问题不在于方位词本身不能理解，而在于理解文字、建立空间、推导当前机位画面、跨镜保持一致，是不同要求。不能因为词语意思清楚，就承诺模型会精确执行。

原文还存在编写者自身的推导不足：窗在西墙，没有说明窗沿墙的具体位置，不能据此确定窗就在女子身后。人物位置、朝向、摄影机取景也需要共同核对。“自然留在”不能代替这些判断。

**编写建议：规划时可以使用方位或坐标；最终视频提示词优先转写为地标关系、人物相对位置和当前机位可见的画面。**

该建议有助于读者理解、画出构图和检查返图，但本次没有对照实验证明相对描述必然比绝对方位更有效。不能归纳成“AI不认识东南西北”。

## 二、区分四种参照

| 参照 | 负责什么 | 表达示例 |
|---|---|---|
| 世界空间 | 固定地标、行动轴、摄影机与光源位置 | 可用东南西北、坐标或俯视图，并对应实际地标 |
| 人物方向 | 朝向、走位、持物与接触 | “女子面向桌子时左侧的窗” |
| 摄影机位置 | 从哪里、朝哪里拍摄 | “摄影机在女子右侧，斜向拍摄她与桌角” |
| 当前画面 | 构图、裁切、遮挡和可见范围 | “人物位于画面左侧，信封在右下前景” |

世界西侧、人物左侧与画面左侧不能直接互换。左右前后也要说明参照对象；只把“西侧”换成“左侧”，不一定解决问题。

## 三、推荐写法与示例

按以下顺序组织，不要求每次写成表格：

1. 固定必要地标：入口、窗、桌子、通道等。
2. 明确人物起点、朝向、目标和行动路径。
3. 写摄影机相对人物或地标的位置与拍摄方向。
4. 说明本镜要看到的对象、画面位置、裁切和遮挡。
5. 指明实际光源，以及本镜人物哪一侧受光。
6. 检查这些关系能否同时成立；不确定的关系补资料或设计，不强行推断。

没有影响当前镜头的信息可以省略，不为完整而给所有物体编坐标。

下面是一种表达方案，不是由原文粗略方位计算出的唯一构图。用于实际作品前，要与有效设计和参考图核对。

```text
【空间与全局视觉基线】
桌子靠着入口对面的墙，窗户位于女子走向桌子时的左侧墙面。女子从门内走向桌边。摄影机在她右侧斜向拍摄，同时保留她的侧脸、桌角和信封。
阴天柔光从同一扇窗进入，主要照亮女子靠窗的一侧。旧木桌呈哑光，信封为浅褐粗纸。衣料随步行动作轻微摆动。
```

如果必须让窗出现在人物身后的画面中，需要进一步确定窗的位置、人物落点和摄影机视线，不能只凭“左侧墙上有窗”就认定它会入镜。

| 含糊表达 | 改写要点 |
|---|---|
| 摄影机在东侧朝西北拍 | 补人物/地标参照，并明确需要看到的内容 |
| 窗在左边 | 区分人物朝向中的左侧与当前画面的左侧 |
| 光从左边来 | 先指定哪扇窗或哪盏灯，再写本镜受光结果 |
| 她走到他后面 | 明确按谁的身体朝向判断，是否遮挡、能否入镜 |
| 窗户自然出现在身后 | 查具体位置和取景依据，缺少依据就补设计或删除断言 |

## 四、换机位与站位图

人物、家具、地标和实体光源维持同一世界关系。反打、绕行或移动后，重新核对画面左右、纵深、遮挡、入画范围与受光，不能为了保持上一镜的画面左右而移动人物或镜像房间。

两人隔桌相对而坐时，换到另一人的侧后方拍摄，画面位置可能变化，但实际座位不会交换。是否维持银幕方向还应结合行动轴、具体机位和剪辑设计判断。

三类图分工不同：

- 俯视调度图：规划世界位置、朝向、行动轴和摄影机路线。
- 画面站位图：表达某个机位、某个阶段的姿势、构图、裁切和遮挡。
- 成片关键帧：提供具体外观、材质、光线与最终视觉，按任务声明采用边界。

TIG主要服务画面站位。不能单靠一张图保证全部反打与绕行成立；人物行动或观察方向明显变化时重新检查，必要时补对应阶段的图。关键图文冲突应先修源，不宣称文字必然覆盖图像。

## 五、交付前检查

1. 每个左右前后是否有明确参照对象？
2. 世界位置、人物方向和画面位置是否混用？
3. 能否根据描述画出起幅，明确可见对象、裁切和遮挡？
4. “身后有窗”“左脸更亮”等判断是否有具体位置、朝向和光源依据？
5. 换机位后世界关系是否保持，画面投影是否重算？
6. 站位图、文字和实际素材是否一致？
7. 是否把表达建议误写成模型必然遵守的规律？

## 六、边界与证据

本经验用于空间、摄影机、光线与站位参考的文字编写。地理叙事、日照规划、航拍或明确带坐标的场景仍可保留绝对方位，并辅以地标、图示和需要看到的结果。不将一次问题升级为禁止方位词的通用规则。

本次只确认了文字推导不足，未生成视频，也没有证据证明原写法已造成某次具体生成失败。后续对照应尽量保持模型、素材与设置一致，只改变空间表达方式，检查站位、朝向、遮挡、光源和跨镜关系；不以单条结果推断普遍效果。

背景资料：[Higgsfield官方指南](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-seedance)在前次讨论中已核对，强调具体动作与明确摄影机指令。它仅支持一般编写背景，不直接证明绝对方位无效或相对表达更优。
