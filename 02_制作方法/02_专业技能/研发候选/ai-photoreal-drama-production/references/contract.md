# 制作对象与交接契约

版本：V0.1｜日期：2026-10-24｜状态：AI仿真人通用母版配套候选。当前只建设仿真人方向；本文不代表其他路线已建设或验证。

## 1 用法与权威顺序

本契约只统一各阶段传递的事实与状态，不规定统一画幅、镜数、时长、人物造型或平台。用户可以从创意、原著、已有剧本、资产、指定镜头或既有结果进入，助手只补当前交付不可缺的输入，不要求重做无关阶段。

实际采用顺序：用户当前明确要求与有效授权 → 当前作品已确认事实与适用版本 → 本轮选定专业方法与配置 → 通用默认。共同的可追溯与连续性要求不能被“风格化”一词自动解除；有意的跳切、梦境或省略应在创作设计中说明，不当成无故错误。

过去项目的图号、角色、画幅、三联/四视图、示例时间和G门不自动移为通用标准。当前用户批准建设母版，不等于批准付费生成、发布、迁移删除或修改全部已安装Skill。

## 2 核心对象

| 对象 | 必须能回答的问题 | 最小记录 |
| --- | --- | --- |
| 创作简报 | 为谁制作、要表达什么、交付到哪一步 | 目的、形态/篇幅、硬约束、当前输入、待决定项 |
| 剧本文本 | 哪些事件和台词有效 | 原文位置、当前版本、用户锁定项及允许修改范围 |
| 人物/世界规则 | 同一人物与空间靠什么辨认 | 身份、造型、状态；固定地标、场景拓扑与必要世界规则 |
| 场次 | 本场在故事中改变什么 | 起始事实、人物目标、行动反馈、信息/情绪变化、结束事实 |
| 镜头 | 观众在一个连续观察中看见什么 | 观看任务、可见主体、机位/运动、动作、声音、起尾状态与切点 |
| 资产需求 | 镜头具体需要什么 | 用途、状态、视角/可见部位、优先级及检查条件 |
| 真实资产 | 哪个文件可以支撑该用途 | 实际路径、身份/造型/状态/视角版本、检查范围、使用限制 |
| 生成任务 | 本次实际让哪种工具做什么 | 执行稿快照、实际输入顺序、模型/入口与设置、授权范围和结果 |
| 原始输出 | 原工具返回了什么 | 可打开的文件、实际技术信息、来源任务或明确未知、未改原件 |
| 选用片段与编辑 | 原输出中哪一段实际采用 | 源文件与源内in/out、目标镜头、邻镜状态、声音处理及缺口 |
| 交付文件 | 最终交什么且核过什么 | 输出、规格、版本、实际播放与检查范围、遗留问题和采用决定 |
| 经验 | 什么条件下值得再次使用 | 目标、输入条件、偏差、修改、结果、反例和适用范围 |

这些是逻辑对象，不要求一对象一文件。短片可将简报、版本和问题合为一份入口；长剧再按集/场/段拆分。ID用于查找时才建，内部编码和路径不进入生成正文、角色台词或画面。

## 3 交接的最小内容

交给下一环节时，只需明确：当前交付及版本、真正采用的输入、保持项、允许变化项、实际检查结果、阻断缺口，以及接收方下一动作。现有表格能承载则在原位置补充，不抄第二套台账。

没有实际图像的需求不叫锁定资产；有参考文件不等于平台已绑定；生成成功回执不等于镜头可用；可用镜头不等于成片合格。可先研究、草拟和补资料，但缺口影响到实际活动时，不能伪造准入或通过。

### 资产职责

每个输入只在声明的职责内有权威：身份、衣装、首帧、空间、构图、动作、效果终态、产品或声音。已知冲突的背景、展示姿态、标牌或旧状态须明确不继承；必要时裁切、编辑或替换输入，不能只靠长串否定词承诺解决。

### 进入与退出状态

必要时记录人物世界位置、朝向/视线、手持物和开合状态、衣装/伤势、环境/光源、已知信息和情绪准备。切镜后重算画面投影，不能为了保持屏幕左右而移动真实人物或场景。允许对象出框，不允许无依据地把出框等同消失。

## 4 时间与媒体层次

分清剧本/分镜的目标时间、GEN内部时间、生成原片源内时间、后期成片位置。它们可以通过映射关联，不能相互替填。容器时长、视频帧时长和音频尾长也可能略有差异，先辨认测量对象再判不合格。

镜头总时长包括准备、主要过程与结束保持。有明确“过程至少N秒”的要求时，单独核过程从可辨触发到完成的区间；不得把等待或完成后的静止时间算入N。台词和表演时间以实际演读/录音或真实输出核对，纸面估算标为估算。

## 5 状态与证据分开

| 维度 | 示例值 | 不能代替什么 |
| --- | --- | --- |
| 阅读/检查覆盖 | 未读、局部、全文；未看、抽帧、连续播放；未听/实际听取 | 不能代替创作者采用或质量结论 |
| 断言 | 已核事实、有据推断、创作提案、未知 | 不能代替真实生成效果 |
| 工作进度 | 待做、进行中、待决定、已交付本轮范围 | 不能代替成片通过 |
| 使用状态 | 候选、指定范围采用、停用 | 用户采用不能补成未发生的实测 |

检查人如为同一创作者，写自检；没有另一审查者，不称独立复核。只有抽帧时，运动、短暂形变和音画结果保留限制；未听声音不能凭字幕或波形写混音通过。

## 6 变化、返工与继续执行

改动只在获得授权的对象和范围内进行。记录改了什么、为什么、影响哪些场/镜/任务；不受影响的文件不重做。回退顺序由最早有证据的错误源决定：故事事实→剧本；动机/接触→场面；镜位/时间→分镜；几何/身份→资产；输入版本/顺序→提交；动态偏差→结果诊断；编码/字幕/混音→后期。

按五类处置择最低必要成本：保留、后期处理、局部编辑、受控重新尝试、修改设计。没有证据不将全部问题归为“提示词不够详细”，也不默认重生成。实际次数和费用受本次预算约束，同一办法反复失败先复查假设，不无界重试。

阶段检查是客观工作，不自动要求用户每步签字。用户已授权全流程时，普通实现和下一已授权阶段继续推进；仅因重要故事/风格取舍、不可查明关键事实、费用/权限等需用户决定时暂停相关部分，说明最小问题，其余继续。

## 7 模型与工具边界

工具输入数、音频支持、时长、尺寸、价格、参考作用以实际入口验证，不从旧教程推断。执行前确认当前任务能否访问相应能力；无工具或额度时仍可交付本轮获授权的文字/素材准备，但不能把它命名为已生成或合格成片。

声音、图片或视频上传至外部服务也属于实际操作，需要在当前授权范围内。个人或第三方资料的用途依据用户和项目实际信息核对，本文不提供抽象法律结论，不因题材普通而虚构使用许可。

## 8 版本锁定与维护

项目入口只需锁定SOP、所用主Skill/扩展和项目配置的版本或可查路径。候选升级先确定具体差异，不自动将旧项目换版。问题先回项目/专项/路线，只有明确跨项目成立的部分才进入共同层。真实例子中的秒数、罐数和固定图号不升为普遍规则。
