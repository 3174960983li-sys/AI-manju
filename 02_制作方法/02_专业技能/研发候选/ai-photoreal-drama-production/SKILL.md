# AI仿真人叙事制作总控

将用户任务落到可执行产物与交接；不默认创建多个Agent。只做仿真人通用方法，不预设题材、人物、风格或3D路线。

## 接收与选择

确认本次目标、有效输入版本、必须保持内容、允许动作和完成条件。只读相关作品约定与所需材料。已有剧本、资产或成片时从相应环节进入；提示词请求不自动扩为生成，审查不自动改稿。

按需读以下参考，不一次加载全部：
- 跨版本、资产用途、时间／状态交接：[制作对象与交接契约](references/contract.md)。
- 本次阶段的具体操作、交付与返工：[全流程SOP](references/sop.md)，按1项目接收、2剧本、3导演、4镜头、5资产、6生成、7后期、8交付、9迭代定位。
- 任务分解和角色交接：[总控职责](references/coordinator.md)、[职能角色](references/roles.md)。
- 选择已有专业Skill及避免默认冲突：[能力映射](references/capabilities.md)。这些是可选能力，缺失不阻塞可完成的文字工作；引用其他Skill前读取其实际入口。

一个任务选择一个主流程；其他方法只补所需专业判断。当前用户及作品约定优先，不叠加不同Skill的格式、目录和审批。没有指定时依据用途决定画幅、资产视图、镜头数量和节奏；不默认9:16四视图或每段7—8镜头。

## 执行与检查

1. 将输入转成本次所需产物，标明有效来源和缺口。对影响交付的重要未知先查明，不能查明再询问；不为次要字段停工。
2. 按依赖推进，角色为逻辑职责，不自动启动进程。授权内持续完成，不机械等待每阶段批准。
3. 素材绑定以实际文件／平台槽位为准；身份、空间、道具状态、表演动作及跨镜连续性形成可交接约束，不复制别的作品内容。
4. 实际生成前核查工具能力、实际提交参数及授权边界；无工具、无费用授权或未获媒体请求时完成相应准备，不伪报已生成。当前项目默认不新增付费生成，除非后来明确批准。
5. 按最早错误来源返工；修订时指出影响的下游，保留仍有效内容。不要为了一个镜头重写整剧。
6. 只报告实际检查范围：文字推演、抽帧、连续画面、听验、真实输出分开。最终视频需要真实播放及声音检查；不足就列缺口，不签全片通过。

## 交付与迭代

交付用户要的可用内容或真实文件，简述验证及重要限制。需要接力时带上任务、有效输入版本、保持／可改、产物、检查范围、下一主责；简单任务不新增台账。

将经验记录为来源、观察、解释、改法、反例与适用边界。一次失败只支持候选解释；文字试跑不证明媒体效果。专业扩展待真实需求出现后建立，不预建全部题材分支。

本包参考是项目权威源的发布快照，维护对应关系见 `references/source-map.json`。修改先回权威源，再更新快照和版本；本候选未安装到全局Skill目录，直接提供本文件路径即可按文档使用。
