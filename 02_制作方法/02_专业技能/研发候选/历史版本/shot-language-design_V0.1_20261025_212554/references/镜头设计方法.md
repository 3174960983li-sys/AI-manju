# 镜头设计方法

## 1. 先选择如何观看，再决定拆几镜

核当前段行动、信息及导演意图，写清观众应怎样经历它。然后找注意力需要转移、行为发生反馈、空间关系改变或信息被获得的节点。

这些是镜头选择依据，不是每遇一个节点都切一刀。比较保持观看是否更有力量，还是改变观看位置才增加理解。没有新职责的重复覆盖可压缩；必要的反应、停顿和空间建立不能因没新台词就删除。

每镜有主要任务，也可以在一个连续运动中完成多个有关联的任务。镜头与平台生成单元不同；平台时限不决定叙事镜头数。

## 2. 联合选择景别、机位、构图与光学

先明确注意力对象及其与环境、他人的关系，再选择：

- 景别：需要读清微小反应、身体行动、关系还是空间？
- 机位：摄影机位于世界何处、相对对象什么高度和观察方向，视线或遮挡会不会改变信息？
- 构图：前中后景、画面边缘、留白、框架与人物位置怎样组织注意力和力量关系？
- 光学：观看距离、透视、空间压缩/展开、景深、焦点变化怎样配合任务？具体焦段有依据或确有执行需要才写，不编造真实设备元数据。

广角不等于必须贴脸、长焦不等于必定深情、俯拍不等于必然弱势。选择需要回到具体关系与作品风格。变焦与摄影机前后移动有不同空间效果，不能在描述中混为一个动作。

镜头可以大胆，包括极近、远距、遮挡、非常规角度或复杂运动，只要它们能承担明确表达并与空间/行动相容。不要每镜强行换一种镜头语言。

## 3. 把运镜写成可以执行的过程

固定机位是有效选择，应说明画内变化承担什么工作；不要求所有镜头运动。需要运动时写清：

**起始位置与朝向 → 触发 → 移动/旋转/焦点路径与相对速度 → 运动中保持或揭示什么 → 终止位置与画面状态。**

分别描述人物移动与摄影机移动，不能只写“跟随过去”。摄影机路径不能穿墙、穿人或与家具相撞；绕行时空间背景变化要成立。复合运动分阶段，说明接续触发，避免把推、拉、摇、绕等词并列成无法同时实现的命令。

示例只示范具体程度：人物退到门边时，摄影机沿屋内通路侧移，逐渐让门与留在原地的另一人形成可见间距；人物停下后摄影机停止。实际是否采用由剧情决定，不把此例当默认运镜。

## 4. 设计切点和镜间承接

切镜说明触发：行动结果出现、注意力改变、反应形成、信息需要暂缓或节奏需要中断。不默认一句台词一个镜头，也不将每次动作接触拆碎。

前镜结束状态应支持后镜开始：方向、视线目标、身体/道具位置、接触进程、光源和声音关系一致。轴线或时空可以有意改变，但需让观众重新定位，不能因无意左右颠倒破坏理解。

声音可以先入、延续或与画面形成关系，说明谁说/谁听、口内或画外及实际文本；锁定台词逐字保留，不为凑镜头自动删改。

## 5. 时间与可执行性

无目标时长时先设计事件顺序与相对节奏，表内可写“完成动作及反应后切”。有时长目标则结合对白试读、动作过程、停顿与过渡分配预算；区分估计、目标和实际测得。用户未锁定时长时不要先问参数才能做基本设计。

镜头过载时先检查可否简化画内关系、改变实现或分段生成；需要拆镜时保留动作因果与导演体验。不因模型可能困难直接删除核心动作，也不承诺复杂运动一定能生成。

## 6. 最终自查

每镜主要任务是否清楚；观看选择是否有理由；运镜能否沿真实路径执行；人物与摄影机运动是否区分；切点是否成立；镜间与跨段状态是否一致；声音、原台词和信息揭示是否保持。文字自查不能证明实际生成成功。
