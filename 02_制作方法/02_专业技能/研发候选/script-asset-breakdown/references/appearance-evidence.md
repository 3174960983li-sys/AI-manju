# 外观取证与限定范围抽测

V3.1｜2026-10-28。选择性吸收cyber-character、cyber-scene、cyber-prop的事实提取思路，保留本包原有资产层级、完整原文和三表五列。三份来源包位于`E:/AI漫剧/03_参考资料/SKILL/`，原作者为魔一小蕾(抖音)。不迁入自动风格注入、固定字数、错误示例或素材不足即整项拒绝等规则。

## 外观事实与设计缺口

把已明确的身份、用途、性格判断与外观分开。描述丰富不等于五官、材质、颜色和尺寸必须齐全；事实少时如实保留少量事实和缺口，不编造，也不把已知对象从清单删掉。

复杂或易误读的外观，内部可用`appearance_facts`逐条记`text`与`source_ids`；`appearance_gaps`记录原文没有确定的项目。沿用source_records和source_ids，不再建立另一套证据目录。原文附属行仍完整逐字输出；五列描述中用“外观事实”“缺口”等自然语言承载，不增加表列。

每项事实必须有对应依据，不能因为整段讲的是这个角色就把任何形容词算作证据。人物说“你真丑”属于台词立场，不自动变客观五官；“英俊”“高挑”保留原词，不延展为具体鼻梁、身高或发色。原文已有提示词不能倒灌成原剧事实。

名称含“银色”不等于纯银，“血色手套”不等于染血；有超常治疗作用的玉，不自动补翠绿、发光、项链或藏匿位置。未说明材质的黑衣不补皮革，未写款式的睡衣不补蕾丝、颜色或长短。

## 三类重点

- 角色：别名先凭证据归并；服装与身体状态分别记录。上身脱衣属于明确可见状态，脸红、微笑通常只是表演。动物归角色。未写痊愈不认作痊愈，原文明示伤痕消退则保留变化。
- 场景：从环境取证，不以人物/人群存在推造破损家具或散落行李。空场景外观段可省略人物，但本资产清单仍保留用途和人物行动所揭示的真实出入口、陈设及视线关系；不能删掉相关完整原文中的人物。日夜或损毁是关联状态，不按每次切镜重建场景。
- 道具：外观事实与剧情用途分开写；持有人、数量、关键文字和可见完整/损坏、折叠/展开等状态保留。纯特效不自动变实物。结构不明可登记用途与缺口，不为凑完整提示词补设计。

设计需要补全时，候选单列/标记，引用的原文是需求依据而非造型证据。样本仅示范判断，不自动新增整套美术设计。

## 限定范围的测试方式

1. 按用户限定集数提取段落目录，检查集号边界与顺序；不借范围外小传或结局识别当前未知对象。
2. 阅读范围内文本后选少量代表性样本，覆盖事实不足、别名、状态、母子空间、关键道具和易串项边界。
3. 每个样本给出可用描述、依据、缺口与应排除的错误补充；不用输出本范围全部资产。
4. 将机器检查与语义判断分开。程序核来源引用、范围、父子和候选，不证明自然语言事实正确；人工回原段核对。
5. 仅列举部分出场证据时标“样例证据，非完整出场统计”；没有全量资产覆盖表时，不宣布漏项率为零或全20集资产全部整理完成。
6. 测试只产出样例数据和报告，除非用户另有要求，不生成全资产Excel或媒体。需要验证新导出逻辑时另选最小工作簿，不覆盖旧版。
