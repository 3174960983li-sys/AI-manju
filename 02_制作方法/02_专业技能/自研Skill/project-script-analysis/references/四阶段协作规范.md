# 项目分析 导演 分镜 视频提示词共同协作规范

接口V2.0｜2026-10-27｜四阶段主链及可选TIG辅助。此处只维护共同依据、决策权与修改传播，专业设计各在所属包维护，不另造全套审批系统。

## 1 架构与决策主责

| 阶段 | 主责与交付 | 下游必须收到 | 留给下一阶段的空间 |
|---|---|---|---|
| 项目剧本分析 | 明确有效文本、因果、人物知识、世界约束、表达义务与准备需求 | 原文范围、采用修补、目标/硬约束、关键问题和初末态 | 导演选择讲法；分析候选不等于导演锁定 |
| 导演思维 | 选择观众经历、戏剧重点、表演、调度、声画与节奏原则 | 导演意图、刺激/行动/反馈、必须读到与暂缓信息、保持项/自由度 | 分镜设计景别组接、机位、构图、运动、镜长与剪辑；导演已明确锁定的手段除外 |
| 镜头语言设计 | 把当前场面转为有表现力且可执行的镜头组和七列表 | 段落共性、稳定镜号、起中末画面、动作与运动、原句/声音、切点/末态 | 提示词负责去歧义、任务组织与实际绑定，不重新导演 |
| 视频提示词制作 | 将有效镜头编译为可复制任务正文，明确实际输入与依赖 | 镜号—任务映射、实际发声范围、素材职责、首末态与未适配条件 | 实际生成、声音、剪辑与审片按具体请求执行，不因写出提示词自动开始 |
| TIG角色站位图 | 按需表达某镜/阶段的几何与身份键 | 来源版本、镜号阶段、观察侧、真实图状态和适用范围 | 不决定剧情，不替代世界布局、分镜或成片关键帧；不是第五个必经阶段 |

共同数据只有一份当前采用内容，可以在不同阶段引用。导演本、文字分镜、提示词各有必要形式，但不能各自维护不同的剧情事实。Skill版本、作品版本、图稿版本和生成任务版本分开。

## 2 优先关系与约束分类

用户当前有效要求和授权 → 作品已确认事实/版本及本次修改范围 → 当前选定方法 → 通用默认。参考书、教程、示例和其他Skill的偏好不自动成为项目要求。

先区分三类条件：故事事实/对白/知识/重要揭示，已选导演体验与明确锁定手段，可由当前阶段自由设计的实现。只有明确被锁定的手段才作为必须保持；“重要信息要清楚”并不等于锁定一个固定中景。换一种可行构图、运动或普通摆位而不改保持项，可以自主设计。

用户指出旧分镜不满意并要求重做，受影响的镜头选择就是本次可改范围。不能继续拿旧稿当锁定约束；新稿仍标待审，不把重写完成等同用户采用。

原文和制作采用文本区分，已采用修补不因“保留原文”回滚。新版材料与已采用结果冲突时定位差异，按有效要求处理，不擅自混拼。人物知情、观众可得信息、制作人员掌握事实分别保存。

## 3 通用执行次序

核本次任务与保持项 → 构思并选择表达 → 联合安排动作/空间/观看/声音/时间 → 检查表现力与可读性 → 检查事实和接口 → 交付及必要局部修订。创作和检查会往返；既不能先堆禁令取消设计，也不能为大胆摄影忽略已知空间冲突。

各阶段只使用一个主流程。辅助Skill提供对应方法，不携带另一套格式、镜数、画幅、审批或平台默认。角色可由同一Codex承担，不代表自动创建多个Agent。

## 4 最小交接

普通任务一段说明即可；复杂任务按场/镜排列，不要求数据库或每次一套新台账。

1. 当前作品、制作文本和本次交付版本/消息，实际覆盖范围与下一起点。
2. 已采用、待改、候选、未知；所选方案及本次获准修改范围。
3. 导演目标、必须可见可听/暂缓的信息、锁定对白和结果、手段自由度。
4. 首末态及相关人物知识、位置、持物、身体/环境与声音；真实素材用途和适用范围。
5. 已做的检查、未验证条件、影响哪一步的实质缺口与下一动作。

需求、真实文件存在、已检查适用、用户采用、平台绑定、生成效果通过分别记录，不能互相替代。普通非关键细化可以直接完成；重要故事/风格取舍、不可查明关键条件或新费用等才按实际情况提问。

## 5 单位 结构与时间

场次、戏剧节拍、整理段落、连续镜头、关键画面、生成任务和剪辑源段是不同单位。一个连续镜头内可以有多个景别与行动节点；节点不自动代表切镜。一个任务可含多镜，长镜分任务不能暗加切点。

本体系文字分镜采用七列：镜号/时间、镜头任务、起幅与构图、主体行动与场景动态、摄影机与光学、声音与对白、落幅切点承接。Word可用同义竖排七项。专业方法维护在分镜和表演手册；不为接入新知识再加一套表格。

视频提示词默认六职责模块，完整格式仅由video-prompt-authoring维护。七列与六模块是转译关系，不是竞争结构。其他作品已指定格式时按作品要求适配，不能覆盖其五列表或其他有效约定。

区分目标、预算/估计、试读/预演和实测。时间由动作、对白、观看和节奏共同设计，不能平均分配、最短优先或用平台上限代替切点。连续对白可跨镜，最终发声逐字完整且不重复。

## 6 采用与继续范围

默认文字分镜逐段审阅。用户明确要求多段或整链草案时覆盖其范围，不人为插入逐步确认；若明确要求逐段批准则保留该边界。“按这版出提示词”已含采用指向稿和分支请求。只说“可以”不等于自动选择故事板、媒体生成或上传。

故事板、TIG图均为可选。导演输入已经足够描述镜头时可以直接编译；不足时补当前所需镜头设计并标其候选状态，不强迫从头重跑，也不冒称已有确认分镜。

## 7 修改传播与冲突处理

| 问题与证据 | 首先处理哪层 | 应同步哪些内容 |
|---|---|---|
| 文本因果、身份、数字或知情矛盾 | 分析/制作文本 | 受影响小传、场次、导演与下游，不动无关部分 |
| 目标体验、人物策略、关键调度互相冲突 | 导演 | 所在场、相关镜头、首末态；具体取舍有理由 |
| 景别单调、机位/运动/清晰/切点不能有效表达 | 分镜 | 镜头组及相邻接口；在自由度内直接修，不默认退回固定 |
| 图稿位置/视角错误或过期 | TIG与源分镜 | 对应镜号阶段、身份键和引用图的任务 |
| 运动、表演、原句在转译中丢失 | 提示词 | 对应任务，保留源设计，不因便于生成改镜头 |
| 素材偏离、剪辑丢失或反馈不符 | 据实际媒体定位 | 输入、工具、源段、剪辑或设计，以观察证据为依据 |

措辞修正不撤销采用；实质改变镜头或状态时标受影响范围、旧新映射和需回查项。上游改动让相关下游待回查，不代表所有旧素材无用。未知模型能力列为具体试验，不因未知删核心内容，也不保证能实现。

## 8 旧体系如何接入

旧S1对应当前分析；S2和S3分别提供整体导演与逐场行动/空间；S4对应分镜；S6应拆清提示词编译、实际生成和源片审查；S5仍为资产准备支线。旧T/A/G编号仅在明确采用旧项目契约时有效，不自动成为通用前置。

旧七栏按语义映射：镜号时码→第一列；任务→第二列；摄影设计→摄影机与光学并补起幅；画面表演→主体行动；场景光影→段落共性、起幅及场景变化；台词声音→第六列；衔接备注→第七列。不能按相同列号直接覆盖，新旧均称七栏也不代表内容同位。

旧“只读”来源保持历史身份。新流程的专业方法以本次发布入口和三手册为准，未迁移作品仍用自身有效约定。SOP总控管任务与共同对象，本规范管本链交接，专业手册管设计；层次不同，不互相重写授权。

## 9 分发与验证

同级包齐全时用相对链接；缺包仍可依据足够材料完成当前阶段，本地必要方法自含，不能假称调用了缺失Skill。参考书/本地知识链接是可选来源，不应当成为包离开E盘后无法运行的依赖。

每次系统发布至少做同一输入的完整文字链，另查主动运动、特殊复合运动、表演可读性、缺图/缺平台、局部修改、旧栏映射和输出范围。实际产出与审阅设计内容，链接和哈希只能证明结构及文件完整。

文字自查、用户采用、独立评审、平台适配、媒体验证分开。本规范不宣布任何旧试跑自动证明新版效果。
