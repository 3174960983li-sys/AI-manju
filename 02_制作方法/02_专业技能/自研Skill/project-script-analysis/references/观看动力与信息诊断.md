# 观看动力与信息诊断

V1.3新增方法。用于检查剧本能否提供预期体验的必要条件，不替导演指定全部视听实现。

## 先分清三件事

人物的情绪、创作者希望观众的体验、实际观众的反馈不是同一件事。人物平静可以使观众不安；人物哭泣也不能证明观众关心他。没有观看反馈时，只能提出有依据的设计假设。

先沿原文说明：发生什么→谁想做什么→采取什么行动→结果或认识怎样改变。再检查需要观众看见、理解、相信、关心和期待的内容。只展开影响当前判断的维度，不给每场强填六问或情绪分数；氛围、观察、幽默、余韵和低强度投入均可成立。

## 从原文到诊断

1. **明确本段观看目标。** 使用项目已选方向，写成具体体验，如“观众知道她要离开，但要到回答后才明白这是永久离开”。目标未定时给候选，不将自己的偏好升级为锁定项。
2. **核观众实际可得的信息。** 区分原文事实、人物知道/以为、观众可见可听及可能推测。小说写出的心理不等于视频已表达；尚未拍出的方案也不等于观众已理解。对关键节点注明应该何时知道、何时仍未知。
3. **核观看动力的条件。** 关切依赖哪些愿望、关系、选择或后果？期待指向哪个答案或行动结果？好奇可以来自新奇和理解，不一定需要危险；知道结果后也可能仍关心过程，不强行增加未知。
4. **核推进与兑现。** 等待期间是否有必要观察、尝试、关系积累、信息变化或消化？不能仅因没有反转判为拖沓。已有承诺是否在约定范围得到回应？阅读范围之外的回收保持未知。完整兑现后允许结束，不强加新钩子。
5. **定位缺口并提出最小处理。** 原文缺因果前提、表达尚未设计、实际素材未表现、剪辑没有保留，是不同问题。分析阶段先区分已知与待验，不能未看成片就认定剪辑失败。补动作、改对白、提前揭示等如影响故事或已锁方案，列为候选讨论，保留原稿。

## 交给导演什么

放入原有项目理解、逐场要点和交接段，不另建全套“情绪台账”。关键内容可简写为：

> 目标体验与采用状态；原文依据；观众必须读到/仍不能确定的信息；人物知情及行动结果；尚缺的表达条件；后续怎样检查。

“怎样检查”是验证问题，不是预先通过。例如“试看者能否说明她为什么急于修好”比“这里一定感人”更可核验。导演决定通过什么观看顺序、表演、空间、声音与节奏实现；本阶段不因此生成逐镜表。

## 失败回查示例

“观众不在乎音乐盒”：先查是否理解女孩为什么要修、修好对关系意味着什么。若剧本已有，不能直接补病危或死亡设定；应交导演检查这些条件是否被有效表达。若成片线索太小或对白被遮盖，优先修素材与采用方式，而不是重写人物小传。
