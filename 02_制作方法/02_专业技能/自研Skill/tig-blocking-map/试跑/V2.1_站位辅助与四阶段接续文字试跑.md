## 1. 原始测试输入与分析需求

新编测试制作文本R1：林站在店内工作台外，右手拿着未拆信封，陈在台内看着林。林把信封放到台上，随后从门离开；陈没有走动，信封留在台上。

测试预设：导演D1、分镜S1为本例有效候选。单镜SC01-S01，固定中景，一镜到底；当前画面工作台居左、门在右，台外前侧有通向门的通路。林起始在画面左前，陈在右后、下身被台面遮挡；林沿台外通路走向右侧门离开。未知两人关系、信封内容和陈的心理，不能补成告别、背叛或认可。

分析阶段只交需求：需读清信封放下后留在桌上、林确实离开、陈未走；原文无台词。世界布局未给精确尺寸，不从画面左右推导真实距离或建筑平面。

## 2. 导演与分镜交入

导演任务：连续观察交付与离去，保留陈反应的含义未知。保持项：未拆信封、不新增对白或回应动作、信封归台、林出门、陈不动。固定机位与连续观看在测试中锁定，不能为站位图方便而切镜。

分镜必要执行信息：起幅林右手持信封，陈在台内，门与通路可辨。林把信封放稳并松手，再沿台外通路去门口退出；陈留在原位，不接信封。相机固定，桌、门的画面位置连续。落幅林已画外离开，陈仍在台内，信封仍完整地在台面。没有实际测时。

站位设计选择：复杂度不高，纯文字已经可用，本次为验证分支而按测试请求提供起/末两态图提示词。两图为同一镜头的阶段，不代表增加两次剪切，也不能用初态图锁死林的离开。

## 7. 逐项检查与异常判断

| 情境 | 实际判定 |
|---|---|
| 初态两人、末态一人 | 两份提示词已分别写清，未把离场人物画回末态；A始终指林，B始终指陈 |
| 信封在手到台面 | 两态与连接段都保持一份未拆信封，没有复制或交给陈 |
| 两态图是否增加剪切 | 两份提示词及连接段均按同一固定单镜，未加切镜 |
| 有无虚构绑定或图像通过 | 只有逻辑图号，无原生@句柄；明确无图、未检查、未绑定 |
| 纯文字可否直接提示词 | 可以；本场文字充分，不因新增Skill强迫做图 |
| 原图若只见陈上半身 | 实际任务应保留裁切与遮挡；本轮无源图，只验证文字规则，不能报源图提取完成 |
| 改机位至另一侧 | 需分镜明确新观察与空间承接，再重算位置/遮挡及图的适用；不直接镜像旧图，也不保证任意跨轴剪切成立 |
| 改蓝色为紫色但站位不变 | 更新人物键及相关素材说明，不因此重写剧本或撤销导演采用 |
| 图把信封画在陈手里 | 改变关键归属，图不合格；先修图或不用该错误图，不能说文字一定压过去 |
| 图附带白底，项目风格不同 | 只取几何，外观按项目有效依据；仍需真实视频检查污染，不能承诺消除 |
| 摄影机路径仅有屏幕箭头 | 不据此推导世界推轨轨迹或距离；需另有空间条件 |
