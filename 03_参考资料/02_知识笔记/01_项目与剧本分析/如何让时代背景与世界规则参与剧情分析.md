# 如何让时代背景与世界规则参与剧情分析

**背景分析的结果，应当说明人物在这个世界里能做什么、不能做什么、为什么需要付出代价。**只列朝代、服装、建筑，尚未完成故事分析。

操作主线：**确定背景边界 → 抽出影响行动的规则 → 核关键事件是否成立 → 找到制作与研究需求。**

## 一、背景为什么会改变事件

《故事》第三章从时代、故事经历的时间跨度、地点和冲突层面理解背景，并强调虚构世界也有可能性和因果约束。[S1·L661—697]

例如“主角无法求救”可能来自通信条件、制度限制、空间阻断或个人选择。原因不同，行为、道具和声音都不同。若只把背景理解成视觉装饰，常会出现角色本来可以轻松求助，却无缘无故陷入绝境的问题。

本文将四项背景检查具体化：

- **时代：**故事位于哪个时期，或者明确架空？
- **故事跨度：**事件实际经历多久？它不是片长，更不是交付期限。
- **地点：**真正影响行动的场所与路径在哪里？
- **冲突层面：**阻力主要来自自己、人际、制度或环境，如何实际作用？

无需每项扩写百科。先辨认会改变行动判断的条件。

## 二、怎样执行背景分析

### 1. 分开原文、事实研究与候选设定

先提取原文明确条件，再列需要核实的现实或历史事实，最后才列创作补充。参考电影的美术不能证明历史制度；原文缺年代时也不能因某件模糊道具便锁定朝代。

**产物：**已知边界与未知项。影响关键事件的未知优先处理。

### 2. 从关键行动反查规则

逐项问：谁想完成什么？需要什么资源、权力、时间或通路？什么阻碍使它困难？原文有没有建立限制或例外？

若没有相关规则，先说“未说明”，不能直接判逻辑错误。若已有规则却被某事件无解释突破，再定位冲突。规则发生变化也可能成立，前提是作品给出相应依据。

**产物：**规则—相关事件—支持证据—缺口。

### 3. 检查例外是否靠临时方便

同一能力在前场能用、后场突然不能用，要查条件是否变了。成立条件、消耗和代价都可能解释变化；如果只为拖延剧情而临时失效，就应提出问题候选。

幻想不要求复制现实规则，但要求读者能理解本作品选用的规则。作者的“幻想严格”主张不应被转成禁止梦境、寓言或有意非因果叙事的统一禁令。

### 4. 将缺口变成有限研究与制作任务

只研究会改变当前决定的事项，并明确完成点：需要确认哪条事实，影响哪场，得到什么证据便能继续。事实核查、项目设定和美术方案分别记录。

麦基同时提醒，研究要与创作交替，资料积累本身不能取代事件设计。[S1·L719—763] 因而研究不必等全部背景知识齐备才开始工作；不依赖缺口的整理可继续。

**产物：**具体场次、问题、研究任务、资产或声音需求及待定选择。

## 三、完整例子：暴雨山站为什么不能求救

新编输入：当代山间值班站，故事跨一夜。暴雨后停电；主角想报警。剧本写手机没有信号，墙上另有对讲机，后场主角独自冒险去找人。

1. **背景边界：**当代、一夜、偏远站点；没有明确地理位置和设备规格。
2. **关键行动：**求救。手机无信号已解释一种方式，但对讲机是否能用尚未说明。
3. **规则检查：**现阶段不是“对讲机肯定可以报警”的事实，更不是“停电必定让它失效”；两种推断都缺设备与原文依据。
4. **处理候选：**询问或查原稿是否交代通信范围、供电或呼叫结果；若要新增故障原因，作为提案讨论。原文没有真实地点时不做无关地理长报告。
5. **制作交接：**一旦采用“尝试呼叫但无回应”，需要相应动作、设备与声音职责；它仍是候选，不自动写入原稿或生成媒体。

结果是一项可执行的问题，而不是一句“加强环境压迫感”。

## 四、何时停止扩展背景

当前关键事件已能判断，影响制作的事实有足够支持，剩余疑问不改变本轮交付，就可以结束本批研究。没有必要先补完世界每条街和每个角色的家谱。

背景改变时检查受影响事件、资产、声音和人物知识。项目整体时代未变，不代表某个新通信道具可以无条件加入。
