# 如何把心理叙述转成视听表达需求

**先确定这句心理叙述承担什么信息，再选择动作、对白、声音或旁白怎样承载。**不能看到“内心活动”就删掉，也不能一律改成皱眉、流泪和特写。

操作主线：**确定叙述作用 → 区分谁知道 → 选择表达渠道 → 检查新增内容与理解结果 → 交给导演和制作。**

## 一、为什么必须先辨认信息，再找动作

《为银幕写作》强调视觉造型、声音和时空组织。[S2·P11—36] 它提醒我们，文字需要转成视听体验；但不能据此得出“所有心理都必须直接变成可见动作”。声音、明确获准的旁白、信息延迟和人物行为，都可能承担不同任务。

例如“她知道来人说谎”至少含两个可能目标：告诉观众她已经识破，或只说明作者给她的行动依据。两者如果混淆，就可能过早泄露悬念。

## 二、五步形成处理候选

**1. 提取这句话真正负责的信息。**它在交代事实、判断、情绪、回忆，还是一条行动动机？同一句可能有多项职责，但先说明当前剧情需要哪些。没有作用依据时回看前后文，不急于找替换表情。

**2. 画清知道与不知道的边界。**人物知道什么、观众该知道什么、其他人物是否知道？原文内部揭示不一定是观众此刻应获得的信息。只有局部片段就记录未知，不自行锁定悬念方案。

**3. 选择承载渠道。**

| 信息需要 | 可考虑的渠道 | 容易出现的问题 |
|---|---|---|
| 展示策略与态度 | 行动、反应、对白及其配合 | 单个动作含义可能不够明确 |
| 传达精确信息 | 对白、文本、获准旁白或明确情境 | 擅自新增台词、字幕或设定 |
| 保留人物感受而不揭底 | 声音、节奏、行为变化或延迟说明 | 用抽象气氛代替必要信息 |
| 作者背景资料，当前无需观众知道 | 保留在人物/导演资料中 | 把所有背景都硬塞进画面 |

这里是选择工具，不是唯一映射；重要渠道改变须符合用户的表演、旁白及改编边界。

**4. 检查是否偷偷改了剧情。**新增某个证据、动作或声音，是否改变人物知识和因果？原文只说怀疑，不能让角色看见确凿证据后仍称最小外化。如果准确性不足，保留几种候选及代价，先讨论。

**5. 输出叙事义务与候选方案。**先写观众必须理解什么，再写实现选项。不在分析阶段直接锁死特写、焦段、秒数和生成工具。

## 三、完整例子：保留“怀疑”，别改成“实锤”

新编原句：“她听完他的解释，仍怀疑他来过这里，于是暂时没有交出钥匙。”

1. 必要信息是怀疑仍在，并影响交钥匙的选择；不是已经证明对方说谎。
2. 她知道的事实只限于输入；观众是否应知道对方真正来过，尚未提供。
3. 可以提出“她回应解释，但将钥匙握住，暂不递出”的行为候选；能否让观众理解怀疑，需要结合前场。
4. 不能为了表达明确，就新增监控录像或鞋印实证。那会改变她掌握的证据与故事状态。
5. 导演本应写：“保留她对解释的不信任及暂缓交钥匙的因果；具体动作/声音表达待定。”若原稿台词锁定，不自行增加“你在骗我”。

边界：若钥匙本来不在她手里，这个候选不成立；先核持物状态。若悬念要求观众暂时不知道她怀疑，就应重新选择表达方式，而不是沿用上述显化方案。

## 四、完成标准

能指出原句信息由哪里承担；人物与观众知识没有混乱；新增内容明示为候选；下游知道该呈现什么，却仍有镜头设计空间。

这与[场景精炼](如何使场景精炼_新版样稿.md)衔接：先确保信息得到承载，再压缩重复表达；不能先把心理全删掉再指望演员自行补回。
