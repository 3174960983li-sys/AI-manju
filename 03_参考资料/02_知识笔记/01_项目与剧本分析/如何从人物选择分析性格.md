# 如何从人物选择分析性格

**人物小传里的形容词只是起点。要判断人物怎样的人，先查他知道什么、想保住什么、有哪些选择，以及选择之后承担了什么。**

分析主线：**身份与表现 → 当前处境 → 可行选择及代价 → 实际行动 → 有限结论。**最终结果应能回到剧本行为，而不是为人物补一套看似完整的心理档案。

## 一、为什么身份和性格标签不能代替分析

麦基在《故事》第五章区分可观察的外部特征与通过选择揭示的内在倾向，并强调压力、风险会影响选择的揭示力。[S1·L1025—1045]

这一区分给分析带来的价值是：职业、衣着、口吻可以解释一个人处在怎样的世界，却不能自动证明他在利益冲突时会怎样行动。“警察”不等于勇敢，“说自己诚实”不等于会承担说真话的代价。

但“压力越大越真实”是该作者的创作观点，不能直接当心理学定律。人在极端情境中的反应也受知识、能力、误判和强迫影响。本文将它用于寻找有揭示力的叙事选择，不用它给现实人物下人格诊断。

## 二、怎样分析：先完成选择，再写性格

### 1. 分开四种证据

先从原文摘出身份资料、本人宣称、别人评价和实际行为。它们可能一致，也可能冲突。某角色说“他不会背叛我”，只能确认该角色的认识，不能直接写成对方的真实品质。

**产物：**有位置的事实与评价，避免将台词当作者认证。

### 2. 还原作出选择的当时

检查人物当时知道什么、想得到或保住什么、面临什么风险。尤其不要用观众后来知道的真相责备人物：角色不知道箱子里有炸弹，就不能分析为“故意让同伴送死”。

**产物：**本场欲望、知识范围、压力及损失；没有依据的动机留为候选。

### 3. 检查是否真的存在不同选择

列出原文明确或情境支持的可行选项。一个人被锁在屋里，没有逃离途径，“没有逃跑”未必证明勇敢。能力不足、不知情与主动牺牲必须分开。

如果只能确认行为、无法确认其他选项，就先描述行为及结果，不强行提升为性格结论。

**产物：**选项、代价、可行性与未知。

### 4. 写出选择支持的最小结论

使用“在什么处境下，他选择了什么，承担什么，因而支持怎样的理解”。一场戏可支持某种倾向，尚不足以证明这个人在所有情境下一贯如此。跨场行为一致时结论增强；出现相反行为时查条件、动机或是否发生变化，不急于判崩人设。

**产物：**带依据和适用范围的人物解读，可放进小传或导演处理。

## 三、完整例子：同样是交出记录，人物含义可以不同

新编教学情境：小陈发现一份错误记录。主管要求隐瞒，明确说公开会使小陈失去晋升；小陈知道这一后果，仍向复核人员提交原始记录。

1. **证据分类：**主管提出威胁、小陈知情、提交原件，都是给定事实；“天生正义”不在原文。
2. **处境还原：**他要处理记录错误，同时面临晋升损失；原文未说明是否另有利益。
3. **选择检查：**隐瞒与提交均由情境给出，可行性比单纯“他没有逃”明确。
4. **分析结果：**在已知个人利益受损的情况下，他仍提交原件，支持“此刻将纠错置于晋升之上”的人物理解。它尚不能证明他从不说谎，也不能擅自补写童年经历。

边界变化：如果原文补充“他以为提交后会获奖”，付出代价的知情条件就改变了。若他被强制搜身取得文件，也不能称为主动提交。同一结果不代表同一选择。

## 四、导演本里怎样落地

建议压成四项：**当下目标／已知信息／关键选择及代价／支持的人物解读与待确认项**。普通配角可以一句话完成，不要求全员长小传。

表演交接应指向选择过程，例如“他听到晋升威胁后仍提交记录，需要让观众理解他听懂了风险”；怎样拍、停顿多久留给下一步设计。不把分析新增成原稿对白。
