# 如何把导演主张变成可判断的场面设计

**导演主张要能决定观众怎样理解这一场，并帮助你在多种拍法之间作选择。**如果换掉一句主张，表演、信息和空间设计仍完全一样，它就还没有成为有效的导演方法。

操作主线：**明确人物要完成的事 → 确定观众要形成的理解 → 选择承担表达的事实与关系 → 检查每项手段是否必要。**

## 一、主题、人物任务和导演主张不是一回事

“讲离别”是主题范围；“把钥匙交还后离开”是人物在场内的任务；“先让交接显得平常，再让观众通过离开前的停留重新理解两人的在意”才是在选择体验的组织方式。

后者不是剧情新增事实，而是对原有行为的解释和呈现。它仍可能读错剧本，因此要能回到具体动作核对，不能只靠一句漂亮隐喻成立。

《导演功课》第一章强调，画面之间的组织能够使观众形成理解；第四章把场景目的、简单动作与拍摄判断联系起来。[D1·印刷12—18、63—71页] 本文采用它的目的意识与表达精简，不采用“所有作品必须依靠某一种剪辑方法”的强规则。

## 二、四步形成能用的主张

### 1. 先锁定叙事义务

从有效原稿提取：发生什么、谁知道什么、结果是什么、不可改的台词和信息揭示是什么。只列本场需要守住的条件。

原文没有写清的关系可以提出解读，不能补成事实。主张依赖尚未确认的关系时，先说明条件；其他可独立处理的部分继续。

**产物：**本场必须成立的行为、信息与结果。

### 2. 决定观众理解的起点和终点

分别写“观众开始把它理解为什么”“结束理解发生什么变化，或什么感受得到累积”。没有变化的场也可能成立，例如建立空间或维持等待；应说明停留的意义，不硬造反转。

**产物：**一条具体体验路径。别只写“更感人”“更紧张”。

### 3. 让原有事实承担表达

选择哪些行动、回应、距离、声音或信息关系足以支持路径。既可以依靠同一空间里的连续行为，也可以依靠不同画面之间的联系。

《场面调度：影像的运动》第一章讨论叙事、戏剧重点和画面因素，以及连续调度与剪辑组织的多种方式。[D2·印刷4—8页] 因此不把“画面关系”窄化为必须多切镜，也不把长镜头当作导演深度的证明。

**产物：**每项主要处理的表达职责，以及不能遮掉或省略的信息。

### 4. 用删减和替代检查主次

问：拿掉这项设计，观众理解会损失什么？另一项更简单的设计能否完成同一任务？现在的方案是否反而泄露秘密、误导关系或制造不必要的制作困难？

装饰性设计不一定不能有，但要承认其作用是形式或审美，而非伪装成叙事必需。若一项核心理解只能由导演口头解释、方案内没有证据，就要补设计或缩小主张。

**产物：**推荐处理、理由与代价，不需要用无依据评分表排名。

## 三、完整例子：怎样让交钥匙承载告别

使用本项目教学场景《交钥匙》：手续已经办完，小林交还钥匙，走到门口又提醒门怎么关，陈姨回答“我知道”；小林离开，陈姨看钥匙并合手。不是任何现实人物的记录。

1. **叙事义务：**先交钥匙，后离开；不新增挽留台词或亲属关系。
2. **体验路径：**从普通交接到理解这次交流有未说尽的在意。这是候选解读，不声称二人必有深厚旧情。
3. **表达依据：**原稿已有“将走又停”和“人走后看钥匙”，不必再增加一段回忆证明情感。
4. **取舍结果：**交接顺畅，转身后才短暂延缓，关门后留下反应；不在每一句话后加停顿。若拿掉离开前的停留，只剩事务性提醒，主张就更弱；若加孩子笑声，会新增未经授权的关系暗示，应排除。

这个过程既产生导演选择，也产生结束条件：观众能够读到停留与离开的区别，不要求必须流泪。真实效果仍需表演或样片验证，文字解释不构成观众反馈。

## 四、交给分镜时保留什么

交接“必须看懂的行为及先后”“信息在何时被掌握”“允许变化的视觉组织”“场尾保持项”。镜头数量、焦段、精确切点仍给下游选择。
