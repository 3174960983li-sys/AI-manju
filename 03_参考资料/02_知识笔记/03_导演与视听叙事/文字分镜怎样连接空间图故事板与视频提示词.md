# 文字分镜怎样连接空间图、故事板与视频提示词

**三个阶段应共享同一套已确认行动与空间；改变的是表达形式，不是故事事实。**故事板可用于检查，但不是直接编写视频提示词的必经环节。

操作主线：**文字确认 → 核空间锚点 → 按需选择故事板或提示词 → 检查版本和职责 → 只修受影响部分。**

## 一、几种图的职责不同

| 材料 | 主要解决什么 | 不能证明什么 |
|---|---|---|
| 俯视平面图 | 门窗、家具、人物与路径的相对位置 | 不等于镜头实际看到的构图 |
| 鸟瞰/透视空间图 | 建筑形体、空间层级与方向感 | 不等于无透视的精确平面布局 |
| 故事板 | 某一镜的观看关系、行动和必要运动说明 | 不保证最终人物美术或动态结果 |
| 最终关键帧 | 成片身份、风格、材质与具体画面基准 | 单张图不证明动作过程和声画完成 |

《image2场景一致性》示例同时有动作分镜、平面图、多视图和鸟瞰图。[T3·T1—T7] 图像漂亮或标注多，不意味着它已经同时承担所有职责。其宫殿例的提示写“完全平面”，实际抽看图有透视，说明必须看结果，不能只读提示词就给通过。

## 二、文字确认后怎样进入可选分支

### 1. 提取跨阶段必须保住的内容

镜号、人物身份、行动起止、持物、空间地标、观众信息及关键声音要与采用稿对应。复杂场景可补最小空间锚点；用户不需要图时，文字锚点也可用。

不把这个步骤变成要求全员四视图、全场景九宫格的前置工程。只补会影响当前镜头判断的资料。

### 2. 需要故事板时，分清箭头与主体

标清摄影机路径、人物路径和交互/飞行方向；图例随图可读，颜色只是辅助，文字标签也要能分辨。一个镜头内有几个关键构图，就按实际需要展示，不把一格等于一镜变成硬规则。

教程的红/蓝/绿等箭头区分值得借鉴，但它的3×2、4×3布局以及具体焦段、时长和角色名只属于示例。原文中3×2却要求“12镜”的数量冲突，应先纠正交付映射，不能凭模版套用。

### 3. 不需要故事板时，直接编译提示词

使用确认稿及真实可用素材，注明每份参考锁什么：身份、空间、构图、动作或风格。平台图号由实际输入槽位决定，不能复制教材里的`@@图片1`等绑定。

提示词需要画幅、时长或平台参数时按实际要求核对；未定可提供条件式通用稿，不假称已适配。写提示词不是提交视频生成的授权。

### 4. 发现冲突时回到最早出错层

图中门窗变位或人物站位不一致，先核空间与版本；不是靠追加更多“保持一致”就算解决。原文字动作本身不成立，则标出镜号、影响和修改候选；用户确认后才更新设计性变化。

只有某格图错了不必整段文字重做。反过来，文字末态改变时要检查依赖它的下一段、故事板和提示词，不能继续混用旧状态。

## 三、完整例子：文件交接跨阶段保持什么

新编例子：甲递文件，乙看见标记后抬眼。

文字确认稿需要保住“文件从甲到乙、标记触发反应”。空间图只需交代表达所需桌位、人物位置和观察通路。故事板可用交接前后或抬眼前后的关键构图表达变化，但不能换手、反转标记朝向或让乙在看见前惊讶。

若直接出提示词，仍需说明文件起止持有、标记可见性、反应触发和结束状态；不因为跳过故事板就省掉这些关系。若用带箭头故事板作参考，应说明它是调度参考，不当作最终美术图；箭头会否污染生成结果要实际观察，不能保证一句“去掉箭头”必然解决。
