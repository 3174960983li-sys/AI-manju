# 如何把情绪要求转成可执行表演

**先告诉表演者此刻要完成什么，再确定哪些行为及反应使观众理解这一点。**“更悲伤”“更有压迫感”可以描述目标，却不足以独立指导动作。

操作主线：**人物任务 → 可执行行为 → 对方或环境的反馈 → 策略变化 → 行为完成与结束状态。**

## 一、情绪词为什么常常不够用

同样是紧张，一个人可能急着解释，也可能刻意缓慢，或者停止说话。只写紧张，不能决定当下行为；再堆抿嘴、吞咽、眨眼，也不保证符合人物。

《导演功课》第四章主张把指导落在简单动作上，反对让演员在每个动作里装载整场主题，也强调人物言语与其欲求有关。[D1·印刷63—66、69—71页] 可用之处是减少结果性指令，明确任务；不必因此拒绝人物目的、感受与关系，它们仍帮助导演选择合适行动。

**要区分给导演的理解依据与给执行者的当下任务。**“她怕再次被拒绝”是解释；“她问完后等对方回答，不抢着替对方答”是可以执行的安排。解释是否有原文依据，安排是否符合人物，两者都要核。

## 二、五步写出表演处理

### 1. 明确要改变的对象

问：角色希望对方做什么、相信什么、停止什么？独处时希望处理什么？任务太泛就缩到本场。例如“想获得爱”不足以安排一次交谈，“让对方答应留下来吃饭”更具体。

没有原文依据时不替角色锁定深层欲望。可以给候选并说明差异。

### 2. 选择行为策略

试探、催促、安抚、避开、转移话题、争取配合等词可帮助描述关系行动，但仍需落到具体行为。不能只把“愤怒”替换成“威慑”便称完成。

**产物：**角色对谁做什么，以及原稿中哪些话或动作承载它。

### 3. 规定真正触发变化的事件

是对方没回答、一个声音响起、道具没找到，还是新信息被理解？先后必须成立。角色不能在知道消息前提前反应，听者也不必每次都夸张反馈。

若没有策略变化，不为凑情绪弧线硬加一次爆发。

### 4. 简化动作，检查身体与空间

只保留承担表达的行为和必要衔接。手拿着什么、注意力在哪、动作是否有支撑与结果，应当清楚。相互矛盾的指令应作取舍，例如既要他隐藏钥匙，又要对方清楚看见钥匙。

动作强度由人物与风格决定。“简单”不等于全员克制，也不等于限制所有动作：有任务依据的激烈冲突可以保留。

### 5. 用完成条件决定是否需要继续

检查任务有没有传达到对方、反馈有没有发生、场面该继续还是结束。没有实际排练就写待验证；不要为了“自然”无限重做，也不规定每场固定几次试演。

最终产物：**刺激与目的、具体行为、反馈及后果**。复杂场面可补起止状态，普通场面用连贯文字即可。

## 三、完整例子：一句“我知道”怎样处理

教学场景《交钥匙》里，小林提醒门有点涩，陈姨回答“我知道”。原稿没有说明她受伤、责怪或故作坚强。

- **任务：**接收提醒，让这次交接可以结束。这是本版导演处理，不是人物一生的心理定义。
- **策略：**平常地回应，不抢话，也不另开话题。
- **触发：**小林原本走了又停下，她才重新将注意力交给他；听完再答。
- **行为：**用已给台词完成回应，不加叹气、挽留或强撑笑容的连续表情套餐。
- **完成条件：**回应被小林接收，离开能够继续；门关后再完成原稿看钥匙的动作。

如果导演要求“观众必须感觉她在责怪”，这与现有含蓄处理不同，需说明新的解读依据和代价，不能让模型仅凭一句话同时表演所有复杂心理。

## 四、AI仿真人应用的额外检查

人类演员的动作指导不能原封不动等同于模型可控能力。先写清人物任务，再写可见行动、触发与结束状态；进入提示词阶段才按具体工具改写。

微表情、持物接触和双人反馈需要实际验证，不能保证一个动作词就能稳定实现。不改变人物意图的实现简化可以提出；删掉关键选择或台词须讨论。
