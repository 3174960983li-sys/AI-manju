## 阅读顺序

1. 先读DirectorSKILL、中文七阶段SOP、waoowaoo：确定制作环节与交接。
2. 再读agentskills、Anthropic skill-creator、Spec Kit：统一节点与Skill写法。
3. 接着读Promptfoo、VBench：建立文本与视频两类检查。
4. 试点流程确定后再看LangGraph、MCP、ComfyUI、Langfuse：实现运行与观测。
5. 知识量或团队规模确有需要时，再评估LightRAG、Kitsu、OpenTimelineIO。
