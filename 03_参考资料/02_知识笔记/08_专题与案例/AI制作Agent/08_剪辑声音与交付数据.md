# 怎样让制作结果便于剪辑、验收与交接

版本V0.1｜2026-10-30｜状态：有来源的研究提炼，制作效果待具体任务验证。

视频文件只是交付的一部分。后续需要知道哪个版本可用、取哪一段、如何与声音相接、参考和生成来源是什么。结构化记录帮助接续生产，但不能代替最终播放检查。

<a id="G36"></a>
## G36 · 时间线记录媒体引用而非仅写描述

镜头顺序、素材版本、入出点、轨道与时间单位应明确。 “把镜头接起来”无法复现一次剪辑，也不说明实际用了哪个生成版本。

**本项目用法：**记录源素材、帧率或时间基准、入点与时长、放置位置及声音关联。

**教学示例：同一片段只取中间可用三秒，时间线应指向对应版本和取段范围。**

**适用边界：**OTIO是时间线信息工具，不是媒体本体或通用渲染器；采集的格式说明自标旧草案。

**检查办法：**交接者能定位素材并复原取段，实际导入另做验证。

来源：[S21](来源与阅读边界.md#S21)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G37"></a>
## G37 · 声音按持续关系组织

对白、动作声、环境声与音乐各自有开始、持续和结束。 画面切换不必让环境声同时断掉，持续声音也不能每镜重新触发。

**本项目用法：**写清声音来源、是否画外、跨镜持续位置与必要同步事件。

**教学示例：雨声贯穿两段镜头，人物进入室内后按空间变化调整，不简单重启同一雨声开头。**

**适用边界：**音乐是否存在和是否连续取决于创作；不采用来源的所有场景统一声床规则。

**检查办法：**分别听音频与看声画组合，核对台词、同步和接缝。

来源：[S10](来源与阅读边界.md#S10)、[S15](来源与阅读边界.md#S15)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G38"></a>
## G38 · 转场先确定叙事用途

转场可以通过形状、运动、声音或信息关系组织，但不是每次切镜都需要效果。 强制变形或叠化会给普通动作衔接增加无关视觉事件。

**本项目用法：**先判断是否有时空或叙事变化，再写清前镜落点、后镜起点和需要维持的联系。

**教学示例：从手中的圆形表盘切到墙钟，用可见形状建立关系；连续对话可直接切换。**

**适用边界：**来源偏创意视频，其三步变形和过渡帧要求不普遍采用。

**检查办法：**转场让信息更清楚，并未引入无意变形或时空误解。

来源：[S24](来源与阅读边界.md#S24)、[S10](来源与阅读边界.md#S10)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G39"></a>
## G39 · 交付需要可用段和来源关系

文件存在、生成成功与可交付应分开判定。 视频可能只有部分可用，或依赖文件遗漏导致别人无法继续制作。

**本项目用法：**登记实际可用区间、质量结论、输入版本、工具任务及最终文件；修改后更新引用。

**教学示例：SHOT_05_v3仅前四秒可用，剪辑清单明确区间，不将整段标为通过。**

**适用边界：**不要求每次都输出庞大清单；按本次交付对象保留必要信息。

**检查办法：**实际打开交付文件，检查引用、时长与用户要求相符。

来源：[S15](来源与阅读边界.md#S15)、[S21](来源与阅读边界.md#S21)、[S11](来源与阅读边界.md#S11)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G40"></a>
## G40 · 交接模板应服务下一步决策

只收集下游会读取、验证或据此行动的信息。 模板字段过多会造成虚填，过少则反复询问。

**本项目用法：**每个字段写用途；先用一次真实交接观察缺口，再删掉不被使用的重复内容。

**教学示例：镜头交接保留素材版本和入口出口状态，不重复抄整本导演知识。**

**适用边界：**团队或工具要求的必要字段应保留；模板不能覆盖项目既有表格格式。

**检查办法：**下游无需猜测关键事实，也不需要重新整理全部材料。

来源：[S14](来源与阅读边界.md#S14)、[S07](来源与阅读边界.md#S07)、[S02](来源与阅读边界.md#S02)。用法与示例为本项目综合改编，不是已验证结果。
