# 怎样检查结果并选择有效返工

版本V0.1｜2026-10-30｜状态：有来源的研究提炼，制作效果待具体任务验证。

质量检查应告诉你哪里有问题、证据在哪里、影响多大以及下一步改什么。分数可以帮助比较，却不能掩盖人物错误、关键动作缺失或素材丢失。本篇区分文本、视频和序列检查，避免用一个总分替代所有判断。

<a id="G16"></a>
## G16 · 生成前、片段后、序列后三层检查

输入可执行性、单段质量和连续剪辑效果应分别检查。 片段单看合格，不代表接在一起能成立。

**本项目用法：**生成前查事实与绑定；片段后查身份动作物理；剪辑后查方向、节奏、声音与信息理解。

**教学示例：两段各自人物正确，但接缝处杯子换手，只能在跨镜检查中发现。**

**适用边界：**检查方式随任务风险调整，来源的固定观看次数与分数不直接采用。

**检查办法：**记录每项在什么阶段被验证，不能只写“整体通过”。

来源：[S15](来源与阅读边界.md#S15)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G17"></a>
## G17 · 关键缺陷与评分分开

明确必须修复的问题，再使用评分比较其余质量差异。 画面很美可能拉高总分，却不补偿关键剧情动作错误。

**本项目用法：**按项目目标定义阻断项；逐项给证据；全部排除后再讨论节奏与风格偏好。

**教学示例：总分高但钥匙凭空消失，且下场戏依赖钥匙，仍不可交付。**

**适用边界：**字幕或标识是否禁止要服从任务；不能照搬来源的统一禁止文字。

**检查办法：**任一关键项未通过时，结论明确标出不可交付及修复对象。

来源：[S15](来源与阅读边界.md#S15)、[S06](来源与阅读边界.md#S06)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G18"></a>
## G18 · 问题描述要有时间位置和预期

用可定位症状取代“不自然”“不够高级”。 模糊反馈无法区分动作、结构、身份与相机问题。

**本项目用法：**记录素材版本、首个异常时间、持续区间、预期、实际与已尝试修改。

**教学示例：00:03.2起右手多出手指，比“手不对”更利于比较不同生成版本。**

**适用边界：**首次异常时间不能单独证明是时长或提示词导致；需要对照输入。

**检查办法：**另一个审查者能够找到同一处问题，且不必猜测指的是哪个版本。

来源：[S15](来源与阅读边界.md#S15)、[S16](来源与阅读边界.md#S16)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G19"></a>
## G19 · 先选最低成本的有效修正

根据原因决定改描述、换参考、拆动作、补镜还是后期修整。 无限重抽或每次同时改很多项会耗费预算并失去判断依据。

**本项目用法：**优先修正已证实问题；单因对照时只改主要变量；多症状共因时先改上游设计。

**教学示例：素材末尾有半秒无用抖动且不影响动作，可评估裁切；关键表演缺失则不能靠裁切伪装完成。**

**适用边界：**单变量方法是实验策略，不能妨碍同时修复互相依赖的确定错误。

**检查办法：**每次重试写修改理由与效果，达到预算或无进展条件后换路径。

来源：[S16](来源与阅读边界.md#S16)、[S15](来源与阅读边界.md#S15)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G20"></a>
## G20 · 自动视频指标只覆盖部分质量

将人体、身份、服装、空间和运动等维度分别考察，再补人类剧情判断。 模型分数与观众是否理解人物动机不是同一件事。

**本项目用法：**从目标缺陷选评测维度；核对评测器支持的输入；与人工标注比较误检漏检。

**教学示例：人体检测通过的片段仍可能把拒绝演成同意，需要剧情审查。**

**适用边界：**VBench2自定义视频支持范围有限；本轮不声称运行过评测或这些阈值适用于短剧。

**检查办法：**证明所用维度支持当前素材，并保留人工核查证据。

来源：[S25](来源与阅读边界.md#S25)、[S15](来源与阅读边界.md#S15)。用法与示例为本项目综合改编，不是已验证结果。
