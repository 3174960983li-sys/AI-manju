# 怎样把连续性落实到每个镜头与素材

版本V0.1｜2026-10-30｜状态：有来源的研究提炼，制作效果待具体任务验证。

同一个人物、道具或空间跨镜出现时，连续性需要同时贯穿设计、提示词、素材绑定与成片检查。文字里声明保持一致不能替代实际观察。本篇保留连续性方法，舍去来源中的固定词数、秒数和单一构图偏好。

<a id="G11"></a>
## G11 · 稳定身份与剧情状态分开

角色身份、道具设计等相对稳定；湿润、受伤、持物和位置随剧情变化。 把变化状态写进永久设定，会使后续镜头无法正常变化或被错误重置。

**本项目用法：**资产表锁身份和设计；镜头状态表记录变化；使用时读取最新有效剧情状态。

**教学示例：外套为深灰是设计；袖口被雨淋湿属于当前状态，进入室内不会自动变干。**

**适用边界：**伤口愈合、换装等有明确时间或剧情原因时允许变化。

**检查办法：**比较前后镜的状态变化是否有事件依据。

来源：[S14](来源与阅读边界.md#S14)、[S10](来源与阅读边界.md#S10)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G12"></a>
## G12 · 记录动作入口、变化与出口

动作描述需要说明开始时是什么状态、发生什么、最后停在哪里。 只有“走向门口”时，无法判断是否到达，也无法交接下一镜。

**本项目用法：**先写可见起点与终点，再设计动作过程；相邻镜头承接已完成部分。

**教学示例：前镜已经放下杯子，后镜从空手开始，不能再演一次放杯。**

**适用边界：**回放或非线性叙事可以重复，但应标明叙事意图。

**检查办法：**逐对检查接缝，确认没有动作重演或无因跳变。

来源：[S10](来源与阅读边界.md#S10)、[S14](来源与阅读边界.md#S14)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G13"></a>
## G13 · 把空间关系转成可观察信息

位置、身体朝向、视线目标、运动方向与环境锚点要相互一致。 写了景别和运镜，不代表人物行动在空间中成立。

**本项目用法：**先确定人物与门窗道具的关系，再选择机位；改角度时复核银幕方向和视线。

**教学示例：甲在桌左看向桌右的乙，反打需要重新校验视线，而非照抄“向右看”。**

**适用边界：**180度规则可有意识地突破；参考图的正面居中构图不是所有镜头默认构图。

**检查办法：**用简图或镜头说明能复原两人相对位置，并与实际画面对照。

来源：[S14](来源与阅读边界.md#S14)、[S10](来源与阅读边界.md#S10)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G14"></a>
## G14 · 每份参考都写明用途与版本

身份图、场景结构图、首帧、运动参考和音色参考承担不同作用。 素材上传了但角色不明，容易混用身份、姿态与空间。

**本项目用法：**先核实际文件和槽位，再记录主用途、版本与生效镜头；按工具支持的模式提交。

**教学示例：图1只锁角色身份，图2锁房间结构；不能把图1自动当视频第一帧。**

**适用边界：**槽位语法、数量和模式来自实际平台能力，不能跨平台照抄。

**检查办法：**逐个比对真实上传列表、提示词编号与任务记录。

来源：[S10](来源与阅读边界.md#S10)、[S09](来源与阅读边界.md#S09)。用法与示例为本项目综合改编，不是已验证结果。

<a id="G15"></a>
## G15 · 镜头、叙事节拍与生成片段是不同单位

镜头是观看组织，节拍是信息或行动变化，生成片段是工具执行容器。 混为一谈会为了吃满工具时长而拖延动作，或把一个复杂动作拆成无法衔接的生成。

**本项目用法：**先设计剧情与镜头，再依据工具能力组合或拆分生成片段，记录切点与承接状态。

**教学示例：一次递钥匙可跨两个景别，但两次独立生成是否可接要另验，不能仅凭同样文字保证。**

**适用边界：**既不强制最长片段，也不强制固定短片段；以试验结果决定。

**检查办法：**总时长、动作完成和跨段可剪性分别检查。
