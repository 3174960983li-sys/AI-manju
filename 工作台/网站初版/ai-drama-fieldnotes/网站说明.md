# 造片手记：个人网站第二版

站名暂定，首页视觉为代码绘制的概念画面。文章、SOP、Agent、Skill 均明确标注为演示内容，没有导入用户真实作品、内部 SOP 或私人资料。

## 内容结构

1. 学习手记：概念理解、练习与待验证问题。
2. 制作经验：可复用的方法与经验。
3. 问题复盘：现象、原因假设、修改、结果与适用边界。
4. 制作 SOP：每个环节的输入、输出、检查标准。
5. Agent / Skill：职责、适用范围、模板与版本。
6. 作品档案：成片、个人职责、制作过程及关联记录。

内容之间以作品为真实案例，以手记解释经验，以 SOP 固定流程，以 Agent / Skill 承载方法。当前共有 3 篇示例手记、4 个 SOP 环节、3 个工具条目和 1 份作品归档模板，作品区等待真实素材。

## 当前实现

- 18 个静态 HTML 页面，正文无需 JavaScript 即可阅读，支持电脑和手机布局。
- 分类筛选与全站正文关键词搜索；筛选条件保存在 URL，刷新后保留。
- 独立文章地址、桌面目录、手机折叠目录、阅读进度与关联阅读。
- 自动生成反向引用、Markdown 下载、模板复制与文章链接复制。
- 明暗主题可切换，设置保存在当前浏览器中。
- 内容源集中在 content/library.json。id 不应随意改动，related 字段指向其他条目的 id。
- 展示生成器为 build.py，样式与交互源文件为 assets/style.css、assets/app.js、assets/theme.js。
- 执行 python build.py 将生成静态文件到 dist/。不要直接修改 dist/ 下生成的 HTML 或脚本；下次构建会覆盖它们。
- 未实现后台、登录、上传、在线 Agent 执行、数据库、评论或订阅。
- 内容更新目前通过编辑源文件完成。后续若需要浏览器后台，应再确定编辑权限、草稿与发布流程及存储方式。
- 使用系统字体，不依赖外部字体服务或远程图片。

## 替换真实内容

先补充站名、网名与个人介绍，再选 1 个有展示许可的作品、3 篇真实手记及 1 份可分享 SOP。作品资料可以按页面中的“作品归档模板”填写。不应直接公开包含凭据、私人路径或未授权素材的内部 Skill。

## 本地查看

在本目录先执行 python build.py，再执行 python -m http.server 8787 --bind 127.0.0.1 --directory dist，然后访问 http://localhost:8787。页面采用站点根路径，应通过 HTTP 服务预览。

参考选型、结构调整和采用边界详见《参考研究与改版说明.md》。

当前部署保持仅站主可访问的默认权限；对外开放、域名和后台属于后续部署决策。
