# 个人网站参考研究与第二版调整

调研日期：2026-10-28。范围：GitHub 原始仓库 README、对应演示站页面与本地浏览器截图。质量判断来自本次对目标适配性的评估，不以 stars 或作者宣传作为效果证据。

版本区别：Brittany 的 v4 仓库是历史版本，其当前官网已经不同；没有将当前站误认为 v4。Quartz 当前默认分支与官方文档显示 v5。Magic Portfolio 的演示页首次加载时主体尚未出现，等待加载后才完成截图与正文核对。

这些项目都是方法与信息结构参考。本次自主实现页面与交互，没有复制其网站设计细节、源码、字体或视觉资产，也没有将其性能、访问量或用户转化视作已验证结论。

## 初版问题与实际修改

1. 初版主要依靠长单页和阅读弹窗。现在生成首页、作品、手记、SOP、工具箱、关于与每篇内容的独立 HTML 页面。链接可直接访问与刷新；旧文章哈希链接仍可跳转。
2. 初版搜索只覆盖手记标题与摘要。现在全站搜索覆盖 11 条示例内容的标题、标签、分类、摘要与正文，包括 SOP、Agent、Skill、模板。手记页保留单独分类与搜索，查询参数可保存当前筛选。
3. 初版各模块缺少联系。现在每篇条目通过 related 字段定义关联内容，构建时检查链接，并反向生成引用列表。
4. 长文增加桌面目录、手机折叠目录、当前章节提示、阅读进度、面包屑和返回入口；Markdown 下载内容保留代码围栏。
5. 视觉调整为墨绿黑底、暖白文字、铜橙强调；首页采用大标题、宽幅概念场景与三个入口。文章列表与流程侧栏形成不同阅读节奏。明暗主题切换可保存在浏览器本地。
6. 作品单独提供档案页，采用成片、职责与过程、方法复盘三层结构。尚未导入真实作品，页面明确显示整理状态。

## 内容与技术架构

内容源：content/library.json。每条内容包含 id、类型、标题、摘要、分类、标签、更新日期、状态、制作阶段、正文与关联条目。

页面构建：build.py，仅使用 Python 标准库。样式与交互位于 assets/。执行 python build.py 生成 dist/。生产网站是静态 HTML，文章正文无需 JavaScript 即可阅读；JavaScript 只增强搜索、筛选、主题与复制等交互。

本轮没有迁移到 Astro 或 Next.js：现阶段这些访问路径与内容结构可在现有托管方式下完成，不需要为了外观参考而增加框架依赖。若后续需要浏览器编辑后台，再根据真实更新频率、权限与草稿发布需求选择 CMS。

现阶段未实现：上传后台、在线 Agent 执行、评论、订阅与数据库。本次没有虚构个人履历、真实作品或成效数据。

## 后续内容准备

优先准备一部可展示的真实成片，三篇来自真实制作的手记，以及一份确实使用过的 SOP。作品档案应标明个人职责，并链接对应的经验与复盘。真实素材到位后再替换首页概念视觉。
