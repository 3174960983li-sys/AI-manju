# 合成验证剧本《诊室夜变》V1
这是为检验Skill设计的虚构短场景，不属于已有作品；不据此增加任何真实项目设定。范围S01—S03。

S01 日 内 东村诊所诊室
P01：阿宁穿灰布外套站在窗边，双胞胎小禾、小苗分别坐在长凳两端。两孩子均穿蓝布衣，原文未写具体年龄。屋内靠窗一张木桌，门旁药柜，窗帘被风吹动。
P02：三名村民在门边，其中右颊有疤的村民甲说：“宁姐，外面有个人。”另两人没有独立动作。阿宁回头，先皱眉，随后笑了。
P03：蒙面客进入。他把一枚刻“东”字的铜印交给阿宁。桌上还有一枚同款铜印。两枚分别记为铜印A与铜印B。

S02 夜 内 同一诊室
P04：阿宁仍在诊室，剧本未说明是否换衣。雷声后窗外雨响，阿宁右袖湿透并沾血，右前臂有一道新伤。她惊恐地抬手，铜印A仍握在左手。原文没有交代受伤和淋湿经过。
P05：小苗的小臂逐渐融合为白色鳞片覆盖的鳍状前肢，到手腕为止，小禾仍保持人形。门外响起三下钟声，没有钟的画面。阿宁说：“听说山上的老道能救她。”

S03 夜 内 同一诊室
P06：镜头反打。阿宁用左手把铜印A交给村民甲，随后推木桌堵门，桌面裂开一道缝。药柜和长凳未写变化，铜印B此时位置未交代。小苗后续形态未交代。
