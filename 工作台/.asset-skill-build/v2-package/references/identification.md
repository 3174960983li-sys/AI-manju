# 识别标准

## 一、先确定出现方式
入画：实际可见，包含闪回、画中画、梦境等，但须标叙事层。声音：可听不可见，包括画外对白、广播；不直接要求人物可见造型。提及：只存在于对白或文字叙述，不直接要求图像。待确认：改编尚未决定呈现方式。无声小说中的心理描写不能直接认定为画外音。
当前提及者也登记其身份和用途，标“不要求可见设计”；不能把入画名单与全人物登记数混算。角色谎言/传闻不是世界真相，隐藏身份不提前泄露到可见设计。

## 二、角色身份
同一身份的本名、昵称、亲属称呼合并，保留原称谓与证据。同名不同人、双胞胎、替身分别登记。身份不明用角色稳定编号和临时名称；后来揭示身份先验证文本，再更新名称/别名，不因改名换号。若原先已有两条经证实同人，保留被合并条目及“合并至编号”，重定向关联并记录理由，不删除历史。
群众按群体身份与需要区分的造型群记录。人数未知写未明确，不造人数。独立对白、关键动作、跨场辨认者单列；群组人数相应扣除并注明包含关系，防止“3名村民＋其中1名”算4人。临时出现不等于不需要提取。

## 三、服装与角色状态
先建一个实际可用的基准外观组合，服装/妆发/年龄/形态/身体状态分列。服装方案在描述内用稳定名称，例如“服装A：灰布外套”；同款变脏属于外观状态，不另起服装名称。衣物被脱下后作为独立持物参与剧情时，可转成关联道具，注明与服装关系，不能算两件不同实物。

|差异|处理|
|---|---|
|明确换装或确认设计要求|同一角色组下增加服装/状态子行，写明衣物/轮廓/材质的实际区别|
|昼夜切换但没写换装|不擅设睡衣；记录未明确，沿用只能是候选|
|恐惧、哭泣、愤怒、转头、挥手|通常记录在相关描述/内部来源记录，不新增状态子行|
|湿透、妆花、伤口、血污、包扎|检查可见部位、程度、持续性和跨镜一致性；必要时增加状态子行|
|婴儿/成年/衰老/显著形态变化|同身份增加形态变体，不复制成新人物|
|变形过程|记录起始、局部变化、剧情到达的终态；过程方案单列外观子项，不能补写未出现终形|

外观差异记录与独立素材需求分开。轻微差异可能沿用基准，但仍记录关键连续性；瞬时结构变化也可能需要专门设计。只建立实际出现/已采用组合，不做服装×年龄×伤势笛卡尔积。未知不能当正常、干燥、完整；衣物明确完整后才能标完整。

## 四、场景与场景状态
按地点归属、几何结构和连续性辨认空间。上级地点可仅作为层级名称，不为了补全层级自动要求制作院落外景。若上级地点本身入画，再建空间条目并关联。异地同名房间分开。
景别、反打、机位、焦距、画幅不同均不新建空间条目；实际连通的区域可按叙事独立性划为子空间，不能因一个镜头就拆一个场景。
家具、陈设、门窗、固定设施包含在“家具陈设/关键布局”。关键部件在同一场景内用稳定称呼，例如“靠门木桌”；夜景不重置家具位置。需交互/可拆卸/破坏时补充该部件需求，仍不重复建道具条目。独立携带和传递的小物进入道具条目。
场景状态子项按实际组合记录日夜、天气、人工光/自然光和物理变化。灯光变化≠几何变化；烟、风、雨记录来源/作用对象/强度/持续范围，镜头中的一阵风可只记事件，不新造风版场景。梦境/闪回如空间相同可用状态或叙事层区分；空间确实另建则另空间条目并说明。
状态描述格式：基准＋改变对象/位置＋改变程度＋起止场次＋后续继承。例如“同一诊室；靠门木桌由窗下移至门前；自S03堵门起持续；S04未提供恢复证据”。不要只写“破败版、恐怖版”。

## 五、道具
设计编号道具条目与实物实例分离。同款两枚印章共用道具条目，在相关描述/内部来源记录用“印章A/印章B”记录每件的归属/位置/传递。数量未知不能用出现次数推算总件数。不同功能/身份的牌、钥匙即使相像也分开。
道具破损/消耗/变形/文字变化写入状态要求与出现初末态；需要独立设计的版本可另道具条目，关联“基准道具编号”，仍保留同一实例。连续变化不为每个瞬间新起道具条目。
重要文字逐字提取，遮挡/不可读/未写明分别说明，不能补写号码和咒文。声音物件和传闻物件保留方式，不自动列为可见制作任务。

## 六、证据与候选
每条事实可回到输入版本、场次、段落/短摘句。没有页码就用段落/场次，不编页码。同一行多类信息时，推断写“推断：…”，建议写“候选：…”；证据性质列对应该行资产识别与状态事实，建议列不会因此被当原文明示。
冲突同时保留来源和影响，不自行挑一个变成事实。已确认补充可以没有原文依据，但必须写确认记录定位及“设计候选/已确认”；已批准改编作为当前制作来源，原文对照不回滚它。

## V2阅读优先
基础角色一行已经承担基准，不为所有角色额外创建“服装未明确”的基准子行。动物独立列角色且在名称注明；群众保留，未知人数不编写。父场景下同时管理子空间和其状态，家具陈设不另列道具。交通工具可在道具表末尾用载具标签区分；VFX在相关描述或专项文字说明，不算实体道具。候选差异若尚无具体内容，集中提问，不为每个可能性新增空资产。
