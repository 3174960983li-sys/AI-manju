# 03阶段验收与交接

版本：1.0

## 验收清单

- [ ] 输入版本与采用依据明确，缺口及影响已记录。
- [ ] 候选默认5—8部、短剧占多数；偏离默认有理由。
- [ ] 核心参考存在用户确认记录；默认2部短剧＋1部电影或剧集，允许职责合并。
- [ ] 重点场面默认3—5个，并直接关联研究问题。
- [ ] 重点结论可追溯，观察范围与片源版本明确；时间码对应所用片源。
- [ ] 事实、推断、建议已区分；未观看内容未被描述为已观看。
- [ ] 市场数据可核实并有口径和日期，缺失则标未知。
- [ ] 导演分析包含表演、调度、视点与声画组织，不止风格标签。
- [ ] 参考板有来源、定位与用途，不止图片堆叠。
- [ ] 转化对应本剧场次，说明做法、作用、竖屏适配与资产需求。
- [ ] 推荐方向一个、备选至多一个；冲突有取舍建议。
- [ ] 高风险建议进入05验证任务，未虚称可稳定生产。
- [ ] 未直接修改采用剧本，无虚构素材、确认或验收结果。
- [ ] 实际输出可访问，下游位置、限制和未决事项明确。

检查项可以标不适用，但必须说明理由。检查结果为未检／通过／限定通过／需返工；限定通过必须明确可使用范围，不能笼统视作全阶段通过。Agent自检不冒充独立审查。

## 接收规则

04接收研究依据、方向候选和待决事项，打开实际成果检查，逐条记录采用、调整或放弃及原因。核心证据缺失、确认缺失或转化与本剧无关的部分返回03补充；不受影响的部分可限定接收。

02接收剧本修改建议并决定是否改稿；03不覆盖文学事实。

05接收实际需要验证的方法，检查输入、观察目标和通过条件是否具体。资源上限未定时可准备任务，不视为付费执行授权。

## 异常与恢复

| 情况 | 处理 |
|---|---|
| 核心作品无法访问 | 记录实际范围，提出替代候选供用户确认；继续无关研究 |
| 只有预告片或截图 | 限定到相应内容，不推断完整表演、剪辑或声音 |
| 参考彼此冲突 | 回到项目目标提出取舍，不静默混合 |
| 剧本或项目目标换版 | 定位受影响建议并复核，保留有效证据 |
| 缺少转化方案 | 返回03补充场次和具体执行方法 |
| 样段证伪 | 05回传观察证据与限制，03修订建议，04复核受影响决定 |
| 工作中断 | 从输入版本、确认记录、最后成果、未决项及下一步恢复 |
