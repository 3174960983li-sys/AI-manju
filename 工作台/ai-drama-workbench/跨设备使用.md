# 跨设备使用与开发

发布分支：`codex/m1-workbench-20261031`。源码与资料在 `工作台/ai-drama-workbench`。此分支保留原仓库内容，新增工作台包，不改动既有SKILL。

## Windows首次安装

安装Git及Python 3.12，在PowerShell执行：

```powershell
git clone --filter=blob:none --sparse --single-branch --branch codex/m1-workbench-20261031 https://github.com/3174960983li-sys/AI-manju.git AI-manju-workbench
Set-Location AI-manju-workbench
git sparse-checkout set 工作台/ai-drama-workbench
Set-Location '工作台/ai-drama-workbench/M1原型'
py -3.12 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-lock.txt
& '.\.venv\Scripts\python.exe' -m streamlit run app.py
```

浏览器访问 http://127.0.0.1:8501/ 。每台设备的localhost指向该设备自身。首次运行创建空数据库，不会自动出现原电脑上的剧本。

## 数据单独管理

数据库默认位于M1原型/data/manju_m1.sqlite3，包含原始剧本与项目记录。源码同步不包含数据同步。需要移动数据时，先关闭两端应用，通过私人渠道复制完整数据库并备份目标端旧数据；SQLite没有自动合并能力，不要让两台设备同时编辑后互相覆盖。不要把私人数据或API Key提交到公开仓库。
