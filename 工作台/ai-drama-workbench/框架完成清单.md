# M1工作台整体框架完成清单

2026-10-31｜当前层级：可操作的人工管理框架，不等于完整生产系统或全部SOP细则。

| 框架 | 可用内容 | 验收边界 |
|---|---|---|
| 项目与整剧 | 项目创建、简介、单集规划与导出 | 项目隔离，整剧先规划后分批推进 |
| 单集 | 稳定编号、梗概、时长、剧本归属与历史 | 整剧稿可未分配，多稿分别保留 |
| 场次 | 原稿导入、模拟拆分、原文定位、人工修订与导出 | 未调用真实模型，不自动改剧本 |
| 镜头 | 来源场次、行动意图、镜头方法、时长、资产引用、候选位置 | 手工文字分镜框架；源场次ID保持可追溯 |
| 共享资产 | 角色/造型/空间/道具/声音需求、版本、位置、来源权限与限制 | 不生成或自动验证素材 |
| 12阶段 | 输入、产出、职责映射、准备记录、人工进度 | 每阶段可登记任务和交付，不推断完成 |
| 任务与交接 | 负责人、输入输出、范围、检查依据、状态、修订历史 | 接收与成果采用分开 |
| 四个早期关口 | 立项、整剧创作基准、首批方向、生产基准 | 用户本人决定，不由Agent替代 |
| 批次与采用 | 单集组织、本批准备、工期、资源与开工记录；逐集采用关口仍在确认中心 | 批次状态需开工记录；人工核对实际范围版本 |
| 质量检查 | 对象及指定版本、实际范围、标准、时间码证据、发现与复核 | 不将检查结论自动当作成果采用 |
| 后期与交付 | 阶段任务、完成版位置、规格、清单、验收记录、归档与恢复依据 | 不执行剪辑、编码或远程上传 |
| 预算与工时 | 预计、上限、实际三类数字及单位/依据 | 人工台账，不计费或调用API |
| 变更与恢复 | 原因、影响、决定依据、执行与回退方案 | 不自动覆盖旧成果；历史保留 |
| 规范与SKILL | 只读规范索引、专业职责映射 | 未执行、改写或安装原有SKILL |
| 存储与追溯 | SQLite v6、升级前备份、原件保留、对象历史、关联版本快照、JSON/CSV导出 | 不自动合并跨设备数据库 |
| 源码同步 | 已公开独立GitHub分支、跨设备说明、18:00一次性增量任务 | 不部署公网；私人数据与密钥排除 |

## 主链路

项目 → 单集规划 → 剧本归属 → 场次 → 镜头 → 共享资产与素材位置 → 质量检查 → 完成版交付与归档。

批次组织单集；任务、确认、资源与变更跨阶段使用。镜头保存场次来源，资产与批次引用保存当时版本；质检对应实际检查版本。关系变化不自动更新其他记录状态。

## 完成判定

整体框架已有导航、输入表单、业务校验、项目隔离、持久保存、历史及导出入口；64项自动测试通过，包括全部新工作区渲染、资产保存、跨项目拒绝、过期编辑、关联版本保留、批次/交付关口和v5迁移备份。

后续进入真实项目试用与逐阶段细化：完整SOP细则、专业SKILL接入、真实模型解析、生产依赖与自动失效检查、文件存在性与媒体质量实测、时间线编辑和视频生成均未纳入本轮完成声明。不能用“框架完成”代替上述验证。

当前新版在可写工作区发布候选并使用8502预览；E盘8501原运行版未替换，两个数据库独立。
