# 故事、场次与信息诊断

V1.2执行参考。将正确复述推进到有依据的结构判断；与原人物/背景方法协作，不另造一套全剧评分表。

## 1 先确定分析单位与整体关系

区分原文的章节/集场、按制作地点/昼夜整理的场次、欲望/行动/反馈形成的戏剧单元。三者可交叉，不能因换地点就认定一个戏剧过程已结束，也不能把长篇章节直接当短剧一集。标原号与临时整理号对应，不为符合理论静默拆并原稿。

全读本轮范围后，简述主线及关键支线如何依赖。对重要事件区分“先后发生”与“导致后事”，核行动者当时知识、可用条件、触发、结果及后续影响。非线性材料分别核故事发生顺序与观众接收顺序；时间跳跃不是天然漏洞。只读节选时标未覆盖前后文，不把尚未读到的解释判成作者遗漏。

## 2 分析场次，不强迫每场反转

根据复杂度选写：进入时的人物/关系/信息/行动条件→当前所求与阻力→重要动作和反馈→结束时改变或维持了什么→与相邻单元的联系。

动作/反应的交流有明显改变才形成新的分析节拍，不按每句台词、自然段或一个手势机械划分。人物意图、实际结果和观众认识分别核；自然现象不强套人的意志目标。事件发生了，不等于观众已经得到相应信息。

可以用麦基的价值/状态对照分析戏剧场面，但不是所有场次都必须正负翻转。关系建立、等待、信息累积、日常观察、过渡或形式体验也可成立，说明具体作用和成本。开头结尾表面相同，要查内部过程及相邻依赖，不能立刻删场。反之，换了地点/道具而理解与体验均无作用，也不能仅凭事件多就称结构有效。

## 3 信息、伏笔与揭示

分清作者/叙述者陈述、角色声称、角色信念、实际行动证据和观众可获得的信息。全知叙述明确的心理可属原文事实，但不自动为其他角色或改编后的观众所知；不可靠叙述须结合文本判断，不能预设所有话都在撒谎。

关键线索核：原文载体、首次出现位置、谁能接收、当时怎样理解、何处被确认/重释，以及改编需要保住什么。前后出现相似物不自动证明是伏笔；人物回答不自动认证真相。未读到回收记“当前范围未见回收”，不能指控全书烂尾，也不许为闭合而补结局。

潜台词是有依据的行动/关系解读，不是新增隐藏阴谋。可给少量不同解释，说明证据与对表演/揭示的影响。直白、真诚或没有复杂隐情的对白同样可能有效；不强迫全员言不由衷。

## 4 问题分类与处理

- 明确矛盾：同一条件下互不相容的事实/规则，定位两端及实际后果。
- 信息不足：关键前提缺失或当前范围未覆盖，提出最小查证，不直接判错。
- 表达风险：故事可成立，但银幕上可能看不懂、提前揭底或漏必要反馈，提出表达需求/候选。
- 取舍或偏好：节奏、形式、信息安排存在多种成立选择，比较体验，不冒称客观错误。
- 制作未知：工具、参考或素材未验证，转为需求/试验，不宣称剧情不可实现。

每个关键问题仍用“位置与证据→影响→最小候选→决定者”。修一处要检查人物知识、前提/后果、资产状态和相邻场；没关联的内容不重写。确认改稿后保留原文对照及制作采用状态，不把新补的伏笔说成作者原意。
