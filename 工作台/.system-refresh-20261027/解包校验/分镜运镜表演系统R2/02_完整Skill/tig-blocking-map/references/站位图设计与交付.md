# 站位图设计与交付

## 1. 图的职责和几何依据

TIG主交付是镜头视角角色站位图：从当前摄影机位置观察，表达人物和地标的画面关系。沿源图或有效分镜的观察角度，即使是高机位、斜向或局部裁切也不改成平视正面。

世界俯视布局用于推导位置/通路，镜头站位图用于当前可见关系，故事板用于观看与剪辑设计，最终关键帧用于成片外观。若同时需要世界布局和镜头视图，分开说明职责与推导；单张透视图不能恢复完整场景，背面/距离未知不编造。

沿用人物名称/编号，必要才给A/B等临时别名。对关键主体说明：相对地标与画面左/右/近/远，身体朝向与头部/视线，姿态、可见范围/裁切、遮挡、持物/接触及必要道具高度。每个左右有参照，不能将转头当作身体转身。

源图模式不加未见人物/家具、不补齐裁切身体，未知道具称可见物体；文字模式允许提出必要布置，但标新设计，不宣称原图匹配。持续动作用起态、触发、必要路径/节点、末态表达；静态任务不强填完整动作链。

同一人物跨图保留文字别名和颜色，画面左右变化不互换身份。相近色难辨时优先简化到当前必要主体、分视图并用图外位置校核，不靠颜色独自识别拥挤人群。背景群体可概括，关键人物不能省略。

## 2. 工具中立绘图提示词骨架

按任务取舍，方括号仅代表需要替换的说明，不是平台句柄；实际交付应填好关键项。

```text
用途：为指定镜头/阶段提供人物几何参考。
依据：源画面仅约束构图、角度、裁切、位置、姿态、可见比例与必要物体关系；或明确按有效文字新设计视图。
画幅和观察方向：沿本次有效源图/镜头设定，不额外固定横竖屏或正面。
画面：简化技术线描，背景干净，人物为清楚可辨的不同低饱和颜色细轮廓，无大面积填色。图内不画文字、字母和标签。
各主体：逐一写颜色、当前画面位置、可见范围/裁切、朝向与视线、姿态、前后关系和关键接触。
地标：只画判断关系所需的门、桌、墙等轮廓；源图模式不补未见区域，文字新设计按采用方案。
辅助路径（需要才有）：分别说明人物/物体/摄影机、所用视图与坐标、起点/终点/方向及触发；角色颜色和路径不混用。
保留必要裁切与遮挡，不补全画面外身体；不把照片纹理、服装和灯光细节作为本图主体风格。
```

轻网格是可选绘图辅助，不是模型精确坐标系统。没必要就省掉。没有真实引用句柄时块外说明需附实际源图，不伪造image_1。工具专用参数仅在选用并核实需要时添加，不沿用原版固定MJ参数。

## 3. 图外人物键与视频连接

图外可写“A＝当前镜头蓝色轮廓＝老许＝已核角色参考文件/槽位”。A和MAP01是逻辑名，不默认加@；没有角色资产可用名字对应并标待核，不为填表强制补定妆图。图内仍不绘字母/标签。

可接当前视频提示词素材/镜头段的说明：

> 这份图稿只约束指定镜头/阶段的位置、朝向、姿态、裁切和遮挡。身份、服装、环境外观、材质与光线来自各自有效参考及文字；颜色仅区分图中人物。初态保持到对应行动开始，随后按脚本走位；换镜按其机位重新判断画面左右。

非仿真人项目沿已选风格，不硬写fully photoreal。必要可加“轮廓线/白底不进入成片”等简短边界，不把禁用否定词设为硬规则。

源照片若也承担有效环境/构图职责可以使用，分别声明，不一概禁止视频引用源照片。真实绑定按实际工具表达，未绑定就交待绑定说明，不给虚假可提交标签。顺序/权重未知不猜，不承诺一句几何限定能消除外观污染。

## 4. 动态与换机位

一图约束当前镜头/阶段；动作开始后按脚本推进，不用位置锁压过已确认行动。复合运动还核中途遮挡、显露、转向及观察侧变化；起末图正确不证明中间路径成立。复杂走位可按需给起始/转折/结束图，多图节点不代表剪切。

镜头视角的虚线路径表达屏幕投影，不能直接证明世界轨迹、距离、速度或物理可行性。摄影机路线优先在另行明确的世界布局里判断；屏幕箭头只表达画面变化/转向时要说明，不能把摇摄箭头当推轨路线。弹道等轨迹需要条件，网格不自动保证物理正确。

反打/绕行后人物可在画面另一侧；地标、身份和实际位置仍连续，不能直接镜像旧图当新图。遮挡变化还要核是否泄露本应未知的人/物；制作人员掌握的幕后事实不自动进入成片。

## 5. 交付与检查

只要提示词：交用途/依据/镜号阶段、完整绘图提示词、图外人物键及依赖；要求连接说明时一并交。实际出图才调用适合的图像能力，检查数量/身份、位置朝向/裁切、遮挡/接触、轮廓可辨和错误文字。源图模式须实际看源图才能称提取完成。

已生成、已检查、已采用、已绑定、视频已验证分别记录。图稿关键几何错了先修或提出不用该图的替代，不能说文字必覆盖；仅不影响用途的差异可注明保留。真实视频另查站位、动作释放、外观污染和连续性，文本本身不证明通过。
