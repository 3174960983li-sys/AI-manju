# 与项目分析、导演、分镜和提示词的接口

接口R2｜2026-10-27。共同依据/采用状态仍见[主链规范](../../project-script-analysis/references/四阶段协作规范.md)；本页细化站位辅助分支，同级包缺失时仍可按本地规则执行。

## 接入位置

主链仍是分析→导演→文字分镜→提示词。导演空间推敲时可用站位候选；镜头视角明确后可表达某镜初态/关键阶段；提示词接实际可用图稿及有效说明。不是每场必做，不是故事板前置。

| 接口 | 接收 | 交回与边界 |
|---|---|---|
| 分析→站位需求 | 场景/人物/道具、必须表达关系、制作文本、未知项 | 空间表达需求与缺口，不自动画全场或决定机位 |
| 导演↔站位 | 行动/调度、保持项、地标/通路、观众信息、自由度 | 布置/视角候选；新增空间或改知情/关键动作回导演，普通细化可继续 |
| 分镜↔站位 | 七列及段落说明、场/镜号、机位/裁切、阶段/相邻状态 | 图稿或绘图提示词、图外身份键和范围；不反过来默改分镜 |
| 站位→提示词 | 实际文件/绑定、来源和图版本、镜号/阶段、人物键、动态起末态 | 几何用途进素材职责和对应镜头，不另叠视频格式，不用图色决定服装 |

## 最小交接与坐标

记在原有段落/交付说明，简单任务一段话，不给七列表增加必填列：依据的导演/分镜版本；场/镜/动作节点；源图提取或文字新设计；图稿/提示词逻辑名及真实路径（有才写）；生成/检查/采用/绑定状态；人物名—别名—颜色；锚点与可见/暂缓内容；本图约束范围、行动释放和下一节点；缺口。

沿项目编号，无规则才提出如MAP01；“场—镜—阶段—图版本”的对应比前缀重要。逻辑名不是平台标签，一场多镜不能被同一场名掩盖适用差异。

世界关系→摄影机观察→画面左右/裁切是不同层次。人物动、摄影机动、遮挡改变分别核；静态图不冻结整段。接触必须有触发与后果，图上靠近不能代替动作成立。从首图到末图核状态：杯在桌上时不能已在手里，袋移走后不能回旧位；幕后人物/道具不自动允许提前展示。

## 变更回查

- 仅改颜色、几何不变：更新人物键和用它的绑定/说明，通常不撤销导演/分镜采用。
- 改机位、画幅裁切或遮挡：核相关视图、画面位置说明和提示词；同一世界布局不等于旧图仍适用。
- 改站位/路径/接触/时点或关键道具：核导演保持项、该镜及相邻状态、图和任务；改因果/知识/锁定体验才提实质取舍。
- 源图与采用分镜冲突：说明差异、有效依据与影响；不以图更直观为由覆盖文字，也不宣称文字必压过错误图。
- 只完成提示词或无真实槽位：可交待图/待绑定稿或无需图的文字版，明确状态，不能把逻辑图号当已上传参考。

旧图保留历史身份，相关部分标待回查，不为一个镜头重做全剧。没有真实图/视频时只报文字和接口检查，不报精准匹配、防外观污染或站位控制成功。
