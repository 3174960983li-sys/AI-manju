# 多人空间与视听统筹

R2适用说明｜2026-10-27。当前入口和共同协作规范确定职责/范围，专业细节以本次操作手册为主；下方版本号与阅读/试跑日期标识来源历史，不是并行运行的另一套系统。
V0.4执行摘要。用于多人、多个行动区域、画外行动，以及视觉/声音/节奏互相竞争的场面；简单双人戏按需取用。

## 以关系和区域共同组织

先核地标、出口、通路、交互物及人物初态。按当前行动关系辨认人物组，按场景实际功能辨认区域：谁正在交流，谁旁听/忙于另一任务，谁能进出或影响另一组。组不是固定阵营，区域不是不能跨越的格子。

不要逐人排完整走位后才拼整体；也不能只分区域、不顾个人动机。联合选择关键关系及活动范围，再给个人具体行动。位置可承载距离、阻挡、归属等意义，但站高、坐首位、居中不能自动等于权威，更不能由性别/年龄配调度。

重要移动注明触发、目的/实际行为、可行通路、目标位置和反馈。人物可在区域之间移动；固定不动、等待和画外活动也可以承担任务。画外人物保存位置、可听范围、活动及进入条件，不因画面看不到就暂停其世界行为。

## 组织注意，不让全场同步表演

对关键节点问：此刻观众重点跟谁或哪项环境变化？其他人知道什么、在做什么？注意转移由什么行动、声音、视线或关系触发？

按必要程度分主线、相关反馈和持续背景。相关反馈可以并行，群体不同步不代表必须各演一种表情；只有输入支持时才安排知情差。环境异变成为核心时可以压过人物，不固定把背景永远降为装饰。

跨区域连接可由人物经过、视线/声音联系、共同物体或观看变化完成。导演写必须保住的空间与信息关系，分镜选具体构图、镜头拆分和运镜。不得让下游靠剪切遮掉无法通行、接触不成立或不该听见的声音。

## 视觉、环境、声音与节奏共同决策

1. 列本场必须看清、听清、保持未知和需要经历的过程。没必要不另建表。
2. 给关键要求指定有效载体：人物/物体关系、明暗和清晰层次、声源或等待。没有实际载体的“压迫感”需补设计。
3. 核冲突：遮挡是否盖住动作；音乐是否淹没线索；转移注意是否过早；移动是否让另一条行动线消失；环境变化是否无因抢戏。
4. 优先调整次要干扰、发生先后、空间和表达方式，保住核心体验；若取舍会改变已确认揭示/人物理解，明确讨论，不静默替换。
5. 核场尾：区域与相对位置、持物/身体状态、环境变化、人物知识和必要声音。光色、听觉可有意变化，但说明来源或风格依据，不为了统一而强求恒定。

区分角色能听见的故事内声音、观众听见的配乐/主观处理和画内外声源；不能让人物对纯配乐作反应，也不把转为近景当成对白必须变响。环境先核因果再设计动态，安静稳定可以成立。细节知识已在项目相关正文维护，导演输出只交场面原则与关键事件，不复制逐镜规则。

## 对AI制作的交接

所需空间锚点、身份/物件参考、关键接触、跨区可听条件和连续末态写为需求。空间简图有助于判断时可用文字或示意，不能自动生成图像。未有真实资产不伪造可用素材；复杂度未知不一律拆碎或承诺一镜完成。提示词阶段不能重新发明各组人物的事实与知识。
