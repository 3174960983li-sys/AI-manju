# 观众体验与情绪组织

R2适用说明｜2026-10-27。当前入口和共同协作规范确定职责/范围，专业细节以本次操作手册为主；下方版本号与阅读/试跑日期标识来源历史，不是并行运行的另一套系统。
V0.6新增方法。把体验目标变成场面选择，避免将“悲伤、震撼、紧张”直接当作可执行方案。

## 设计顺序

**目标→必要信息与关切条件→观看过程→视听手段→兑现→验证。** 这是检查因果的顺序，不要求每个场面按同一种节拍展开。

1. 接有效剧本与上游判断，区分人物感受、观众目标、已有反馈。已有体验选择继续深化；未选方向形成候选，不冒称用户已确认。
2. 找到本场关键节点：观众此刻知道什么、可能怎样理解、关心谁或什么、等待什么。事实与推测、角色与观众的知情分开；不把所有场次都当悬疑。
3. 指定造成体验的场面条件：谁先看到/听到什么，谁做出什么选择，什么反馈可被看见，结果怎样改变理解或关系。选择观察立场、调度、表演、声音和时间，使这些条件成立。抽象目标不能替代具体设计。
4. 组织强弱、持续与变化。强度与情绪方向分开；紧张不是唯一目标，低强度也可以投入。停留期间可以观察静止、听声、等待判断或消化结果，不必强加手部动作、眨眼、风雨或运镜。
5. 检查承诺和兑现。揭示前给足理解问题的条件，揭示后给结果被感知的机会。延迟有无必要取决于内容；教程可以先给结论，温情结尾可以满足地结束。
6. 将关键条件交给分镜，并写验证问题。纸面检查只能判断设计是否自洽、表达是否覆盖；真实效果需要实际声画与观众反馈，不承诺统一情绪。

## 五种方法如何选择

课程的“混沌、平静、惯性、旁观、满足”只提示可能的观看状态，不能从镜头或留存曲线直接诊断观众。先描述具体问题，再选方法；可以不用，也不必集齐。

| 可能的问题 | 可选处理及成立条件 | 常见误用 |
|---|---|---|
| 焦点分散、关键差异难辨 | 用构图、视线、对比、声源或观看顺序突出必要信息，核实际可读性 | 误把线索不清当强度不足，一味加音量或快切 |
| 需要更强体验却缺少分量 | 让既有后果、阻力、时间关系或人物选择可感；按所选体验组织层次 | 擅自增加事故、死亡、倒计时，或让全片持续最高强度 |
| 过程可预测或没有消化空间 | 改变观察/反应/时间关系；停留须有观看价值，长短由实际呈现检查 | 固定停两秒、每场打断一次、用黑屏代替已锁表演 |
| 人物处境可知但反应难读 | 明确刺激、判断、交流行动和结果，选择足以看清变化的观看条件 | 每场哭泣特写；把情绪标签写成表演指令；重复旁白解释 |
| 有值得等待的答案或结果 | 安排线索、行动阻碍、视点与兑现；让等待期间发生有效推进或观察 | 隐藏必要前提、重复拖延、提前泄密、结尾强留新谜团 |

表演可以克制，人物也可以掩饰。观众不必读到唯一心理解释；有意保持歧义时交代歧义范围，不能要求下游用表情将其坐实。

## 最小交接与回查

在现有逐场设计/分镜交接中写清：**希望经历什么→依靠什么可见可听条件→必须保住什么/允许改变什么→怎样检查。** 需要时补信息释放节点、应暂缓的答案、强弱与停留用途。不要给所有镜头增加“情绪等级”列。

反馈首先保存观察事实，例如“试看者能复述修理过程，却不知道女孩为何急”。再提出可能原因和最小修订。缺前提回分析/剧本，前提齐但呈现无效查导演/分镜，设计明确而素材没实现查素材，素材有而采用丢失查剪辑。按证据定位最早导致问题的条件，不按阶段机械重做；没有媒体与反馈时只保留验证计划。
