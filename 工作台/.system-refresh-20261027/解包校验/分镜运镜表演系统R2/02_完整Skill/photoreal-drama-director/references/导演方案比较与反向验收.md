# 导演方案比较与反向验收

R2适用说明｜2026-10-27。当前入口和共同协作规范确定职责/范围，专业细节以本次操作手册为主；下方版本号与阅读/试跑日期标识来源历史，不是并行运行的另一套系统。
V0.4执行摘要。选择依据是材料与体验目标，不是风格标签、复杂程度或是否省钱。

## 比较真实差异

只有不同方案确会改变体验才比较。先保留同一原文、保持项和任务，再指出观察立场、信息次序、关系重心、场面组织或声画节奏的实质差别。“冷色版/暖色版”若不改变体验机制，不必凑成两套导演方案。

比较时说明：观众在哪些节点获得什么；人物被怎样理解；空间/交流与节奏能否成立；有何表达代价和制作依赖。推荐适合当前材料的一项，必要时保留另一项；不打无依据分数，不将多数书认同当效果证据。

未知会实质改变推荐时，把分支条件说清：如门外角色能否听清关键话、用户要观众先知还是同步发现。能完成的共同部分继续，受影响处不假定已定。普通风格细节可合理设计，不把每个动作交用户审批。

## 正反两向检查

**从原文到方案：**重要行动、对白、事实与结果是否都有去处？人物知情与空间是否保持？哪些是原文、推断、新提案？必须看见/听见的证据是否真的可被获得？

**从方案回原文：**每个重要解读是否有证据？是否借灯光、声音、表演暗中坐实了原文未证实的罪责、亲疏或隐情？需要剧情改动才能成立时列候选，不把创作判断伪装成原文分析。

**从下场反查本场：**下场需要的位置、物件状态、人物知识和余留期待，本场是否交出？关系可以改变，答案可以保留，不能无因恢复。无全剧材料只核当前范围与必要相邻状态，不替未读部分认证。

**删除/替换检查：**去掉处理会丢叙事事实、改变体验、失去形式韵律，还是只是少一个装饰？这些层次都可以有价值。纯氛围、观看愉悦或形式探索并非无效；说明作用即可，不强迫所有选择都证明剧情因果。别以“精简”为由把有辨识度的方案统一为保守写法。

## 返工与交接标准

- 核心事实丢失或新解读越界：修正具体处理；必要故事改动单列讨论。
- 主张只在阐述里成立：补可见/可听依据或缩小主张，不能要求观众靠读说明理解。
- 声画/调度互相冲突：提出保留核心体验的具体调整，不只写“注意协调”。
- 空间或制作未知：交有条件候选及最小验证需求；不能标执行已通过。
- 只是审美不同但自洽：保留为取舍，不称客观错误。

交接须说明必须保住的表达和状态、允许变化的手段、待补条件。文字可读/可接续、用户采用、排演/试读和实际媒体分别记录。示例与自查不能证明观众必然产生特定感受；没有媒体不报镜头、声音或演员效果通过。
