# 声音与对白设计

R2适用说明｜2026-10-27。当前入口和共同协作规范确定职责/范围，专业细节以本次操作手册为主；下方版本号与阅读/试跑日期标识来源历史，不是并行运行的另一套系统。
V0.6执行摘要。声音参与信息、空间、节奏与表演；不是为每个动作机械配音。

## 从导演要求到声音方案

1. **核声音义务与原文。** 列需要听清的原对白、行动结果、画外事件与须保密的信息。锁定说话者和完整台词；缺文、身份或声音来源会改变理解时提问，不擅自补旁白、内心独白或改关键字。
2. **分清不同坐标。** 分别判断故事内/故事外、声源在画内/画外、谁实际能听见、观众听到的是否主观处理，以及声音相对画面的先后。画外电话或隔壁音乐仍可属于故事世界；配乐不能自动被角色听见；内心声音只说明相应人物感知，不能当他人共有知识。
3. **定听觉视点与主次。** 谁或什么是听觉关注中心？角色距离、遮挡、空间反射等给出可信听感；观众的混音可选择性强调，但须与风格和信息揭示相容。近景不自动等于音量增大，变焦不自动等于声源靠近。对白、关键音效、底噪和音乐发生竞争时，按当前叙事任务选择突出、降低、错开或刻意遮蔽；故意听不清的台词仍保留原文和不可辨意图，不悄悄删掉。
4. **落到事件。** 对关键声音写“声源/说话者→动作或词句触发→听感/可听范围→持续或停止”。动作音与实际接触、材质和结果对齐，不给每次接触统一大轰鸣。背景底声可持续，安静也可保留细微底声；完全静音属于明确效果选择。无音乐是有效方案，音乐进入/退出应有表达作用。
5. **设计跨镜声音。** 分开画面切点和声音切点：下一镜声音提前进入是J-cut，前镜声音延续到下一镜是L-cut；写明来自哪里、延到哪一事件，不只填字母。声音桥不自动证明同时同地，防止角色听见不属于其时空的声音。镜内同一构图下先听后见，不必误标成J-cut。
6. **对白交接与核对。** 说话者、对象、准确原文及覆盖镜号有唯一对应。表中可把一句按原字序分配到相邻镜，另一处注明整句索引；这是引用映射，不是两遍说话。不要重复生成整句，也不要用“同上”让下游猜范围。可见说话者核口型与语音归属；画外延续也核对谁在说。对话时长须经试读或素材校准，不编测时。

## 输出与边界

共同声场写段落说明，声音列写本镜必要变化，落幅列写跨镜延续。视频提示词获得完整对白及镜号映射、听觉视点和同步事件；需要独立配音、拟音、音乐或混音时标制作依赖。未听实际音轨不得报清晰度/口型验收通过；无参考不虚构音色样本、分贝、声道参数或现成曲目授权。
