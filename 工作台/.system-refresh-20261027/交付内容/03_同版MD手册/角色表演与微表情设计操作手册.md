# 角色表演与微表情设计操作手册

V1.0｜2026-10-27｜适用于AI仿真人叙事短剧与剧情短片。维护原件随photoreal-drama-director发布，Word为同版阅读导出。本文是导演与生成描述方法，不提供心理诊断或识谎结论。

## 先掌握这条工作主线

表演不是在脸上叠加情绪词，而是一个具体的人，在具体身体条件下，对对象采取行动、接收反馈并调整。真实感来自动机、注意、动作、身体受力、声音和面部变化相互支持，且过程在当前镜头中可读。

流程：核处境与知情 → 明确目的、对象和阻力 → 选择行动策略 → 设计刺激与相互反馈 → 落实身体任务和接触 → 选择脸部与声音的可见变化 → 匹配景别、运动和时间 → 检查连续性 → 输出分镜/提示词可继承的执行描述。

这里是设计依赖关系，不是每次反应都必须按八段依次演完。真实交流可以同时倾听、行动和说话，也可能没有自觉策略、只有突然受惊或失衡。

## 1 先确定角色此刻为什么行动

对关键行为先问：他知道什么、误解什么，想得到或保住什么，对谁做什么，受到何种阻力，什么代价使他不能轻易换一种做法。人物传记只使用原稿或已采用设定，不为解释表情补造童年创伤、背叛或疾病。

目的要足够具体：希望对方留下来，比“渴望爱”更可执行；让对方先别看信，比“表现紧张”更能指导动作。潜台词帮助选择行为，不自动变成新增对白。

区分目的和结果。试图安抚可以失败，请求不等于获准，沉默不证明认罪。表演必须允许对方的反馈真正改变行动，不能让两人各完成一份互不相干的表情清单。

完成物可以写成：“她想让对方答应留下，起初用轻松邀请；对方避开日期后，她把问题缩到今晚。”这是关系行动。真正执行还需明确台词、视线、身体任务与反馈，不能把策略动词当最终指令。

## 2 先有刺激 再有可读的变化

核角色在何时有机会看见、听到、触到或理解某件事。角色不知道门外来者身份，不能先露出认出的神情。观众可以比角色早知道，也可以晚知道；两条时间线分别核。

对关键节点写“原来在做什么 → 接收到什么 → 注意/行为怎样改变 → 对方或环境怎样反馈 → 接下来做什么”。判断可能很短或不可见，不必固定插一个思考皱眉。预感、误认和条件反射需由已有处境支持，不能用它们替代缺失前因。

听者可以在句中被触动、打断、继续工作或延迟回应；不必等全部台词说完。群戏按各人知情、注意对象和职责分层，不能所有人同一瞬间瞪眼、后退、张嘴。

## 3 怎样设计行为与动作

区分关系行动与物理任务。递水可以安抚，也可以只是倒水；擦桌可以与争论并行，而不是所有物理动作都必须象征隐藏情绪。听到某句后擦拭继续、变慢、停住或换方向，是否有表达价值取决于当下关系。

| 行为类型 | 设计重点 | 写成可执行内容 |
|---|---|---|
| 接近与退出 | 目标位置、距离、是否得到回应 | 走到对方可听见的位置停下，等回应后再决定是否靠近 |
| 递取与放下 | 谁持有、接触、支撑、何时释放 | 接收者抓稳后交付者松手，物件归属发生一次变化 |
| 阻挡与让位 | 所守位置、对方路线、力与反馈 | 用身体占住门前通路，对方停止或绕开，不能只写压迫 |
| 请求与试探 | 对象、允许答案、聆听窗口 | 问后真正等回应，不抢着替对方答 |
| 隐藏与回避 | 藏的具体信息、仍需完成的任务 | 避开某个问题但继续当前工作；不擅自确认角色有罪 |
| 失衡与受惊 | 感知、重心、支撑、恢复 | 受刺激后步伐中断，身体调整找回支撑；不是无因后退两步 |
| 爆发与决断 | 累积条件、触发、行动后果 | 情绪转为明确行动，爆发之后留下呼吸、关系和身体余波 |

动作幅度、速度和强度依据人物及风格选择。有基础的克制表达可以细，快节奏强情绪短剧可以明确而有力；不要把专业等同于轻声、少动和无表情。强烈也不等于全身所有部位同时抖动。

## 4 身体真实感怎样设计

身体先有支撑和任务，再有局部表现。走、转、蹲、起身、推拉与碰撞，都要能说明重心如何转移、足底或座位如何提供支撑、躯干与四肢怎样协作。不是要求生成提示词逐条罗列骨骼，而是防止漂浮和无反馈。

| 身体层次 | 观察与设计 | 不真实的典型问题 |
|---|---|---|
| 支撑与重心 | 哪条腿承重，坐姿接触何处，失衡后如何恢复 | 脚底滑行、前倾却无支撑、坐着瞬间站直 |
| 骨盆 躯干 肩带 | 转向和用力如何传递，是否与任务相容 | 只转头却整个人瞬移，肩颈僵成一块 |
| 手臂 手腕 手指 | 接近、抓握、受力、释放及物件反馈 | 空抓、穿手、腕方向不可能、换手无过程 |
| 呼吸与发声 | 说话、用力、停顿和恢复如何配合 | 长句不换气、身体剧喘却声音毫无影响 |
| 惯性与停止 | 衣物、发丝、随身物怎样滞后并衰减 | 人停物也瞬间冻结，轻触却全身弹飞 |
| 身体限制与个体性 | 疲劳、伤势、技能、服装、地面条件 | 前镜跛行后镜健步；长裙动作不受约束 |

重物移动时先有握持和施力，物体再加速，停止后身体与衣物可能仍有短暂调整。刚性固定件、软布和液体反馈不同。强度只写到本任务可观察且有依据的程度，不编造牛顿值或关节角度来假装物理仿真。

接触双方要同时成立：拢衣者的手沿布料移动，被照顾者肩部承接，褶皱有受力变化；扶起者施力，被扶者也需支撑/配合或明确被动状态。不能只写“他温柔扶起她”，让下游自行解决全部身体过程。

## 5 微表情和细微表演先分清

日常创作把小幅度眼口变化叫微表情；研究中的短暂微表情与一般含蓄表演并不完全相同。创作描述优先写细微表情或局部变化，只有确实需要极短泄露时才强调短暂，不把所有变化锁成固定毫秒。

FACS将可观察的面部运动分解为动作单元，是描述工具；动作编码仍需解释，不能从一个动作直接推导唯一心理或谎言。本手册不宣称完成FACS训练，也不把AU编号作为通用文生视频的控制指令。[Paul Ekman Group FACS说明](https://www.paulekman.com/facial-action-coding-system/)。

真实感不由微动作数量决定。脸上先有相对稳定的基础状态，刺激引起某处改变，变化进入峰值或被压住，随后留下余波或转向新行动。各部位可以不同步，但不同步要有任务依据，不能为了真实随机左右抽动。

## 6 通过肌肉与身体变化细化面部

肌肉知识用于理解皮肤和轮廓如何变化，最终执行多用可见效果。面部表情主要由软组织变化表现，不应让角色因皱眉而改变眼距、颧骨、鼻骨、年龄或身份。

| 区域 | 可见变化和身体联系 | 怎样用于设计 |
|---|---|---|
| 额部与眉区 | 眉抬起、眉间收拢、额纹或局部紧张改变；额肌参与抬眉，皱眉肌参与眉区收拢/下移 | 写哪部分改变、幅度及何时放松，不写整张脸永远紧绷 |
| 眼睑与眼周 | 眼睑开合、下睑张力与眼周皮肤变化；眼轮匝肌参与闭眼 | 区分看得更用力、眯眼、正常眨眼和惊张眼；不给眼球随机抖动 |
| 嘴唇与口周 | 唇闭合、收紧、开启与嘴角变化；口轮匝肌参与唇部动作 | 先核是否在说话、吸气或准备回应，避免闭紧嘴仍完整发声 |
| 面颊与口角 | 嘴角牵动会带动相邻软组织，笑容不是嘴形孤立切换 | 设计笑的形成、是否中断、结束残留，不强迫每次笑都露齿 |
| 下颌与颈肩 | 咬合、放松、张口，与头颈姿态和用力相连 | 将下颌紧张写成有限可见线索，不生成夸张骨骼膨胀 |

基础解剖关系参考[OpenStax头颈肌肉教材](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-3-axial-muscles-of-the-head-neck-and-back)。这里的创作选择不由解剖学直接推出；同样的唇部收紧可以有多种处境解释。无需在每份提示词写肌肉名称，更不能保证模型能逐条激活肌肉。

### 设计局部变化的六个问题

先确认这次反应由什么触发，再选主承载区，说明变化方向、相对幅度、形成与消退、和身体/声音的关系，最后检查镜头是否读得到。例如“听到名字后，笑容停在未完成的位置，嘴角逐渐放回，视线仍留在对方脸上；下一句开口前短吸气”，比“震惊悲伤愧疚、瞳孔颤抖”有明确过程。是否采用仍取决于原文，这个例子不能自动认证人物有罪。

不必每次都显露完整起峰落过程：突发动作可以很快，藏情绪可以只留下残余，画面也可以在进行中切走。但设计者应知道过程，后镜承接才不会重新从中性脸启动。

## 7 眼神与注意怎样设计

眼神首先有对象：对方眼睛、手里物件、门口声源或某个任务区域。世界中的对象方向和镜头投影要对应。画外对手仍有位置和高度，不因未入镜就让角色瞄向错误一侧。

看、识别、确认、回避、搜索、失焦式走神是不同任务，不能全写眼神复杂。可以先看物再看人，也可以身体继续任务而视线停在对方；具体顺序由知情与目的决定。头、眼和身体不总同步，转头也不总要求先转眼，但相互关系应可执行。

眨眼与吞咽可以发生，不宜按每几秒固定插一次。长久凝视可以是设计，别为“自然”硬补眨眼；过密眨眼或瞳孔大小变化也不能证明情绪。近景需看清眼睑、焦点对象和注意变化，远景则靠头向与身体取向。

## 8 笑 哭 愤怒 害怕怎样避免公式化

| 需求 | 从任务与过程设计 | 避免的情绪套餐 |
|---|---|---|
| 真诚欢喜 | 先接到好消息或关系回应，再选择笑容形成、呼吸放松和身体靠近等适当渠道 | 所有人同时咧嘴露齿、强加眼眶湿润 |
| 社交性微笑 | 维护礼貌的目标、笑的形成与对方回应；是否真有开心保持文本边界 | 用眼角没动就断言假笑与欺骗 |
| 忍住哭或悲伤 | 角色仍要完成什么，声音/呼吸或动作在哪被打断，何时恢复 | 眉皱、嘴抖、眼红、流泪、喘息全部同时拉满 |
| 哭泣爆发 | 触发、是否发声、呼吸间断、身体支撑、能否继续说话与收束后余波 | 用一句大哭覆盖整段；眼泪无来源瞬间贴满脸 |
| 愤怒与压制 | 想逼谁做什么，距离、音量、动作与克制/爆发的变化 | 愤怒必握拳咬牙，全员始终最高强度 |
| 恐惧与警觉 | 具体威胁和逃避/保护/确认任务，感知与身体准备相连 | 未见刺激先后退，眼白放大和乱抖代替行动 |
| 意外与重新理解 | 哪项预期被打破，注意如何重排，接下来如何验证 | 每个发现都张嘴瞪眼后定住 |

表演的混合与冲突可以丰富：嘴上继续安抚，身体先挡到孩子前方；保持礼貌笑容但不再接近。但这些是有依据的候选，不是“复杂人物必须表里不一”的规则。真诚、直白也能成立。

## 9 表演 景别 运镜与时间如何对接

| 观看条件 | 优先表演渠道 | 镜头侧配合 |
|---|---|---|
| 远景或全景 | 方向、距离、重心、步态、动作后果 | 保住完整身体与关系，不要求读唇部细动 |
| 中景 | 手、躯干、头肩、交流和物件 | 接触与面部可有主次，不能处处要求同等清晰 |
| 近景 | 目光、头肩、呼吸、聆听与口周 | 给予关键变化可辨时间，不用持续急绕遮掉脸 |
| 特写 | 特定眼口或接触变化 | 归属、触发与后镜承接明确，避免器官展示失去关系 |
| 移动或高运动镜头 | 可读轮廓、关键动作与落点 | 需要细微反应时降低该瞬间干扰或另选观看，不一律取消运动 |
| 背影或遮挡 | 可见肩背、手、停顿、声音 | 不在看不到脸时依赖嘴角或瞳孔 |

快节奏不意味着所有反应只有一帧；细微表演也不意味着全镜静止。可以推进时形成表情、侧移中读手的停顿、动作中切到反馈。时间由台词、动作和阅读负荷共同预算，实际排练/生成再核；不为每次微动作固定加一秒。

## 10 声音和表演怎样成为同一次交流

确定说给谁听、是否想被旁人听到、话里正在争取什么。语速、音量、停顿、重音与呼吸服务这个任务，不统一使用低沉、轻声或哭腔。台词强度可提高，但要与当前身体任务和声场相容。

说话时口型、头颈和呼吸应在同一过程，不能嘴唇一直抿紧还发完整长句。听者有接收窗口：某个字、停顿或动作触发改变，不必一句话结束才统一点头。跨镜声音保持同次发言，不让镜头切换导致整句重说。

人物对世界内声源反应，不对观众配乐自动转头。声音如果来自记忆、电话或门外，说明归属与可听范围，不能因声音参考存在就把该人加进画面。

## 11 从导演依据转为分镜与提示词

导演层：处境与目的、对象、策略、刺激、相互反馈、关键结果、可以变化的部分和仍保留的歧义。

分镜层：当前画面能读到的行动/面部/身体变化，起态、触发、过程和末态；声音列放准确对白及聆听窗口，摄影列保证相应部位和时间可读。

提示词层：保留必要因果和可见变化，删去长篇心理解释与肌肉教材。可以写“她接到拒绝后仍把杯子推到对方面前，手放开，笑容慢慢收回”，不用复制“通过防御机制表现自我价值瓦解”。

普通镜头一句连贯动作足够；关键表演写短节拍；复杂双人接触再补身体状态。最少充分描述不是固定字数上限，平台也没有已证实的统一“多写环境就抢走表演权重”公式。按主次压缩重复，不能删去触发和结果。

## 12 完整表演设计示例

教学输入：母亲正在扣孩子的衣扣；门外有人说“今天不用去了。”母亲停一下，问“是谁说的？”未说明门外人身份，也未说明消息真假。目标是让她从日常照料进入核实消息；不让她先知道背后真相。

| 环节 | 设计与依据 | 交给分镜的可见条件 |
|---|---|---|
| 原状态 | 她熟悉照料动作，注意在衣扣和孩子身上 | 手在扣眼处，身体靠近孩子，不必预先皱眉 |
| 接收 | 听到“今天不用去了”后需要核实 | 当前扣合动作停在未完成阶段，不先把扣子扣好再重停一次 |
| 身体行动 | 仍要照顾孩子，又把注意交给门外 | 扶衣的手保留支撑，另一手停止；头转向声源，身体不突然全转离孩子 |
| 面部变化 | 从惯常工作转为具体询问，心理原因未定 | 目光移到门口，眉区轻收，嘴唇为下一句自然开启；不补愧疚或惊恐套餐 |
| 声音交流 | 原句询问消息来源 | 母亲：“是谁说的？”句尾等待可辨，门外没有新增回答 |
| 末态 | 衣扣未完成，她仍在核实 | 手位、未扣状态和门外声源方向进入下一镜；孩子不凭空哭闹 |

推荐观看：起于手部照料细节，声音先入；以短移/上摇或切近景把注意转到母亲的询问，孩子和扶衣关系仍有锚点。若需看清复杂指尖，不同时要求急速绕脸。这个镜头选择是候选，不是表演方法强制的固定方案。

更强烈的另一处理可以是她听到消息立刻抱紧孩子，但这可能新增保护动机和威胁解读，不应只当无害微动作加入。需先核文本与导演是否允许，不能为了强情绪越过知情边界。

## 13 常见问题怎么修

只有标签：补对象、任务、刺激和反馈。动作像摆拍：补支撑、施力和物件后果。全员同步：分清各人信息与注意。脸像面具：先看是否只写静态状态，再设计有限变化与声音和身体协同；不要马上叠十个微动作。面部变形：检查极近视角、表情过载、身份参考冲突和生成偏离，不认定全由一个词造成。

表演过弱：先问动作与目标是否可读，再增幅度、改变策略或换观看条件，不一律改成哭。表演过满：找本段主承载渠道，减少重复，不删除关键转折。跨镜情绪重置：继承注意、呼吸、肌肉张力、持物和行动阶段，允许有新刺激后的变化，不冻结整张脸。

## 14 交付和验收

对关键表演能回答：为什么做、对谁做、接到什么、身体怎样完成、对方怎样反馈、结果是什么、画面与声音如何读到。重要未知仍保持未知，导演解释与最终指令分层。

先做文字自查，再用图或预演核可见范围与接触，实际视频正常速度核反应顺序、身份、身体反馈、语气和连续性；需要时回看局部。单帧笑脸不能证明笑容形成真实，波形或字幕不能证明声音和口型通过。未生成媒体就保留该验证缺口。

局部修表演不自动改变已采用剧情、台词和机位；若当前机位无法读到关键变化，明确关联修改。事实缺口回分析，策略/动机问题回导演，镜头遮挡回分镜，提示词丢项回编译，实际执行偏离查素材与工具。
