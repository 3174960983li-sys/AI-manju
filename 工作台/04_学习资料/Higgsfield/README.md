# Higgsfield 学习资料库

用途：持续搜集值得学习的 AI 视频项目、制作方案、风格与图片提示词、分镜思路、视频提示词结构及效果设计。
怎么用：从 [资料总索引](资料总索引.md) 进入；每个案例保留来源、证据状态、可借鉴方法及局限。
状态：2026-10-28 首批资料已整理；每日定时任务尚未创建或启用。

## 定时安排

计划每天北京时间 09:00 执行，每次精选 3–5 条值得深入学习的新资料。没有合格新增就写“今日无合格新增”，不重复填数。
当前会话没有 automation_update 或其他原生任务创建工具。Codex CLI 在 WebSocket 超时后自动切换到 HTTPS，最终成功联网读取 Higgsfield 教程；直接抓网页仍返回 HTTP 403。随后尝试注册 Windows 计划任务时，系统返回“拒绝访问”，未创建任务，未提升权限。

打开应用侧边栏 Scheduled / 定时任务，新建每日任务，将 [每日搜集任务指令](每日搜集任务指令.md) 的全文作为任务内容，选择本项目、本地目录模式、每天 09:00。该任务需要电脑开机、应用运行、本地目录可访问及 Higgsfield 连接有效。
官方说明：https://learn.chatgpt.com/docs/automations?surface=app

## 目录

- 每日精选/YYYY-MM-DD：当天精选案例卡片与日报。
- 来源记录：工具返回的预设资料与可追溯元数据；不是实际成片验证。
- 资料总索引.md：类别、来源、日期、状态与卡片入口。
- 每日搜集任务指令.md：可直接交给定时任务执行的工作要求。
- 每日执行.ps1：本机命令行执行脚本，已通过 PowerShell 语法检查；完整自动归档尚未端到端试跑。失败时写入“运行记录”，退出码为 1；命令完成后仍须检查日报是否存在。脚本不会自行创建定时任务。

## 收录边界

优先有真实作品、清晰制作方法或可核对提示词的内容。官方宣传、预设配方、作者实测与亲自观看分开记录。
原文提示词与自行拟写的学习模板分开；没有公开的提示词不反推成“原作者提示词”。
只采集整理，不生成图片或视频，不消费 Higgsfield 生成积分，不安装 Skill，不改动现行 SOP 或项目默认方法。
本库是本工作台新增资料的专用位置；不迁移总库或具体作品的原件。
