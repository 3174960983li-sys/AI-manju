# AI仿真人制作助手

用途：让 Codex 根据已有材料，从当前阶段处理剧本、导演分析、资产需求、分镜、提示词或审查任务。

状态：试用中。候选 Skill 未全局安装；已完成的文字自检不代表真实图片、视频或完整成片效果已验证。这里是用法入口，不是另一份 Skill 正文。

## 怎么用

把下面这段话复制到 Codex，补上你的任务和材料即可；不需要先安装，也不要假定只说 Skill 名称就能自动调用。

```text
请读取 E:\AI漫剧\02_制作方法\02_专业技能\研发候选\ai-photoreal-drama-production\SKILL.md，
按其中与本次任务相关的方法工作，并遵循当前作品的约定。
本次作品：……
任务：……
材料路径与有效版本：……
必须保留：……
期望交付：……
```

例如：“读取上述 Skill，检查我提供的一场戏是否便于制作，列出具体问题。本轮只审查，不改稿、不生成图片或视频。”

## 谁负责什么

- SOP：规定操作步骤和检查方法。
- 制作助手：由当前 Codex 判断起点、完成本次任务、检查结果，必要时交接。
- 专业 Skill：补充本任务需要的具体方法。

这些是职责分工，不表示自动启动多个 Agent、聊天或后台服务。实际生成和新增费用仍以用户本次授权为准。
