# 项目剧本分析

用途：拿到项目要求与剧本后，理解作品、发现问题、提出导演／画面风格／制作路线候选，讨论后整理一份可编辑的Word导演本。

状态：V1.0可用初版，已按用户确认制作并安装到本机Skill目录。已完成《开局鬼敲门》小说素材的讨论稿试用，尚未完成跨项目或媒体生产验证。

## 怎样使用

在Codex中说：

```text
使用 $project-script-analysis（项目剧本分析）。
项目要求与风格偏好：……
剧本路径和有效版本：……
本次分析范围：……
必须保持的内容：……
先读材料，给我项目理解、制作重点、关键问题和必要候选；
与我讨论方向后，再完善Word导演本。
```

如果当前聊天没有刷新新Skill清单，直接说：

```text
请读取 C:\Users\Administrator\.codex\skills\project-script-analysis\SKILL.md，
按“项目剧本分析”的方法处理我提供的剧本和项目要求。
```

## 会交付什么

第一轮给项目理解与关键问题，必要时附少量候选及推荐。讨论后交付Word导演本：项目定位、故事大纲、时代背景与风俗、主配角小传、导演与视觉／制作路线、逐场原文和处理要点、制作需求与安排。

每场先列场景、出场人物及关键道具。小说章节不自动当集数；整理段不是正式场次。原文、推断、研究和提案分开，修补须按用户已确认选择采用；默认不出逐镜分镜、不生成图片或视频。
